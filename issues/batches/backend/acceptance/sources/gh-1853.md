## Specification

The record is `issues/items/gh-1853.md`. No decision record exists. Worker summary: virtual `sleepNight` ref (strict variant with a real calendar date, kind list, dedup identity `sleepNight:<night>`, labeled variant). The message endpoint accepts it with no existence check; an invalid date is the existing 400 `context[i]`. The thread history resolver gives it an active virtual resolution. The ref context reader (data package) resolves one night through `loadSleepNights` in a REPEATABLE READ transaction and renders night, plan name, bedtime, wake time, alarm, changed, duration, bedtime-reminder time, plan item id and exception item id, or `no sleep planned for this night`. Access: the night is read when the turn attached it (`attachedThisTurn`, set only by the Semp message task) or when the agent's project holds read access on all three sleep databases; otherwise a `ForbiddenError` becomes the section `sleepNight: unavailable (no access).` and nothing is read from the sleep databases. `openTurnReadAllowances` also opens the one-run read access for the live settings item, all live plans and the live night item of the attached nights. A new ADR records the decision.

Deviations and spec seams declared by the worker: (1) the sleepNight branch lives in the data package (`sempSleepNightContext.ts`, called from `readSempRefContext`) instead of inside `refExpansion.ts`; (2) the `refExpansion` test file named in Touches is a unit file without Postgres, so the expansion tests are in the new integration file `sleepNightRefExpansion.test.ts`; (3) the one-run access of #1849 cannot be consulted by the prompt expander (the run row does not exist yet), so it reads on the fact that the refs are those of the starting turn, while the allowance rows for the same refs are opened in `onTurnStart`, and a ref in an earlier message needs a grant (recorded in the ADR); (4) the label of a sleepNight ref is the night date, not the plan name; (5) the exception item id comes from a separate query, the highest id wins; (6) files outside Touches: `sempRefHistory.ts`, `sempMessageRefs.ts`, `sempRefReadContext.ts`, `sempMessageTask.ts`, `sempTurnReadAllowances.ts`, `index.ts`, `publicSurface.test.ts`, `sempThreadsHandler.test.ts`, `sempMessageRefs.test.ts` and the new ADR `docs/adr/2026-11-13-a-sleep-night-ref-opens-the-sleep-data-for-one-turn.md`.
