## Specification

The record is `issues/items/gh-1948.md`. Worker summary: an item ref to an Emails item with a draft row expands into the turn context as the draft with the instruction to change it with `mail.draft.update` (a sent draft says it can no longer be changed; a trashed draft and a message without a draft keep the generic expansion); while `mail.draft.update` runs in a run that belongs to a Semp thread it publishes an ephemeral `agent:delta` `{kind: "mailDraftBody", draftId, body}` after the draft is confirmed open and before the durable update, through a new data hook that `wireRealtimeHooks` connects to `publishAgentRunDelta`; a refused update publishes nothing; a delta that cannot be published does not fail the update.
