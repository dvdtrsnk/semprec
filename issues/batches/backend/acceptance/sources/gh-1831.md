Deviations and spec seams the worker declared:

The Task names `apns.interruptionLevel` on `NotificationPushPayload`, but gh-1443 already delivers the level as the top-level `payload.interruptionLevel` (from `pushInterruptionLevelFor`) and `sendApnsNotification` already writes `aps["interruption-level"]` from it.
