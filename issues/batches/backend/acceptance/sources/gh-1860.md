## Specification

The record is `issues/items/gh-1860.md`. Worker summary: migration adds the nullable `semp_messages.steps`, `duration_ms` and `tokens`; a pure projector turns the events of one turn into typed steps (`agentStep.*` i18n keys with params, status ok, wait or error, `approvalRequestId`, `errorCode`); sensitive targets store no name, changes or params; duration runs from the first `turn_start` to the last `turn_end`; tokens are the sum of the settled gateway calls of the message; `finishSempMessageTurn` writes the summary in the same `UPDATE` as the final status, in the done transaction, and a failed turn reads it in its own transaction before the error state is stored; a failed generic operation returns `details.errorCode`.

Deviations and spec seams declared by the worker: (1) the session composition already passed `details`, so only `errorCode` was added; (2) the keys `step.itemPatch` and `step.modelSummary` do not exist after gh-1847, the `agentStep.*` catalog keys are reused and a unit test pins them to `en.json` and `cs.json`; (3) pi emits `turn_start` and `turn_end` per round, so the duration is first `turn_start` to last `turn_end`; (4) message events carry no token usage today, so the tokens of a model step are not set by current producers (unit test with a synthetic event); (5) an errored turn stores no `event_to_id`, its events are read to the end of the run; (6) several files outside the Touches list were added or changed; (7) the new store functions are listed in `publicSurface.test.ts`; (8) the commit trailer follows the Task text.
