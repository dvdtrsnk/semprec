## Specification

The record is `issues/items/gh-1870.md`. Worker summary: mounted `POST /api/proposals/:id/revise`. `reviseProposalWithClient` takes an optional envelope (all of `entityKind`, `target`, `properties` or none; a partial one does not type-check), an optional message (default `Revised by user.`), an optional `ifVersion` handed to the card update and an optional `actingUserId` for realtime addressing. A message alone appends a user history entry on a transcript card only and changes nothing else; any other card gets 400 `validation_failed` on `message`. `createReviseProposalRouteHandler` parses the body strictly (unknown keys, types, `entityKind` against the union, a 2000-character message cap, a partial envelope, an empty body) and runs the revise in one transaction. The manifest `customRoutes` entry, the handler re-export, the route matrix entry, the isolation case and probe and the handler-file mapping were added.
