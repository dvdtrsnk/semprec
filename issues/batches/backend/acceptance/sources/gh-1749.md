## Specification

Deviations and spec seams the worker declared:

1. No ADR was added; the lock order is the one in the trashed-pages ADR and the fan-out and chunking ADRs cover the rest.
2. A failed chunk is rolled back and retried page by page instead of using savepoints, which would leave the after-commit callbacks of a rolled-back page registered.
3. Known limit: the sweep locks a page row then its parent's document, whereas `pageTitleMirror` locks the document then page rows; a concurrent run can end in `40P01`, absorbed by the chunk fallback and the next daily run.
4. The test inventories `taskAffinity.unit.test.ts`, `tenantEnvelope.unit.test.ts`, `queueRuntime.test.ts` and `tenantIsolationJobs.test.ts` were brought in line with the new task (outside the Touches list).
5. `sweepOrphanedPages` is not exported from the `@semprec/data` barrel, so `publicSurface.test.ts` is unchanged.
6. The 30-day restore window itself is not tested; the purge is out of scope.
