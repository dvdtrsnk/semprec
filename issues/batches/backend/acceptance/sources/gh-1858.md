## Specification

The record is `issues/items/gh-1858.md`. Worker summary: Added `GET /api/calendar/reminders?from=<instant>&hours=48` (`createRemindersFeedRouteHandler` in `calendar/remindersFeedRouteHandler.ts`). It validates `from` and `hours` (1 to 168, default 48) before touching the database, then in one repeatable-read tenant transaction reads the tenant zone, selects live Events and Tasks in the window widened by 25 hours, maps them with `toTimelineItems`, reads each Event's calendar `notify`, calls `computeReminderFireAt`, keeps entries with `fireAt` in `[from, from + hours)`, orders by `fireAt` then key and caps at 200. Declared in the systemDatabases manifest as `single-consumer-read`, exported from the data barrel, added to the route matrix, the tenant isolation cases, `ROUTE_HANDLER_FILES` and the `publicSurface` list.
