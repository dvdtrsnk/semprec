Findings and dispositions:

1. Medium, requirements and tests: pages below a subpage do not join the host's epoch when the host's trash joined an earlier epoch, so the host's restore leaves them in the Trash. Disposition: confirmed and fixed in `de5701963`. `pageItemDeleteHook` reads the page's own epoch with `lockItemTrashEpoch` when the page has live subpages and passes it as `deletedAtExact` to the nested trash; the joined-epoch test now has a nested page and a page below it; the new tests fail on the old code (worker's check); the ADR exception was replaced.
2. Medium, project rules: the same defect, reported by the rules lens. Disposition: fixed by the same change; extra tests pin that a page without live subpages reads no epoch and that a page with subpages but no epoch throws.

The focused recheck (`recheck.json`, tip `de5701963`) passed: both findings resolved, no new finding. The security reviewer's read was of `e1699b012`, before the fix; the fix did not touch authentication, secrets, a route or approval and was read by the recheck only.
