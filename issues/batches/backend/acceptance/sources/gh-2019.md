## Specification

The record is `issues/items/gh-2019.md`. Worker summary: a final voice transcript that equals exactly `stop` or `zruš` (NFC, trimmed, lower-cased, trailing punctuation removed) is never stored; the voice session stops speech and, in one tenant transaction, lists the running assistant messages of its thread and sends a `semp_turn_cancel` notification for each. `semprec-agents` listens (`startSempTurnCancelWiring` in `serve.ts`) and calls `InFlightAgentRuns.abortTurn`, which aborts the job's own controller registered through `withInFlightRegistration`; the turn handler stores error/cancelled, closes the run cancelled and pairs dangling tool calls. The voice session ends a cancelled reply for a message it stopped quietly. An ADR was added.

Deviations declared by the worker: (1) `inFlightAgentRuns.unit.test.ts` for the Touches name; (2) the turn registration is a fifth parameter of `withInFlightRegistration`; (3) the barrel entry is one `export *` line and two same-module statements were folded; (4) additions not named in the Task (`listRunningSempTurnIds`, `startSempTurnCancelListener`, `errorCode` on `getSempVoiceDelivery`, `semp/logger.ts`, `sempTurnCancelListener.ts`, fixture controls); (5) the stop applies to running replies only; (6) a stop between the claim of a reply and its first stored run event made the voice session report the turn as unavailable (fixed in the review round); (7) the approval criterion is proven at agents level; (8) the `stop` control frame was not built; (9) one hand-added write-safety baseline entry.
