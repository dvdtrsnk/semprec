## Specification

The record is `issues/items/gh-1841.md`. Worker summary: GET and PATCH /api/projects/:id/database-grants as customRoutes of schemaCore (single-consumer-read, transactional-semantics). The list returns sensitive and user-created databases with the project's access (default none for sensitive, write for user-created, stored row wins). PATCH takes a strict body {databaseId, access}; the default access removes the stored row, any other value is stored; an open system database is 400; unknown project, trashed project, non-Projects item, other tenant's project or database are 404. The wrapper setAgentDatabaseGrantForProjectSettings (exported from the barrel) locks the project and database rows FOR SHARE and is the only path from the handlers to the admin store.
