## Specification

The record is `issues/items/gh-1781.md`. No decision record exists for this source.

Deviations and spec seams the worker declared:

1. "The write moves the task into done" is decided from the `completedAt` the Tasks transform stores with that move (the hook context has no previous status); a repeated done never creates an edge even when the event was later extended.
2. `missed` removes the edge besides `notDone` and `wontDo` (the transform rewrites a `notDone` reopen of a series occurrence to `missed`, issue #1668).
3. An event without a date is not a host event for the completion, consistent with the gh-1780 visibility rule.
4. No barrel export in `index.ts`; nothing outside the package imports the hook.
5. The 13:30 / 14:30 scenario was first tested with a controlled clock at the data layer and, after review, also through PATCH with a fake `Date` only.
6. `taskHostEventOccurrenceRoutes.test.ts` case "creates the next instance once when the placed current instance is completed" was updated for the new edge.
7. The worker's commit trailer used the system attribution instead of the Fable line.
