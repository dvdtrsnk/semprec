## Specification

The record is `issues/items/gh-1756.md`. Worker summary: declared the link rule `fileProjectsFromEvents` (`Events.project` to `Files.projects` through `Files.events`) in the systemDatabases manifest and added `eventAttachmentLinkReleaseEdgeChangedHook` in `blobs/eventAttachmentLinkRelease.ts`, registered in `domainWriteHooks.ts` directly before `linkRuleEdgeHook`. On removal of a `Files.events` edge the hook locks the file row, then the projects link row, then the companies link row. When the removed Event is the only source of the file's `fileProjectsFromEvents` link it deletes that link and the file's `fileCompaniesFromProjects` link with their sources and announces the file after commit; when another Event feeds a link that is not `on` (after the fix round also when the file is in the Trash) it detaches the removed Event; otherwise it changes nothing. Nothing is backfilled and there is no migration. ADR `2026-11-15-an-event-attachments-company-link-ends-with-the-attachment`.
