## Specification

The record is `issues/items/gh-1762.md`. No decision record exists for this source. Worker summary: `GET /api/calendar/agenda` (`createCalendarAgendaRouteHandler` in `calendar/agendaRouteHandler.ts`) pages the calendar timeline as one list from a day, forward or backward, over `readCalendarTimeline` in windows of 31 days, scanning at most 366 days per request and ending five years from the start day. The opaque cursor encodes the day and the id of the last item (continues from the next day when the item is gone); the horizon returns a continuing cursor; an invalid `from`, `direction`, `limit` or `cursor` is `400 validation_failed`. It is declared in the calendar manifest `customRoutes`, the route matrix calendar slice, `ROUTE_HANDLER_FILES` and the two-tenant isolation case.

Deviations and spec seams: (1) the route entry lives in the slice module `routeMatrix/calendar.ts`, not in `routeMatrix.ts`, with its isolation case and handler-file mapping; (2) after the derived timeline sources (birthday, holiday, sleep) landed on the tip, the controller decided that the agenda lists stored Events and Tasks only, so the handler filters the timeline with the type guard `isStoredItem`, two existing tests were adapted (shape comparison with the stored entries; the first/last calendar date test hides sleep); (3) the worker reported one surviving mutant (a cursor whose item id matches an item on another day), which the requirements reviewer found killed by an existing test; no mutation run was repeated at landing.
