Worker summary: Confirm and reject routes accept an optional ifVersion (ISO 8601 UTC timestamp string, validated with z.iso.datetime, else 400 validation_failed field ifVersion) and pass it to confirmProposalWithClient / rejectProposalWithClient (new trailing parameter).
