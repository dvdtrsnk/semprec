## Specification

The record is `issues/items/gh-1992.md`. Worker summary: Exact-match duplicate step in the proposal computation. A company with the same eight-digit IČO or a person with an address in person_email_index that belongs to a live item is replaced by a step that refers to the existing item and writes nothing: a link for a nested record, an update marked primary with no properties and relations for the proposal's own record (also for an answer without operations). The alias of the replaced create is kept. ProposalComputationOperation gets the optional primary marker, buildProposalSteps honours it without storing it, buildProposalEnvelope stores one marked operation as a multi-step envelope. New read lookupLiveCompanyIdByIco; trashed companies and trashed people are not duplicates; invalidProposal results are untouched; the lookups are reads in one short transaction closed before return. ADR written.
