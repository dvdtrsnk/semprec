## Specification

The record is `issues/items/gh-1865.md`. Worker summary: POST /api/mail/threads/:threadId/read with body { read: boolean } (strict; 400 otherwise). New mail/mailThreadActions.ts holds the shared thread-action helpers: resolveMailThreadForAction (alias translation, 404 for unknown or foreign), listMailThreadActionMessages (every live copy with an incoming classification - not own, not in Sent, not in Drafts - plus the last incoming message id, read from the shared mailThreadCopyCtes), readMailThreadUnread (the copy_stats value the list and the detail report) and announceMailThreadChanged (one thin mailThread invalidation via runAfterCommit). The handler createMailThreadReadRouteHandler (mailThreadRoutes.ts) locks each target copy in item id order (lockItemForObservedMailFlags), skips a copy whose locked read value already matches or that is gone or trashed, writes the others through updateItemWithClient as the session user (so the Emails flag hook records the desired state and queues the mailbox sync), answers { threadId, unread } with the translated thread id, and announces once after the commit. read:true writes every incoming copy in every mailbox, read:false the copies of the last incoming message only.
