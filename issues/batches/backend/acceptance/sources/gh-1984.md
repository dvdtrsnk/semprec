## Specification

The record is `issues/items/gh-1984.md`. Worker summary: the undo of a confirmed card cancels the follow-up jobs its confirmation queued, in the undo's own transaction. For `transcriptionQueued` it removes the `transcriptionCreate` and `transcriptionJob` of the Files item, locks the file row and moves a Transcripts item that a job already checkpointed to the Trash (refusing the whole undo when the checkpoint names the transcript of another file); for `mcpSyncQueued` it removes the `mcpServerSync` job; a result without `followUp` touches no job. New inverse helpers `cancelJob` (`@alldots/queue`), `cancelTranscriptionJobs` and `cancelMcpServerSync`. `syncMcpServerTools` re-locks the server item in its two write transactions and writes nothing for an item gone or in the Trash. After review the confirm records `transcriptionQueued` only for jobs it added itself, and the undo locks the file row before the job rows.
