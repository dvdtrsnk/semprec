## Specification

The record is `issues/items/gh-1926.md`. Worker summary: `POST /api/semp/threads/:id/messages/:messageId/retry` queues another attempt of the latest assistant reply when it is in status `error` or `done` with incomplete steps (`retrySempReply`: thread and message row locks, a new queued assistant message with the same `reply_to_message_id` and `attempt` + 1, thread activity and the turn job in the same transaction); anything else is 409 `retry_not_latest`, an invisible or unknown thread or message is 404; the migration adds `semp_messages.attempt` and the partial unique index; the history returns `attempt` on assistant messages.
