## Specification

The record is `issues/items/gh-2020.md`. Worker summary: `POST /internal/tts/stream` reads the optional `x-semprec-agent-run-id` and `x-semprec-semp-message-id` headers (validation shared with the pi route through a new `attributionHeaders.ts`) and reserves the row with both. The STT stream accepts `{type:'attribute', sempMessageId}` and sets `semp_message_id` on the chunk rows reserved since the stream opened or since the previous attribute message, in one tenant-scoped all-or-nothing statement (`attributeGatewayCallsToSempMessage`); a message the tenant cannot see closes the stream with 1008, a malformed frame closes it as `invalid_frame`. The client's `SttStream` gets `attribute()` and `synthesizeSpeech` takes `agentRunId` and `sempMessageId`. The voice session sends `attribute` after a final became a message and passes the turn's run and assistant message to TTS; the read-aloud route passes the message and its run. `getAgentRunUsage` with a message also counts calls without a run id when the message belongs to the run. ADR added for the attribution protocol.
