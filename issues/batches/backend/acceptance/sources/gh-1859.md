## Specification

The record is `issues/items/gh-1859.md`. Worker summary: Results of the `journal` group of the search operation carry `journal { type, period }` (stored type and canonical period). The shared output schema is a discriminated union: only the journal group's results have the field and the strict schemas refuse it elsewhere. A Journal entry with an unknown or missing type or a missing, empty or non-text period is excluded in SQL for both the count and the page, so `total` and the cursor stay consistent with the listed results.
