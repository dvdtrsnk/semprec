## Specification

The record is `issues/items/gh-1770.md`. No decision record exists for this source and the controller gave no note for this chain.

Deviations and spec seams the worker declared:

1. The route entries are in `routeMatrix/transcripts.ts`, not in `routeMatrix.ts`.
2. The Event participant edge is created with `createRelationIfAbsentWithClient` (the insert-only variant), not plain `createRelationWithClient`, so a participant who already has an edge is never rewritten and an invitation's metadata is kept. The rules reviewer confirmed it is the case the ADR `2026-11-06-speaker-confirm-inserts-participants-without-metadata-replacement` defines.
3. Clearing a key (`personId: null`) leaves the key's open card as it is: the Task's card-settling step is read as belonging to an assignment of a person, since a clear has no person to confirm. A test pins this. The requirements reviewer judged the reading defensible and did not report it.
4. `transcriptSpeakerSuggestion.ts` only gained an export of `speakerSuggestionIdempotencyKey`.
