## Specification

The record is `issues/items/gh-1832.md`. No decision record exists. Worker summary: transcription/transcriptAgentTools.ts: createTranscriptGetTool and createTranscriptSegmentGetTool, each (currentRunId, args) => { error, result } with a JSON result and strict zod argument schemas (transcriptGetArgsSchema, transcriptSegmentGetArgsSchema). They run in the caller's tenant scope (fail closed without one), require a run of that tenant, check the transcript is live, and read through readTranscriptDetail, so speaker names, notes with names and the display name of gh-1830 are shared with the detail endpoint; nothing is written. transcript.get returns header, speakers with labels, summary, decisions, action items with owner labels, event, segmentCount, speakerCount. transcript.segment.get takes an index range or a time range, limit 200 segments or 15 minutes (rangeTooLarge), context default 3 and at most 3 added on top with isContext. Both are declared in systemDatabasesModuleManifest.ts agentTools with capability core.item.read, approval none, risk read, with the factories and schemas re-exported in its export block and the labels agentTool.transcript.get.label and agentTool.transcript.segment.get.label in seed/i18n cs and en.

Deviations and spec seams declared by the worker: (1) Error results are JSON strings: {error: not_found}, {error: run_not_found}, {error: validation_failed, reason: invalidArguments | rangeRequired | rangeInverted | rangeTooLarge, message, fields?}; the issue fixes only validation_failed with rangeTooLarge. (2) from and to in the segment result are the first and last index of the requested stretch without its context, null when it holds no segment; an index range past the end is clamped, a time range selects segments that overlap it strictly, and a time range must have a positive length. (3) A range is exactly one complete pair (fromIndex and toIndex, or startsAt and endsAt); a half pair counts as neither. (4) The count limit applies to the requested index span and to the matched segments of a time range; the 15 minute limit to the requested seconds and, for an index range, to the span of its existing segments. (5) The factories are exported from the manifest file as the Task says and are not added to the data barrel. (6) The tools read the whole detail composition (including playback and automation lookups) because the Task asks for the same read as the detail endpoint. (7) Commit trailer names Claude Sonnet 5.5.
