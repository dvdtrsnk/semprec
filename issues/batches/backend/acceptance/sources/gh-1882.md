## Specification

The record is `issues/items/gh-1882.md`. Worker summary: Deleting any instance of a recurring task series trashes every instance under one deletedAt; restoring any one restores the series. Tasks registers a cascade expansion (collectCascadeRows replaces the plain subtree walk in delete, restore and purge), pre-lock hooks (series instances in id order, then the task_recurrence row), delete/restore hooks that turn the repeat rule off, record the holding instance in new task_recurrence.trashed_active_item_id, and turn it on again for that instance. The delete preview gains seriesInstanceCount, attachmentCount, hostEventCount via a per-module delete impact reader; the item.delete projection hashes the numbers into the snapshot and the approval description carries them.
