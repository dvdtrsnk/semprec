## Specification

The record is `issues/items/gh-1810.md`. No decision record exists for this source. Worker summary: per-database agent grants enforced in the data layer. ADR `docs/adr/2026-11-12-per-database-agent-grants.md`; tenant table `agent_database_grants` (now migration 0154); store `agentGrants/agentDatabaseGrantsStore.ts` (`getAccess`, purge cleanup), admin store `agentDatabaseGrantsAdminStore.ts` (not in the barrel), `agentDatabaseAccess.ts` (`assertAgentDatabaseAccess` reads the database and the decision in one statement and locks the decision row `FOR SHARE`; `assertWriterDatabaseAccess`; `listUnreadableDatabaseIds`). The check runs in the transaction of item get/list, `database.query`, `view.query`, `relation.list`, item create/patch/delete/restore, relation put/update/set/delete, `link.relink`/`link.unlink` and the destructive projection of `item.delete`, `relation.delete` and `link.unlink`; `database.get` is forbidden and `database.list` and the schema projection omit an unreadable database; relation targets in an unreadable database are `{ id, hidden: true }`; purge of a Projects item deletes its grants.

Deviations and spec seams declared by the worker (full list in the handover): (1) the admin store is not in Touches and gh-1841 lists the same file as new, so an add/add collision is expected there; (2) the destructive projection and the gateway pass the agent's project for the delete operations; (3) extra call sites were checked beyond the list; (4) `generateSchemaProjection` has the new `agentProjectItemId` option wired in `semprec-agents`; (5) shared types for hidden relation targets; (6) the `archived` column is not read; (7) the composite FK name has no `_tenant_` suffix and two inventory tests were updated; (8) `getAccess` has no production caller in this issue; (9) the commit trailer names Claude Sonnet 5.5; (10) the ADR is dated 2026-11-12. Originally declared deviation 3 (relation.list unfiltered) was withdrawn by the review fix round.
