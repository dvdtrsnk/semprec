## Specification

The record is `issues/items/gh-1902.md`. Worker summary: mail/draftRetirement.ts: retireSupersededSempDrafts(client, { threadId, ownMessageDate, excludeDraftItemId? }) lists the unsent agent drafts of the thread (also those whose thread_id was merged into it, through mail_thread_aliases) whose source message's date is older than ownMessageDate, locks each (Emails item, then mail_drafts row), re-checks it under the lock, retires it with the system writer through the choke point trash (items) and deletes its mail_drafts row (shared steps now in mail/mailDraftTrash.ts, also used by discardEmailDraft), returns the retired item ids and announces the thread once when it retired any. A draft of the user, the excluded draft, a sent draft, a draft without a source message or with an unreadable source date, a draft of another thread or tenant, and a draft whose source is as new as or newer than the message stay. sendDraftEmail calls it in its finalizing transaction (excluding the sent draft, ownMessageDate = send time); ingestEmailMessage calls it for a newly stored message that is the user's own (sender is one of the ingesting mailbox's registered addresses, or the folder is the Sent folder), dated by the message's date or by the ingest time when it has none.
