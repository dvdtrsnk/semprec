## Question

Should Projects declare tasks in both relatedOrder.order and omit despite Task 1 forbidding overlap, and how is the original People order preserved?

## Options considered

- Approve unchanged: rejected because Task 3 requires a declaration that Task 1 requires validation to reject.
- (a) Remove tasks only from projects.order, retain projects.omit = tasks, and explicitly preserve the original people.order including tasks: selected. Context explicitly excludes Tasks from the Projects related list because the page has its own Tasks section. The Decision makes omit specific to the viewed record type.

The accepted manifest declaration precedents in docs/adr/2026-09-11-module-manifest-custom-routes.md and docs/adr/2026-10-25-server-driven-inbox-editor-schema.md were read; neither dictates related-list membership.
