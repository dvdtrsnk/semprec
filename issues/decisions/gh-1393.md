# Decision: gh-1393 (subpages ADR proposal)

## Question

The implementation proposal gh-1393 (record where subpages live in an ADR) is
open without `spec:approved`. Approve it, or make the minimal correction that
makes it approvable.

## Options considered

- Approve unchanged (SOUND): rejected. Task item 2, the second Touches line,
  the In-scope line and the third acceptance criterion required adding an
  "amended by" note to the body of
  `docs/adr/2026-10-28-block-model-for-page-documents.md`, an accepted ADR.
  `docs/adr/README.md` (section "Superseding a decision"),
  `review-rules/rules.md` (editing an accepted ADR's body is a high-severity
  finding) and `issues/README.md` (section "Autonomy": accepted ADR bodies
  are never edited) all forbid that, so the implementation would have been
  blocked in review.
- Write a new ADR that supersedes the block-model ADR (ADR CONFLICT):
  rejected. The new subpages ADR only carves an exception for `page` blocks
  (they carry the title as plain `text`) and leaves the rest of the block
  model intact, so per `adr-conventions` it is a standalone ADR that
  cross-references the old one; nothing is superseded and no frontmatter
  changes.
- Minimal spec correction (DEFECT): chosen. The amendment is recorded in the
  new ADR itself, which the Task already creates; the block-model ADR stays
  untouched.
