# Decision: gh-2029 (Email in a trashed folder after a mailbox removal)

## Question

An Email that lives only in a folder trashed before the removal of the mailbox stays live and listed. This follows the counting rules of gh-1501 and is in tension with the wording of criterion 1. Should it change?

## Decision

No. It stays as delivered.

## Consequence

No code change. The open owner question of the receipt of gh-2029 is closed.
