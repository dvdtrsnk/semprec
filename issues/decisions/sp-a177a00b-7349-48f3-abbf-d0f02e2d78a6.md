The Task's `date_relative` compares with the device's current day, which common Kotlin cannot read without a platform call, and the projection's helpers exceed detekt's limit of eleven functions per file. Which files may the issue touch?
- Options considered: (a) the day from the kept `GET /api/schema` (`tenant.today`), which is stale after a day offline; (b) an `expect` function for the device's day with actuals for the JVM and Android and for Apple, beside the existing `CacheFiles` actuals, the device's day carried on `QueueClock` so tests fix it, and the insertion helpers in a file of their own.
