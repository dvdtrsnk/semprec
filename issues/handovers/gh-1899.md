## What was delivered

- `createPrefilledEmailDraft(client, input, context)` and `computeDraftPrefill` in the new `mail/mailDraftPrefill.ts`, called by `POST /api/mail/drafts` for the modes `reply`, `replyAll` and `forward`. `isPrefilledDraftMode(mode)` tells the route which modes are prefilled.
- Reply goes to the source's Reply-To, else its sender. Reply-all adds the source's To and Cc minus every address of the mailbox and duplicates (case-insensitive). A forward has no recipient. Cc and Bcc are always empty.
- `from` is the address the message was delivered to when it is one of the mailbox's addresses, else the mailbox's first address.
- Subject gets `Re:` or `Fwd:` unless it already starts with it (case-insensitive). `in_reply_to` is the source Message-ID and `references` are the source's plus that id; a forward sets neither and keeps the source thread id.
- Body: the person's own text, an empty line and the quote. The quote header is localized (new keys in `mail/i18n/cs.json` and `en.json`, the date written by Luxon in the tenant's system timezone and the user's locale), every quoted line starts with `> `. A forward uses a Forwarded message header with sender, date, subject and recipients. A text-only source is quoted as stored; HTML is reduced to plain text (fix round).
- A forward copies the source's attachments through `attachFileToDraft` (own file copies; the original keeps its files) under the upload limit of the composition root.
- `createEmailDraftInMailbox` takes optional `inReplyTo` and `references`. Computed fields in the request body are ignored; `sourceEmailId` is required for the three modes (400); a `new` draft keeps its required fields (`newDraftFieldsSchema`).

## Entry points and contracts dependents build on

- Route contract of `POST /api/mail/drafts`: for `reply`, `replyAll` and `forward` the body is `{ mailboxId, sourceEmailId, mode, body? }` and every other field is computed. 404 for a source with no `mail_message_meta` row (a draft) or in the Trash; 400 for a mailbox without an address or a zone the system cannot read (field `timezone`); 413 `mail_attachment_too_large` for a forward over the limit.
- `createMailDraftCreateRouteHandler(pool, dependencies?)` takes the composition root's dependency container as an optional second argument (as the attach route does); `maxFileSizeBytes` is required only for a forward and a plain `Error` when absent.
- `createPrefilledEmailDraft` accepts optional overrides (`to`, `cc`, `bcc`, `subject`) that replace the computed values (added for gh-1927); the HTTP route passes none. `sendingAddress` is exported from `mailDraftPrefill.ts`.
- The route context of the create handler now requires `identity.user.locale`.
