## What was delivered

When the AI gateway refuses a call because of the tenant's own budget state (no budget row, daily cap, monthly cap), the tenant's connected clients now get one Semp status invalidation (`sempStatus` realtime scope) per window, so they re-read the derived `aiBudgetMissing` / `aiBudgetExhausted` problems.

- `reserve()` in `packages/ai-gateway/src/gateway.ts` catches the refusal that the budget transaction threw and rolled back, awaits `announceTenantRefusal`, and throws a fresh plain `BudgetExceededError` (same class and constant message). Nothing is published before the rollback.
- Operator-wide refusals (`globalDaily`, `globalMonthly`) and calls with no tenant scope announce nothing.
- The window is the exhausted window as the gh-1456 summary names it (monthly wins when both caps are reached); a tenant without a budget row is in the window `noBudget`, which lasts to the end of its local day.
- Once per tenant, window kind and timezone, remembered in an in-process `AnnouncementLedger`; the entry lasts to the end of the window. A restart forgets it and the announcement then repeats once (idempotent).
- A failing publish is logged with `{ tenantId, errorName }`, swallowed, and the window is released so the next refusal retries. The publish goes through an awaited publisher so a failed NOTIFY really reaches the gateway (review fix).
- `semprec-ai-gateway` composes its server in `createGatewayServer(pool, config)` (`src/gatewayServer.ts`), which wires `wireRealtimeHooks` over the gateway's own pool before listening; `serve.ts` calls it. New dependency `@semprec/realtime` of the gateway service.
