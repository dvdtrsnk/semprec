## Changes

- **`.github/scripts/run-repo-script-tests.mjs`** (new): a script with no dependencies that runs every `*.test.mjs` file.
  - It takes one optional directory argument. Without it, it uses the `.github/scripts` folder it lives in, worked out from its own location rather than the current directory.
  - It searches that folder recursively for files ending in `.test.mjs`, skips `node_modules`, and sorts the paths.
  - If it finds no test file, it prints an error naming the folder and exits 1. The header comment explains why: `node --test` given a glob that matches nothing exits 0 without running anything.
  - Otherwise it runs `node --test` on exactly those files as a child process with inherited stdio and exits with the child's exit code. It exits 1 if the child was killed by a signal or could not be started.
  - It also exits 1 with a clear message when given more than one argument or when the argument is not a folder. The repo's script review rules require command-line arguments to be checked where they are read.
- **`.github/scripts/run-repo-script-tests.test.mjs`** (new): `node:test` tests that run the script as a child process against temporary folders they create:
  - no test file: exits 1 and the output names the folder (criterion 1);
  - one passing test file in a nested subfolder: exits 0 (criterion 2);
  - one passing and one failing file: exits non-zero (criterion 3);
  - `x.test.js`, `x.mjs` and `node_modules/**/y.test.mjs` are not collected, both alongside a real test and when they are the only files (criterion 4);
  - an argument that is missing or is a file, and too many arguments, all exit 1.

  The tests remove `NODE_TEST_CONTEXT` from the child's environment. Without that, the inner `node --test` would report its results to the outer test runner instead of exiting with its own status.
- **`backend/package.json`**: added `"test:repo-scripts": "node ../.github/scripts/run-repo-script-tests.mjs"` and inserted `&& pnpm run test:repo-scripts` into `verify` directly after `pnpm run check:write-safety`. Nothing else in `verify` changed (criterion 6).
