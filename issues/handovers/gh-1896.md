## What was delivered

- `POST /api/mail/drafts/:id/send` (custom route `mailDraftSend`, `transactional-semantics`). `sendMailDraft` (`mail/mailDraftSend.ts`) reads the draft in one transaction (item lock, then `mail_drafts` row lock), builds the send input (From, recipients, subject, text body, the draft's attachments with the blob's mime type, In-Reply-To and References from a reply or reply-all source message, the provider thread id of a source in the same mailbox) and calls `sendDraftEmail` as the user with the transport of the mailbox's sync mode.
- `sendDraftEmail` (`mail/send.ts`) refuses a mailbox in `needsReauthorization` (409 `mail_reauthorization_required`) before the claim, raises `MailSentFolderMissingError` (409 `mail_sent_folder_missing`), takes attachments and the provider thread id, and in its finalizing transaction sets `mail_drafts.sent_at`, announces the `mailThread` invalidation and returns `threadId` and `sentAt`.
- A second call, or a call that loses the claim, answers 409 `mail_draft_already_sent` with details `{ emailId, threadId }` (`MailSendClaimLostError`, a `ConflictError`). Transport failures map by class: reauthorization to 409 `mail_reauthorization_required`, a rejected recipient to 422 `mail_recipient_rejected`, a rejected login to `mail_auth_failed`, an unreachable server to `mail_server_unreachable`; any other failure propagates and the claim is undone, so the draft stays sendable. 400 without a recipient in To, Cc or Bcc; 409 `mail_draft_not_editable` for a provider draft without a row; 404 for an unknown, trashed, malformed or foreign id; 403 `from_address_not_registered`.
- Fix round: the claim transaction locks the item then the row, refuses a trashed item or a sent row, and runs a `beforeClaim` guard in which the route re-reads the draft and refuses with 409 `version_conflict` when it changed since the route decided; `lockUnsentDraft` (edit, discard, attach, detach) answers a claimed draft with 409 `mail_draft_already_sent` `{ emailId, threadId }`. An ADR for this contract was added by the fix commit.
