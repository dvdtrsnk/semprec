## What changed

- **`delegationRegistry.ts`**: the new-session path opens one `withTransaction` that looks up the supervisor run and the target item. The target must be a live (`deletedAt === null`) item of the tenant's Projects database. Any refusal returns the new `UNKNOWN_DELEGATION_TARGET_MESSAGE`, and the existing `finally` releases the reservation. A missing Projects database throws a plain `Error`, so it is not reported to the model as a refusal. The UUID format guard and the existing-entry reuse path are unchanged.
- **Tests**: hard-coded target UUIDs (21 in the registry test, 3 in the tool test) are replaced with real Projects items. New cases cover a random id, a trashed item, and a Tasks item; retry after refusal; the missing-database throw; the tool mapping; and two cross-tenant cases on the runtime-role pool, where RLS applies.
- **`data/src/testSupport/projectFixtures.ts`**: adds `createTestModuleItem(pool, moduleId)`, which `createTestProjectItem` now delegates to. The Tasks-item case needs it.
