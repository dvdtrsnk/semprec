## Contracts dependents build on

- Route `GET /api/events/:id/tasks` answers 200 `{ eventId, tasks: [{ taskId, title, state }], counts: { open, total } }`, tasks in the order of the Event's edges by `addedAt`. `state` is `{ kind: "open" | "missed" | "done" }`, `{ kind: "doneElsewhere", completedOn }`, `{ kind: "doneElsewhere", eventName }` or `{ kind: "moved", lastEventName }`. `counts.open` counts the rows whose state is `open` or `missed`; `total` counts all rows. A missing, trashed or another tenant's Event answers the same 404 `not_found`; an id that is not a UUID is 400 `validation_failed` on `id`.
- Barrel exports of `@semprec/data`: `taskStateInEvent`, `readEventTasks`, `eventTaskCounts`, `createEventTasksRouteHandler`. `eventTaskCounts` (an Event with no task has `{ open: 0, total: 0 }`; an id that names no live Event is absent) is the reader for the event lists that show counts.

## Deviations from the specification and spec seams

1. The matrix entry is in the slice module `routeMatrix/events.ts`, not in `routeMatrix.ts`.
2. The `task` field of the pure function's input is a small typed object (`status`, `completedOn`, `completedIn`) built by the reader, not an item.
3. Interpretations recorded in the docstring: "not done" for `missed` means any status other than `done` (`notDone`, `wontDo` and `missed` all give `missed` once the Event has ended); a done task that stores no `completedOn` and has no `completedInEvent` edge reports `done`; the last live host event counts every live host event of the task, dated or not; the `completedInEvent` edge decides before the status; the name of the Event a task was completed in is read even when that Event is trashed. `readEventTasks` returns `null` for a missing or trashed Event and the handler maps it to 404.
4. The `tenantIsolationRoutes` case does not pin the state kind, because the fixture Event's date is fixed and the real clock decides `open` against `missed`; it asserts the counts `{ open: 1, total: 1 }`.
5. The commit trailer of the worker names Claude Sonnet 5.5 (the attribution the harness gave it).
