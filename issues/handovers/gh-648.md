## Differences from the issue text

- **A stored credential is needed:** `handleSyncMailAccountTask` checks for a stored credential before the adapter step. Without one, the job fails with `has no stored credential` and never reaches the adapter. So the composition test also stores an app-password credential.
- **Test-only exports:** `storeCredential` and `ensureMailAccountSyncState` are not exported from `@semprec/data`. Rather than add credential writers to the production exports, I re-exported them from the test-only `@semprec/data/testSupport` entry (`testDb.ts`).
- **Parameter type:** `resolveMailModuleIds` takes a `PoolClient`, not the `Queryable` the issue names, because `getDatabaseByModuleId` only accepts a `PoolClient`. The only caller passes a transaction client anyway.
