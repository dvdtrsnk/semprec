# Handover: throttle the mail OAuth callback and the calendar webhooks per client address

Commit on `fix/ia-edge`: `7711346d8`. Nothing was run against a real provider or server.

**Changes.**
- `clientIpThrottle.ts`: actions `mailOauthCallback` (30 per 15 minutes) and `calendarWebhook` (300 per minute), both keyed per client address like login.
- `mailOauthCallbackHandler.ts`: `createMailOauthCallbackRequestListener(pool, { trustProxy, clientIpThrottle? })`; every request is counted first, before validation and the state lookup; a refusal is `429 { error: { code: "rate_limited" } }` with `Retry-After` and the no-referrer headers.
- `calendarWebhookHandlers.ts`: both listeners take `{ trustProxy, clientIpThrottle? }`; every POST is counted before its body is read (the Graph validation handshake included); a refusal is an empty `429` with `Retry-After`. A Graph batch reads its first 100 entries, looks each distinct `(subscriptionId, clientState)` pair up once, at most 20 per batch.
- `app.ts`: passes `trustProxy`; one limiter shared by the two calendar webhooks.
- `docs/architecture/tenancy-and-security.md`: public throttles.

**Tests.** `calendarWebhookHandlers.test.ts`: over budget the Google webhook, the Graph webhook and the Graph handshake answer 429 with `Retry-After` on a listener over an unreachable pool (so no database call ran) and share one budget; a batch of 60 copies of one subscription plus 30 distinct unknown ones runs exactly 20 routing lookups and queues the known account's sync once. `mailOauthHttp.test.ts`: over budget the callback answers 429 `rate_limited` over an unreachable pool and logs nothing more. `clientIpThrottle.unit.test.ts`: the limit table. All three new tests fail with the handlers of the base commit.

**Verified** (backend/): `pnpm run build`, `pnpm run lint`, `pnpm run format:check`; unit `services/alldots-api/src/__tests__/` (13 files, 129 tests); integration `calendarWebhookHandlers`, `mailOauthHttp`, `tenantIsolationRoutes`, `cacheControl` (4 files, 629 tests). Not run: full `pnpm run verify`, `test:e2e`.
