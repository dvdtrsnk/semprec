# Handover for gh-1473

The storage and validation for a mailbox's IMAP and SMTP server settings are in place. Nothing reads or writes them yet outside the tests.

## What was added
- **Migration `0101_mail_account_server_settings.sql`**: table `mail_account_server_settings` keyed by `mailbox_item_id`, with `tenant_id`, row-level security (restrictive `tenant_isolation` plus permissive `tenant_rows`), the tenancy comment and the `semprec_side` grant. CHECKs: ports in 993, 143, 465, 587; security `tls` or `starttls`; IMAP and SMTP host, port and security are each all set or all null. No password column. The previous release never touches the table.
- **Store `mail/mailServerSettingsStore.ts`**: `getMailServerSettings`, `upsertMailServerSettings` (insert or replace, returns the stored settings) and `deleteMailServerSettings` (returns whether a row existed), exported from `@semprec/data`. Either endpoint may be `null` (an SMTP-only or IMAP-only mailbox). Invalid input throws `ValidationError` with `details: { field }` where field is `imapHost`, `imapPort`, `imapSecurity`, `smtpHost`, `smtpPort`, `smtpSecurity` or `username`.
- **Host rules**: lower-cased, trimmed, one trailing dot removed, at most 253 characters, valid labels, at least two labels; refused: IP literals in any notation (dotted, decimal, hex, octal, IPv6, bracketed), `localhost`, and `.localhost`, `.local`, `.internal` suffixes.
- **ADR `docs/adr/2026-10-25-mail-server-settings-allow-the-standard-mail-ports.md`**: the explicit-port exception and the host rules.
- Tenant export and purge lists are derived from the catalog, so only `tenancyCatalog.test.ts` (tenant table list and the primary-key-without-tenant exception) and `publicSurface.test.ts` (three new names) needed lines.

## Tests
`mailServerSettingsStore.test.ts` (round trip, replace, SMTP-only, delete, each bad host and port, bad security and username, the database CHECKs on their own, RLS with a second tenant), `tenancyCatalog.test.ts`, `publicSurface.test.ts`, `migrationCompatibility.test.ts` pass. Lint, format check, typecheck of the data package and the migration numbering check pass. I did not run the full verify.

## Notes for dependants
- Callers pass a `Queryable` inside the tenant scope they already hold; the table has `tenant_id DEFAULT app_tenant_default()`.
- A DNS-name host can still resolve to a private address. The connect-time address check (#1478) is what makes a stored host safe; do not connect to it before that exists.
- The primary key is `mailbox_item_id` alone and there is no foreign key to `items`; removing the row when a mailbox is removed is #1690.
