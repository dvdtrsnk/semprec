# Handover for gh-1491

The outgoing MIME builder exists as a pure module; nothing calls it yet. Committed locally, not pushed.

- **Module:** `backend/packages/data/src/mail/outgoingMime.ts` exports `buildOutgoingMime(input, deps)`, `generateOutgoingMessageId(fromAddress)` (moved from `send.ts`, which now imports it, behavior unchanged), `OutgoingAttachmentMissingError` and the input/output types. It is not re-exported from `@semprec/data`'s `index.ts`; import it by path, or add the export in the issue that first needs it from outside the package.
- **Input:** `{ from, to, cc?, bcc?, subject, text, messageId, inReplyTo?, references?, attachments?: { filename, contentType, blobId }[], calendar?: { method: "REQUEST" | "CANCEL" | "REPLY", content } }`. `messageId` is required; use `generateOutgoingMessageId` to make one.
- **Deps:** `{ client, files, mailAttachments, maxAttachmentBytes? }`. `client` must be a tenant-scoped client (it reads `blobs` and calls `primaryRootForBlob`). Both storage roots are passed, as `openBlobFromRoots` needs them.
- **Output:** `{ raw: Buffer, messageId, envelopeRecipients }`. `envelopeRecipients` is to, cc and bcc addresses; bcc appears in no header. Hand `raw` and the envelope to the transport unchanged.
- **Errors:** a line break in subject, any address or name, message ids, references, attachment filename or content type throws `ValidationError`. A missing blob row, or bytes in neither root, throws `OutgoingAttachmentMissingError` (a `NotFoundError`, 404). Attachments summing above `maxAttachmentBytes` (default 25 MiB, checked from `blobs.byte_size`) throw `ValidationError`.
- **Calendar:** added as a `multipart/alternative` sibling of the text body with `Content-Type: text/calendar; method=<METHOD>; charset=utf-8`. Nothing here produces the iCalendar content (#1774).
- **Memory:** `MailComposer` builds the full message into one buffer, so peak memory is roughly the attachment total (hence the cap). Attachment streams are destroyed in a `finally`.
- **Tests:** `backend/packages/data/src/__tests__/outgoingMime.test.ts` (integration tier, real DB for the blob rows): headers, text/plain body and byte-identical attachments from both roots, calendar part, bcc envelope-only, line-break rejection (subject, name, address, filename), missing blob row, bytes in neither root, size cap, Message-ID generator. Eslint, prettier and `tsc` are clean.
- **Not done:** `OutgoingMailMessage`/`NodemailerSmtpClient` still send fields, not raw bytes; moving transports onto `raw` is for #1634, #1637, #1753.
