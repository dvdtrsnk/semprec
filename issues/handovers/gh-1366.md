# Handover for gh-1366

Added `docs/adr/2026-10-28-block-model-for-page-documents.md` (status accepted). No code, no existing ADR touched.

**What it records**
- Closed type registry (`text`, `h1`-`h3`, `bullet`, `number`, `todo`, `quote`, `page`) and the field contract (`indent` 0-5, `done`, `text` as `Y.Text`, `pageId`); `sys:children` is no longer written.
- Order in top-level `doc.getArray('order')`; fractional index rejected.
- `Y.Text` attributes `bold`, `italic`, `code`, `link`; soft break is `\n`; Markdown is only a serialization (#1608).
- Strict validation (HTTP 400) on server writes, read-time normalization rules for `WS /api/sync`, reading never modifies Yjs.
- Module placement: new directory `shared/block-model/` at the repo root, own pnpm package `@semprec/block-model`, only dependency `yjs`, no `pg` or Node-only imports. Backend and `web/` consume it by a `link:`/`file:` dependency.
- No sweep or migration of existing documents; no native block API; the Yjs behaviors convergence relies on.
