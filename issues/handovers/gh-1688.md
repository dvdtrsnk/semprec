## What was delivered

- `GET /api/mail/summary` (mail module custom route `mailSummary`, justification `single-consumer-read`), implemented in `backend/packages/data/src/mail/mailSummary.ts`. It answers 200 `{ unreadInbox, flagged, sempDrafts, accounts, accountsNeedingReauth }`.
- `unreadInbox` is the number of threads that match the thread list's `inbox` and `unread` predicates, `flagged` the number that match its `flagged` predicate. Both are counted over the thread list's own `copies` and `copy_stats` CTEs, so each equals the number of threads `GET /api/mail/threads` returns for the same filter (`?unread=true`, `?box=flagged`).
- `sempDrafts` is the constant `0` until #1694 delivers the Semp draft predicate.
- `accounts` is the number of non-deleted Mailboxes items. `accountsNeedingReauth` is `[{ id, name }]` of the non-deleted mailboxes whose `syncStatus` is `needsReauthorization`, ordered by id.
- All counts come from one statement in one transaction, so they read one snapshot. The row is parsed with zod. The route writes nothing.
