## What was delivered

- Results of the `journal` group of the `search` operation (`GET /api/search`, MCP search tool) carry `journal: { type, period }`: the stored Journal `type` (`year`, `quarter`, `month`, `week`, `day`) and the canonical `period` string (`2026-10-16`, `2026-W42`, `2026-08`, `2026-Q3`, `2026`). No localised label is returned.
- `SearchOutputSchema` is a discriminated union: only the `journal` group's results have `journal`; the strict schemas refuse it in every other item group and in the thread groups.
- A Journal item with an unknown or missing `type`, or a missing, empty or non-text `period`, is excluded in SQL for both the count and the page (`groupFilter`), so `total` and `nextCursor` agree with the listed results. Inbox items and trashed items are never in the group.
