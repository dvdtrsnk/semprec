Closes #1218

The runtime-role route proof in #1213 exposed two production isolation failures. A legacy global blob content-hash index prevented a second tenant from uploading identical bytes. MCP grant writes relied on foreign-key checks, which bypass RLS and could reference a foreign tenant's registration.

Migration 0080 removes only the obsolete global blob index; the tenant-leading index and existing targetless ON CONFLICT preserve per-tenant deduplication. MCP grant upserts resolve and lock the registration through RLS in the same SQL statement, making foreign and missing registrations return the same NotFoundError without a grant write. Existing blob/catalog fixtures now assert the migrated schema. Two-tenant semprec_data tests cover independent identical bytes, same-tenant deduplication, grant/revoke permission in both directions and no side effects.
