# gh-1498 — Validate mailbox connection limit

Repository-Issue: gh-1498
Implementation commit: `e936e6ec1b18035aa60bba647cd63f95a396b766`.

## Delivered behavior

- Registers Mailboxes create and update validation hooks at `domainWriteHooks.ts`.
- When connectionLimit is explicitly present, accepts null or an integer from 1 to 15 inclusive; rejects other values with ValidationError, status 400, code validation_failed, field connectionLimit.
- An absent connectionLimit and items of other owner modules are ignored. Update checks only the patch, so renaming a mailbox with a legacy out-of-range value remains possible.
- No migration or rewrite of legacy values. The limiter's tolerance and defaults are unchanged.
