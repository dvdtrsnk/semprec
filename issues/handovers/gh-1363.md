# gh-1363 — two-hop relation filtering

Implemented `relation_path_contains` with exactly two nonempty relation keys and a UUID value in both filter-tree copies. The condition lists and new-condition schema inputs have parity tests. `buildFilterProperties` resolves root definitions and one target level in at most two batched queries, fetching only target relation properties. Target database ids are validated from stored property configs.
