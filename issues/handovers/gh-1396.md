# Handover for gh-1396

Added streaming speech-to-text to `semprec-ai-gateway`: a loopback WebSocket route `/internal/stt/stream`, an OpenAI streaming provider adapter, chunked budget accounting and a caller function in `packages/ai-gateway-client`.

- **Route** (`sttStreamHandler.ts`, wired in `app.ts` and `serve.ts`): `/internal/stt/stream` is in `GATEWAY_ENDPOINTS`; a plain HTTP request gets 426. The upgrade needs the bearer token (401) and a valid `x-semprec-tenant-id` (400; a missing tenant is refused here, unlike the HTTP routes). An optional `?language=xx` (two letters) goes to the provider.
- **Frames**: inbound binary frames are raw PCM s16le mono 16 kHz with no type prefix (the one-byte prefix of the ADR is the API channel's concern, #1546), at most 16 KiB and an even length. Inbound text is only `{"type":"end"}` (4 KiB cap). Outbound is `{type:"partial"|"final", text}` and `{type:"error", code}`.
- **Error codes**: `budget_exceeded`, `provider_error`, `capacity` as specified, plus `session_limit` (30 min), `idle_timeout` (60 s) and `invalid_frame`, taken from the ADR limits. An oversize frame closes with 1009 and no message. Close codes: 1000 normal, 1008 policy and budget, 1011 provider, 1013 capacity or outgoing backlog.
- **Accounting**: `reserveAudioStreamChunk` in `packages/ai-gateway/src/gateway.ts` runs the existing reserve step and returns `{settle, fail}`, neither of which rejects (settle uses the existing retry). The handler reserves the first chunk before opening the provider session, and the next one when a chunk has been filled (bytes based, 30 s by default, `AI_GATEWAY_STT_CHUNK_SECONDS`). Rows have operation `voice_transcribe_stream` and are settled with the seconds computed from forwarded bytes. On disconnect the open row is settled when audio was forwarded, else failed; the provider session is aborted. These rows carry no thread, turn or run id yet, the ADR's attribution is still open for #1734.
- **Concurrency**: 8 streams (`MAX_CONCURRENT_STT_STREAMS`), the extra one gets `capacity` and close 1013 without a reservation or provider session. The per-user limit of the ADR is for the API. `closeAll()` runs at shutdown before the drain.
- **Provider**: `audioProviders/openAiStreamingTranscriptionProvider.ts` (realtime transcription, `gpt-4o-transcribe`, server VAD). It resamples 16 kHz to the 24 kHz OpenAI requires. New required env: `OPENAI_API_KEY` and `AI_GATEWAY_OPENAI_STT_PRICE_PER_AUDIO_HOUR`; `ai-gateway.env.example` is updated. The adapter was exercised only through its resampler unit test and the fake provider; it has not been run against the live OpenAI endpoint.
- **Client**: `openSttStream(config, {language, signal}, events)` returns `{sendAudio, end, close}`; events are `onPartial`, `onFinal`, `onError(code)`, `onClose`.
- **Dependencies**: `ws` added to `semprec-ai-gateway` and `ai-gateway-client`.
- **Tests**: `sttStream.test.ts` (partials and final, chunk rows and real seconds, `budget_exceeded` mid-stream and on the first chunk, wrong token and tenant, disconnect leaves no `reserved` row, concurrency limit, invalid frames), `openSttStream.unit.test.ts`, the resampler unit test. `tenantIsolationGateway.test.ts` now covers only the POST endpoints.
- **Not covered**: the 30 minute and 60 second timers have no test.
- **For dependants**: #1734 can call `openSttStream` inside the tenant scope and treat `onFinal` as the end of an utterance. Run id attribution on the chunk rows still needs a way to pass it into the route.
