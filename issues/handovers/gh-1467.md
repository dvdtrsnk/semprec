# gh-1467 — usage units by operation, failed calls excluded

Implemented from integration tip 6a87f7ce06d21248f9f8fdebd08c287f16dce017, on top of gh-1462 (same file).

`getAiUsageReport` (backend/packages/data/src/aiGateway/aiUsageReport.ts) now classifies a call's native unit from `ai_gateway_calls.operation`: the single named list `AUDIO_OPERATIONS` (`transcription_transcribe`, `transcription_diarize`) gives `audio_seconds`; every other operation, including NULL, gives `tokens`. The `rows` query is a CTE that classifies, then groups by (provider, model, is_audio, run unit), and filters `status <> 'failed'`, so `callCount` counts only reserved and settled calls. Total cost is unchanged because failed rows cost 0. Within a group the sums are numbers for its own unit (0 while every call is reserved) and null for the other. `AiUsageReport.estimated` is true when any non-failed call in `[from, to)` is `reserved`. The daily/monthly series are untouched.

Tests: new `usage units and call status (gh-1467)` block in aiGateway/__tests__/aiUsageRouteHandler.test.ts covers failed-call exclusion with unchanged rows and total, reserved transcription and diarization in audio rows only, a reserved token call (0 tokens, null audio), `estimated` true while reserved and false once settled, and false for an empty range. Existing exact-shape expectations gained `estimated: false`. `src/__tests__/aiUsageReport.test.ts` now tags its audio fixtures with `operation = 'transcription_transcribe'` (the `recordAudioGatewayCall` writer leaves operation NULL) and lists `estimated` among the report keys. Both files pass (31 tests) on real PostgreSQL; prettier, eslint and tsc are clean.

Notes for dependants (#1472, #1477):
- `recordAudioGatewayCall` writes operation NULL, so such a row is classified as tokens; production audio goes through `reserveGatewayCall` with an operation. Fixtures for audio rows must set the operation.
- The web client schema (web/src/api/aiUsageOperations.ts) was not changed; `estimated` is not yet consumed there.
- Full backend/web verify: NOT RUN; no migration.
