- Confirming an MCP server card never writes `project_mcp_grants`. The card's project selection only pre-fills the server's `read`-class tools (a client concern built from `riskClass` in the AGENT page list), and the user grants them on the AGENT page route.
- The ADR confirms the rule in the header comment of `mcpProjectGrantsStore.ts` without editing older files.
- It names the invariant to keep testing: no path other than `PATCH /api/projects/:projectItemId/mcp-grants/:mcpToolRegistrationId` writes a grant (not the confirm route, the post-confirm sync job, agent tools or `/mcp`).
