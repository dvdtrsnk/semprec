## What was delivered

- `backend/packages/data/src/calendar/eventReminderValuesHook.ts` declares the allowed sets once, `EVENT_ALERT_MINUTES = [0, 5, 15, 60, 1440]` and `EVENT_TRAVEL_MINUTES = [15, 30, 60]`, and exports the item create hook `eventReminderValuesItemCreateHook` and the item update hook `eventReminderValuesItemUpdateHook`.
- The rule, for `alertMinutes` and for `travelMinutes`: a value that is absent or `null` passes; any other value must be a number of the key's set. `0` is a value: it is allowed as `alertMinutes` ("at event time") and refused as `travelMinutes`. 7, -5, 15.5, a numeric string, an empty string and a boolean are refused.
- The create hook judges the stored properties of the new Event, after the Events transforms and the schema defaults. The update hook judges only the keys of the written patch and does not read the stored row, so an Event that holds a value outside the sets stays editable as long as the patch does not name that key.
- Both hooks do nothing unless the database is the system database owned by the `events` module (`database.system && database.ownerModuleId === EVENTS_MODULE_ID`). A database of the user's own and a non-system database the events module owns store any value.
- A refusal is a `ValidationError` with `details.field` `alertMinutes` or `travelMinutes`, thrown inside the write's transaction, so the insert or update is rolled back. The hooks write nothing and query nothing.
- Both hooks are registered in `backend/packages/data/src/domainWriteHooks.ts`.

## Contracts dependents build on

- Error as each transport exposes it, for a refused create and a refused patch:
  - REST (`POST /api/databases/:id/items`, `PATCH /api/items/:id`): status 400, code `validation_failed`, `details: { field }`.

  - The message is `Property '<key>' must be empty or one of <the set>`; it names the key and the set, not the submitted value.
- gh-1719 (landed in the same merge) and gh-1858 may assume that an Event written after this landing holds `alertMinutes` as `null`, absent or one of 0, 5, 15, 60, 1440 and `travelMinutes` as `null`, absent or one of 15, 30, 60. An Event stored before it can hold another value; nothing rewrites stored rows.
