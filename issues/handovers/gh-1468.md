## Delivery and criterion trace

1. Ingest preview/time: nullable columns are added by `0087_mail_message_meta_preview_ingested_at.sql`, with no SQL backfill/default. `mail/mailPlainText.ts` extracts the existing sanitize-html conversion and collapses whitespace, trimming to 200 UTF-16 code units without splitting a surrogate pair. `mail/ingest.ts` supplies preview and current application time to `mailMessageMetaStore.ts`. `mailMessagePreview.test.ts` tests text precedence, empty/missing bodies, long emoji boundary, timestamp bounds, and repeat ingest.
2. Sent claim convergence: `mail/send.ts` populates the same fields in its pre-SMTP claim. `mailMessageMetaStore.ts` returns both typed columns and uses existing-first COALESCE in its conflict update. The send matrix asserts the committed claim from inside the SMTP adapter, exercises real Sent-folder ingest, then exercises SQL ON CONFLICT with competing values. Text, HTML, empty text and missing body branches are covered; another test fills nulls while preserving an empty preview. Existing `mailSend.test.ts` covers send/claim failure paths.
3. Legacy rows/idempotence: `mail/mailMessagePreviewBackfillJob.ts` runs `forEachActiveTenant`, selecting null-field candidates by item-id keyset, locking source and target rows and committing each page of at most 100 separately. Missing preview derives from the item's body, missing ingest time from its `updated_at`; existing non-null fields survive. The production-worker test processes 101 messages and another tenant through a `semprec_data` runtime pool, verifies exact values, verifies foreign/random reads both return null, skips a suspended tenant, and verifies a second run changes no row. The failure test rejects a write in page two, proves the first 100 rows stay committed and both page-two rows remain null, verifies the other tenant was processed, then retries successfully. A no-body legacy row receives an empty preview.
4. HTML-only ingest: the production ingest matrix asserts tag/script-free preview; the extracted conversion is also tested directly. Search still uses that same conversion.
