# Handover for gh-1533

MCP tools now reach the model as `mcp_<toolName>_<first 8 hex of the server item id>`, so two servers exposing the same tool no longer collide.

- **Change:** new exported pure `mcpModelToolName(toolName, mcpServerItemId)` in `backend/services/semprec-agents/src/agentSessionComposition.ts`, used by `createMcpTools`. The server id has dashes removed and is lowercased and cut to 8 characters; the tool part is sanitized to `[A-Za-z0-9_-]` and cut to 51 characters, so the name is at most 64. The server name is not used, so a rename keeps names. Generic operation tools still use `toModelToolName`. `withUniqueNames` and its warning are unchanged and still catch two tools of one server that shorten to the same name.
- **Tests:** `agentSessionComposition.unit.test.ts` adds cases for the format, different suffixes per server, sanitizing and the 120-character tool name (64 characters ending in `_` plus 8 hex), both servers offered under different names across a rename, and the remaining same-server collision. Existing cases now compute names with `mcpModelToolName`; the wiring case now offers both granted servers' `search`.
- **Not covered:** names are checked through the mocked grant listing, not a real database.

Notes for dependants:

- Old names such as `mcp_search` stored in earlier run histories no longer match (out of scope).
- Ids that are not UUIDs (test fixtures) are cut to 8 characters after dash removal; characters outside `[a-z0-9_]` become `_` to keep the name valid.
