## Deviations from the specification and spec seams

1. The Task names `apns.interruptionLevel`, but gh-1443 already delivers the level as the top-level `payload.interruptionLevel` and `sendApnsNotification` already writes `aps["interruption-level"]` from it. A second field would duplicate the mechanism, so `apns` carries only `category` and `approvalRequestId`.
2. The preference model has only a boolean switch for approvals; "off" means no push, not a lower level.
3. The `apns` fields are set only when `source_table` is `approval_requests`; an `approval_pending` notification from another source gets none.
