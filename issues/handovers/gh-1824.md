Blockers: all declared blockers were delivered on the tip (gh-1820 is an earlier member of the chain); no `Shared-file ordering` blocker was open.

## What was delivered

- `finishAgentRun(.., "error", errorCode, errorDetail?)` and `finishAgentRunWithErrorNotification(client, id, errorCode, errorDetail?)` take no free text: they store the canonical code as both `error_code` and `result`; an unknown value is refused before any write (the run stays running). A done close keeps its result snapshot.
- All error-close callers were converted: `lifecycleAdapter.closeFailedAgentRun`, `sempConversation.closeDropped` (cancelled), `startupRepair` (interrupted), `delegationRegistry.failRun`, `scheduler/actions.ts` (both closes, through `TickRunOutcome` in `semp/sempTickThreadStore.ts`, whose error variant no longer carries a result), `agentRunTasks.closeUncomposedRun`.
- New catalogs `agentRuns/i18n/cs.json` and `en.json` (`agentRun.error.<code>.summary` for the five codes), `agentRunErrorSummary(errorCode, locale)` and `agentRunErrorFields(run, locale)` in `agentRuns/agentRunErrorSummary.ts` (async; catalog loaded with `loadModuleCatalogs`, a failed load is not cached), both exported from the barrel. The data package build copies `agentRuns/i18n` into `dist`.
- `GET /api/agent-runs/:id` returns `errorCode` and `errorSummary` for the session user's locale (null for both on a done or running run) and keeps `result`. A failed row closed before the change (null code, legacy text) reads as `internal` with the internal summary and keeps its legacy text in `result`.
- The close sites that log a close failure now log `agentRunId`, `errorCode` and the close error's name, never the error object or the task.

## Contracts dependents build on

- `agent_runs.result` of an error run is the canonical code (same value as `error_code`), no exception text. The code set: `budgetExceeded`, `modelError`, `cancelled`, `interrupted`, `internal`.
- `agentRunErrorSummary` and `agentRunErrorFields` from `@semprec/data`; catalog keys `agentRun.error.<code>.summary`.
- Response fields `errorCode`, `errorSummary` on the agent run detail.
- No table, migration, route or job added.
