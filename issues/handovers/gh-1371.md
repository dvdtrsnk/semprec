# Handover for gh-1371

Added one ADR, `docs/adr/2026-10-28-live-voice-chains-speech-to-text-agent-turn-and-text-to-speech.md`. No code changed. `node .github/scripts/adr.mjs --all` validates it; I could not run prettier (no network, no installed `node_modules`).

- **Decisions recorded, each with alternatives and trade-offs:**
  - Pipeline: speech-to-text, a normal agent turn, then text-to-speech.
  - Providers: OpenAI streaming transcription (`gpt-4o-transcribe`) and OpenAI TTS (`gpt-4o-mini-tts`) as gateway adapters. Rejected alternatives are Deepgram, Google and ElevenLabs.
  - Transport: a new authenticated WebSocket on `semprec-api`. Binary frames have a one-byte type prefix, `0x01` for microphone audio and `0x02` for speech audio. Audio is raw PCM s16le mono, 16 kHz up and 24 kHz down. JSON text frames carry control, transcripts and errors.
  - Session limits: 16 KiB binary and 4 KiB text frames, 30 minutes maximum, 60 s idle timeout, one session per user.
  - Budget: 30 s chunks, one `ai_gateway_calls` row per chunk. Rows have purpose `voice`, carry the thread, turn and run, and show up as Voice activity in AI usage reports.
  - Audio is never stored.
  - Barge-in stops the speech output only. A turn is cancelled only on an explicit "Stop"/"Zruš" or a `stop` frame.
  - Backpressure: a 256 KiB outgoing buffer limit closes the session with `overloaded`.
- **Czech listening test not performed.** I cannot run a listening test, so no result is recorded. The ADR defines the test and marks OpenAI TTS as provisional; #1399 must run it before shipping its adapter. If ElevenLabs wins, a new ADR supersedes only the provider choice.
- **Area deviation.** The issue asked for `area: [backend, apple]`, but the ADR validator rejects `apple` for ADRs dated after 2026-10-24 ("use mobile for new Apple decisions"). The ADR uses `[backend, mobile]`.
- **For dependants:**
  - #1396, #1399 and #1546 should take the frame format, limits, chunk length and error codes (`budgetExceeded`, `sessionLimit`, `idleTimeout`, `overloaded`) from the ADR.
  - Voice rows in `ai_gateway_calls` need to carry a run id, which audio rows could not before.
  - The STT and TTS model names and the numeric limits are the author's choices. The issue let the author refine them.
