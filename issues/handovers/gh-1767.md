## Contracts dependents build on

- `POST /api/transcripts/:id/action-items/:actionItemId/task` (body `{ name?, date? }`; 201 for a new task, 200 for a replay of the live one), `DELETE /api/transcripts/:id/action-items/:actionItemId/task`, `GET /api/events/:id/transcript-action-items`. Handler exports `createTranscriptActionItemTaskRouteHandler`, `createTranscriptActionItemTaskRemoveRouteHandler`, `createEventTranscriptActionItemsRouteHandler`; route matrix names "transcript action item task create", "transcript action item task remove", "event transcript action items" (slice modules `routeMatrix/transcripts.ts` and `events.ts`), with isolation cases and handler-file mappings.
- Unknown, foreign, trashed and out-of-range ids answer one 404. The Event's proposals list leaves out items with a live task, followed items and other people's items.
- The state row is written only through `transcriptActionItemStates.ts` (single owner, ADR `2026-11-11-transcript-action-item-states-serialize-on-the-transcript-row`). No migration, table or job.
