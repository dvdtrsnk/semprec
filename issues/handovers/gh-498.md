## Summary

Closes #498. Adds `mergeOps(...parts)` in `backend/packages/data/src/chokePoint/mergeOps.ts`. It merges the choke-point section objects that #500 will compose. Unlike object spread, it throws when two parts share a key, so a later section can't silently replace an earlier section's method.

- **Types:** the result's type is the intersection of the parts' types, and a call with zero parts returns `Record<never, never>`.
- **Duplicate keys:** if any own enumerable key appears in more than one part, it throws an `Error` whose message names the key, e.g. `mergeOps: duplicate key "shared" appears in more than one part`. It checks symbol keys as well as string keys. Non-enumerable own keys are ignored, the same way spread ignores them.
- **Result:** it returns a new object built with `Object.assign({}, ...parts)`, and all keys are checked before anything is copied. No part is changed, whether the call succeeds or throws.

Using it inside `createChokePoint` is out of scope; #500 does that.

`backend/packages/data/src/__tests__/mergeOps.unit.test.ts` (unit tier, no Postgres):
- Disjoint parts merge, and each method still works when called detached, which shows it doesn't depend on `this`.
- Type checks with `expectTypeOf`: the result is `typeof sectionA & typeof sectionB`, `a` is `() => number` and `b` is `() => string`. The inline call from the acceptance criteria, `mergeOps({ a: () => 1 }, { b: () => "x" })`, is assigned to `{ a: () => number; b: () => string }`.
- A duplicate string key throws and the message names it; so does a duplicate symbol key.
- A non-enumerable own key doesn't count as a duplicate.
- Zero parts gives `{}` with type `Record<never, never>`.
- One part gives a copy, not the same object.
- The parts are not changed, on success or when a duplicate throws.

For the inline call, TypeScript infers literal return types (`() => 1`, `() => "x"`), as it does for any generic function taking object literals. Those types are still assignable to the originals, so the test uses an assignment for that case and checks exact types on parts declared beforehand.
