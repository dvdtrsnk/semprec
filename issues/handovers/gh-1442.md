# Handover for gh-1442

A shared, localized model display-name lookup now exists in `@semprec/data`. It is not yet used by any API response; #1822 and #1472 consume it.

**What changed**
- `backend/packages/data/src/aiGateway/modelDisplayNames.ts` exports `getModelDisplayCatalogs()` (lazy, once per process, via `loadModuleCatalogs(import.meta.url)`) and the pure `resolveModelDisplayName(catalogs, locale, modelId)`.
- The id is mapped by ordered, case-sensitive patterns: `^claude-sonnet`, `^claude-haiku`, `(^|/)whisper`, `^pyannote`. Any other id (including other Claude families) is returned unchanged.
- The key is resolved with `resolveCatalogLabel` and `toManifestLocale(locale)` (requested locale, then `en`).
- New catalogs `aiGateway/i18n/{cs,en}.json` with `model.claudeSonnet`, `model.claudeHaiku`, `model.whisper`, `model.diarization` (cs "Diarizace", en "Diarization").
- Both functions are exported from `packages/data/src/index.ts`; `publicSurface.test.ts` lists them.
- The `build` script of `packages/data` copies `src/aiGateway/i18n` to `dist/aiGateway/i18n`.

**Tests**
- `aiGateway/__tests__/modelDisplayNames.test.ts` (no database): Sonnet/Haiku versions, whisper with and without a provider prefix, cs vs en diarization, unknown locale falls back to en, unknown and wrong-case ids are returned raw.
- `publicSurface.test.ts` passes. Lint and `tsc` on the data package were clean; prettier clean.

**Notes for dependants**
- Call `await getModelDisplayCatalogs()` once per request and pass the result to `resolveModelDisplayName` per row; the resolver is synchronous.
- Mapping a new family needs a pattern in `MODEL_FAMILIES`, a key in both catalogs and a test.
