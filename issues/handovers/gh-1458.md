# Handover for gh-1458

Runs started from a scheduled heartbeat occurrence now link to it and chain their queue attempts. Committed locally on `wf/gh-1458`; not pushed.

- **Migrations:** `0108_agent_run_heartbeat_occurrence.sql` adds unique index `heartbeat_occurrences_tenant_id_id_uq`, nullable `agent_runs.heartbeat_occurrence_id`, the composite key `agent_runs_heartbeat_occurrence_id_fkey` `(tenant_id, heartbeat_occurrence_id) -> heartbeat_occurrences (tenant_id, id)` (`NOT VALID`, `NO ACTION`) and index `agent_runs_occurrence_idx (tenant_id, heartbeat_occurrence_id, attempt)`. `0109_validate_agent_run_heartbeat_occurrence.sql` validates the key. The key is not named `*_tenant_fkey` for the same reason as in gh-1448.
- **Store:** `AgentRunRow.heartbeatOccurrenceId`, optional `CreateAgentRunInput.heartbeatOccurrenceId` (both create functions write it), and `getLatestRunOfOccurrence(client, occurrenceId)` (highest `attempt`, ties by latest `started_at`, or `null`).
- **Scheduler:** `ActionContext` has optional `occurrenceId` and `attempt`; `runScheduledOccurrenceFire` passes `occurrenceId` and `attempt: helpers.job.attempts`. Manual and item-event branches pass neither. `coreAgentRunAction` creates the first attempt with `createAgentRun`, later ones with `createChainedAgentRun` against the latest run of the occurrence; on a chain conflict (`null`) it logs ids only and creates the run unchained with the same occurrence and attempt. Closing, notifications and retry counts are unchanged.
- **Tests:** `coreAgentRunAction.test.ts` (fail, fail, succeed chain; three failures with one notification on the last run; unchained fallback; no occurrence stays null/attempt 1) and `tenantForeignKeys.test.ts` (another tenant's occurrence refused with 23503). Also run: `agentRunsStore`, `tenancyCatalog`, tsc, eslint, prettier, migration numbering. Full verify not run.
- **For dependants:** #1914 and #1908 can group and inspect attempts by `heartbeat_occurrence_id` and `attempt`; the fallback path can leave two runs of one occurrence with the same `attempt` only if a predecessor was already retried elsewhere.
