## What changed

**Live-sync root in `semprec-api`** (`backend/services/semprec-api/src/serve.ts`)
- After `createApiQueueRuntime(...)`, it looks up `mailboxesDatabaseId` with `resolveMailModuleIds` inside `withTransaction`. It then builds the root with `createNoopMailLiveSyncLifecycleFactory(pool)`, logs lifecycle failures through `onLifecycleError`, and awaits `mailLiveSync.start()`.
- Each active Mailbox now gets a `mail_account_sync_state` row and one immediate `mailAccountSync` job. That also gives the five-minute sweep something to pick up.

**Shutdown order** (`shutdown.ts`)
- `CreateGracefulShutdownOptions` has a new `mailLiveSync: { stop(): Promise<void> }` field.
- `runShutdown` stops it after the HTTP drain and before `queueRuntime.stop()`, so a lifecycle can't enqueue a job while the runner is stopping.
- If it fails, the error is logged and shutdown continues, the same way `queueRuntime.stop()` is handled. The docstring describes the new sequence, and the heartbeat is still not part of it.

**Phantom unit removed**
- `deploy/systemd/semprec-mailsync@.service` is deleted and removed from `SERVICE_UNITS`, so `provision.sh` installs four service units.
- In `deploy.sh`: removed `active_mailsync_instances`, the skip branch in `report_versions`, the instance block in `activate_release`, and the comment. It now restarts exactly `semprec-ai-gateway`, `semprec-api`, `semprec-agents` and `semprec-transcribe`.
- In `deploy.test.sh`: removed the `mailsync-units` fixture and the `list-units` mock, dropped `semprec-mailsync@alice` from both unit loops, and added a check that the first deploy issues exactly four restarts.
- In `provision.test.sh`: dropped the three `semprec-mailsync@` assertions.
- Docs updated: `deploy/README.md`, `README.md`, `backend/services/README.md` (now in English) and `docs/operations/database-roles.md`. The `semprec-mailsync` row is gone and the `semprec-api` row now mentions mail.

- `grep -rn "semprec-mailsync" deploy/ README.md backend/services/README.md docs/operations/` returns nothing.
