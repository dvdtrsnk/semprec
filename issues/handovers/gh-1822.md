## Contracts dependents build on

- **`getAgentRunUsage(client: PoolClient, runId: string, locale): Promise<{ totalCostUsd: number, estimated: boolean, perModel: [...] }>`.** One statement over `ai_gateway_calls` with `agent_run_id = runId` and `status <> 'failed'`, grouped by (provider, model).
- **`perModel` entry:** `displayName` (from `resolveModelDisplayName` in the given locale: a new version of a known family keeps the family name, an unknown model id is returned raw), `callCount`, `inputTokens` and `outputTokens` (0 when no call has a count), `audioSeconds` (null unless a call carries them), `costUsd`. Ordered by cost descending, then model, then provider.
- **`totalCostUsd`** is summed in Postgres as a decimal (a window sum over the groups) and converted once with `Number`, so 0.7 + 0.1 + 0.1 gives 0.9.
- **`estimated`** is true when a counted call is `reserved`; a reserved call counts at its estimate with tokens 0.
- **A failed call is not counted.** A run without counted calls returns `{ totalCostUsd: 0, estimated: false, perModel: [] }`.
- **Sub-runs are not included**, as the issue says.
- The function does not check tenant or actor beyond row-level security: in another tenant's scope it returns the empty usage. The handler calls it only for a run that passed the actor check.

## Deviations from the specification and spec seams

1. `totalCostUsd` is a window sum in the same statement, not a sum of the converted per-model numbers.
2. Ordering adds provider as the last tie-break.
3. The barrel line is `export *`, so the two result types are exported; `publicSurface.test.ts` (outside `Touches`) lists `getAgentRunUsage`.
4. `agentRunHandler.unit.test.ts` (added by gh-1805, outside this source's `Touches`) mocks `getAgentRunUsage` and asserts the locale the handler passes and that a run of another actor reads no usage.
5. The "404 for another tenant" case of `agentRunHandler.test.ts` is a new describe on a runtime-role pool with two tenants. Requirements reviewer: in that HTTP test the 404 would also be produced by the actor check alone, because the foreign run's actor is another user; the row-level-security path is proven separately by the runtime-role test of `agentRunUsage.test.ts`.
