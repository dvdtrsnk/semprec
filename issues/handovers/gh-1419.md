# Handover for gh-1419

Stored Processing proposal envelopes with an unknown `entityKind` are now readable; they are displayed, never executed. No code writes such an envelope yet. Targeted checks run: `tsc`, eslint, prettier and the integration tests `proposalActions`, `inboxTickProposal` and `publicSurface`. The full `verify` was not run.

**What changed**
- **`inboxTickAction.ts`:**
  - `parseStoredProposalEnvelope` now returns `ProposalEnvelope | UnknownKindProposalEnvelope | null`.
  - A well-formed envelope (string `entityKind`, string `target`, object `properties`) of an unknown kind parses into `{ unknownKind: true, entityKind, target, properties }`.
  - A structurally malformed envelope still throws `Malformed proposal envelope on proposal <id>`.
  - The new exported helper `unknownStoredEntityKind(value)` returns the unknown kind string, or `null`.
  - `proposalEnvelopeSchema` and `ProposalEnvelope` (the write side) are unchanged and strict.
- **`proposalActions.ts`:**
  - Confirm throws `ConflictError` (409) naming the kind, before any write.
  - Revise throws the same 409 when the stored envelope has an unknown kind. It uses `unknownStoredEntityKind`, so a malformed stored envelope does not newly block revise.
  - `assertValidEnvelopeForCard` handles an unknown current envelope before the exhaustive `switch`, so its `never` guard stays meaningful.
  - Card listing and reading never parsed the envelope, so they needed no change and return the card as stored.

**Tests**
- `proposalActions.test.ts` has a new "unknown stored entityKind" block with five cases:
  - The card is read with its envelope untouched.
  - Confirm returns 409, the card stays `proposed`, and nothing is written to `tasks`.
  - Revise returns 409 and the envelope is unchanged.
  - Writing an unknown kind through revise is still rejected.
  - A malformed envelope still throws on read.
- `publicSurface.test.ts` lists the new export.

**Notes for dependants**
- A new kind (#1975) must be added to `proposalEnvelopeSchema`, `assertValidProposalEnvelope` and the confirm mapping. Once it is known, `unknownStoredEntityKind` returns `null` for it.
- The unknown shape carries the discriminant `unknownKind: true`; narrow with `"unknownKind" in envelope`.
