# gh-1494 — Queue mailbox sync after message flag changes

Repository-Issue: gh-1494

## Delivered behavior

- The Emails update hook accepts a boolean read/flagged patch, records desired state, resolves the message's metadata, and queues its mailbox sync on the same transaction client. Missing metadata or a null mailbox is skipped.
- Provider observation writes retain the existing `skipMailDesiredStateRecording` early return. Patches without boolean flag values queue nothing.
- Moved the unchanged enqueue function and job-key function into `mailSyncEnqueue.ts`, with re-exports from `mailSyncJob.ts` preserving existing imports. This avoids a flag-hook import of the sync worker and its reconcile dependencies.
- The existing mailbox job key and retry policy are unchanged; multiple messages of one mailbox deduplicate onto one pending job.
