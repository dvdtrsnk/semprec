# gh-1475 — Normalize Whisper language codes

Repository-Issue: gh-1475
Implementation: `e7ddc31d` (completes the preserved partial implementation `4ea2994d`).

## Delivered behavior

- One shared `normalizeWhisperLanguage` maps Whisper names, aliases and recognized codes to ISO 639-1, trimming whitespace and ignoring case; unknown values become null.
- DeepInfra response parsing normalizes the detected language. Missing and null language values produce null; malformed non-string values remain rejected.
- The per-tenant cutover converts Transcripts `computed.language` and Files `computed.asr.language` through the existing computed writer, without announcing. Other ASR fields are preserved. It uses locked keyset pages of 100, with one transaction per page, and skips unchanged values.
- Registered after the transcript duration cutover. No schema migration or write-safety baseline change.
- Language-table edge cases: Whisper's historical `jw` is accepted and normalized to ISO `jv`; Cantonese uses Chinese's ISO 639-1 `zh`; Hawaiian has no ISO 639-1 representation and returns null rather than inventing a code. The single implementation lives in shared, as Task 3 specifies, rather than a duplicate gateway file.
