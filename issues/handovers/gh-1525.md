## Delivered behavior

- `database.<key>.searchPlaceholder` is in both locales of the owning catalog for the thirteen client-visible system databases from the issue table (ten in `seed/i18n`, books and movies in `library/i18n`, emails in `mail/i18n`). `collection.custom.searchPlaceholder` ("Hledat ve sbírce" / "Search collection") is in `seed/i18n`.
- `catalogResolution.ts`: `CatalogResolver` gained `getCatalogsForModuleId(moduleId)`; `resolveDatabaseSearchPlaceholder(dbKey, catalogs, locale)` resolves requested locale, then English, then `null` (a `null` key reads the generic entry); `resolveDatabasePlaceholderForRow(resolver, { key, system }, locale)` picks the right catalog for a row. A keyless system database resolves to `null`; a user-created database reads the generic sentence from the `systemDatabases` catalog. Both functions are exported from the `@semprec/data` barrel and the public-surface list.
- `DatabaseEnvelope` / `toDatabaseEnvelope(database, name, searchPlaceholder, metadata)` and `SchemaDatabaseProjection` carry `searchPlaceholder: string | null` additively. `resolvedDatabaseBody` and `generateSchemaProjection` fill it.
