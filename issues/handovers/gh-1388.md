# Handover for gh-1388

The shared agent base prompt now ends with a language sentence chosen from the user's locale.

- **Composition:** `createAgentSessionFactoryForRun` (`backend/services/semprec-agents/src/agentSessionComposition.ts`) reads `getTenantUserLocale(pool)` once per run, before the project guidance override. A typed map `LANGUAGE_INSTRUCTIONS` holds the `cs` and `en` sentences ("Answer and write all user-visible text in Czech." / "... in English."), appended to the base prompt with a newline. A `null` or unrecognized locale leaves the prompt unchanged. The guidance override is applied afterwards, so it stays last.
- **Scope:** both callers (`createAgentRunTask`, `createRunAgentForHeartbeats`) already run inside the run's tenant scope, the same ambient scope `getAgentRun(pool, ...)` relies on, so the read needs no extra `runInTenant`. `getTenantUserLocale` was already exported from `@semprec/data`.
- **Timing:** the prompt is fixed when the run's session factory is composed, so a locale change applies from the next run.
- **Tests:** `agentSessionComposition.unit.test.ts` mocks `getTenantUserLocale` and asserts the composed system prompt for `cs`, `en`, `null`, an unrecognized value (`de`), and that project guidance comes after the language sentence.
- **Not run:** the full `pnpm run verify`; only the touched unit test file, eslint, prettier and tsc ran.

Notes for dependants: #1738 can rely on the sentence being in the shared base prompt; chat composition does not need to repeat it.
