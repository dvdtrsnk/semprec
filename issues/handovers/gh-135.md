## Summary

Registers `heartbeat.list` and `heartbeat.history` as ungated `AgentTool`s on the schemaCore module manifest:

- **`heartbeat.list`** — returns a project's full heartbeat configuration (rule, assignment/purpose, enabled state, `last_fired_at`). Project scope is derived exclusively from the calling run's persisted `agent_run.project_item_id`, never from a tool argument.
- **`heartbeat.history`** — returns the last N (default 10, max 100) `agent_runs` records (status, timestamps, result) for one owned heartbeat. Unknown and cross-project `heartbeatId`s produce an identical not-found error via a single scoped `WHERE` clause, avoiding any information leak about heartbeat existence across projects.

`agent_runs.heartbeat_id` already existed and was already populated for both scheduled and `onItemEvent`-triggered runs, so no migration was needed.
