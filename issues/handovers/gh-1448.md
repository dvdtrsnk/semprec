# Handover for gh-1448

`agent_runs` now carries a retry chain: `retry_of_run_id` and `attempt`. Committed locally on `wf/gh-1448`; not pushed.

- **Migrations:** `0105_agent_run_retry_chain.sql` adds `retry_of_run_id uuid` and `attempt integer NOT NULL DEFAULT 1 CHECK (attempt >= 1)`, the composite key `(tenant_id, retry_of_run_id) -> agent_runs (tenant_id, id)` (`NOT VALID`) and `UNIQUE INDEX agent_runs_tenant_retry_of_run_id_uq (tenant_id, retry_of_run_id)`. `0106_validate_agent_run_retry_chain.sql` validates the key. The key is named `agent_runs_retry_of_run_id_fkey`, not `*_tenant_fkey`, because the tenancy catalog test pairs every `*_tenant_fkey` with a single-column twin (same reason as gh-1452); there is no single-column twin here.
- **Store:** `AgentRunRow` has `retryOfRunId` and `attempt`; `CreateAgentRunInput` has optional `retryOfRunId` (default null) and `attempt` (default 1). `createChainedAgentRun(client, input)` inserts with `ON CONFLICT (tenant_id, retry_of_run_id) DO NOTHING`, copies `actor_user_id` from the retried run in the same statement, returns the row or `null` if the run was already retried, and throws `NotFoundError` if the retried run does not exist in the tenant. `getRetrySuccessorId(client, runId)` returns the successor id or `null`.
- **ON CONFLICT check:** no other `INSERT ... ON CONFLICT` on `agent_runs` exists, so none is affected by the new unique index.
- **Tests:** `agentRunsStore.test.ts` (defaults, chained insert and repeat, concurrent chained inserts yield one row, missing retried run, successor lookup) and `tenantForeignKeys.test.ts` (a new reference entry: another tenant's run is refused with 23503 on a runtime-role pool). Also run: `tenancyCatalog`, tsc, eslint, prettier, migration numbering. The full verify was not run.
- **For dependants:** the caller sets `attempt` (nothing derives it from the retried run's attempt); `createChainedAgentRun` ignores no `CreateAgentRunInput` fields except `userId`. Treat a `null` result as "already retried" and read the winner with `getRetrySuccessorId`.
