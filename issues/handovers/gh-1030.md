**What changed**
- **Provenance:** `AuthenticatedActor` has `restSession?: true`, which only `restActor` sets. `createItem` and `patchItem` pass `humanWriterUserId` to the choke point only when `restSession === true` and there is no `agentProjectItemId`. - **Policy:** the new `tenantAllowsStdio(client, userId?)` in `mcp/stdioTransportPolicy.ts` runs the `EXISTS` query from the issue.
- **Hook rule:** both MCP server hooks refuse a `stdio` config unless the writer is a human admin of the current tenant. They throw `ValidationError` with `{ field: "connectionConfig" }` and the single message "A stdio MCP server can only be configured by an administrator", for every refusal.
- **Proposals:** proposal validation rejects `transport: "stdio"` before its other checks. `assertNoCredentialShapedEnvKeys` stays.
- **ADR:** `docs/adr/2026-10-16-stdio-mcp-confined-to-admin-tenants.md`.

**REST message check:** the REST error body is `{ error: { code, details } }` with no message. The test therefore checks that the REST refusals have the same code and details, and checks the exact message only on the gateway and `/mcp` paths.
