## What was delivered

- Projects seed a user-owned `multi_select` property `tags` with no shipped options (en "Tags", cs "Štítky"), listed
  in the Projects `searchFields` and in the `project` editor schema.
- The module manifest database descriptor has an optional `facetBarProperty`; Projects declares `tags`.
  `GET /api/schema` publishes it per database only when it names a `select` or `multi_select` property of that
  database; any other declaration fails the request with 500.

## Contracts dependents build on

- Tags are added with `POST /api/properties/:id/options` and set as an array of option keys; unknown keys are 400.
- A selection of several tags is `{type: "in", property: "tags", value: [...]}` (overlap).
