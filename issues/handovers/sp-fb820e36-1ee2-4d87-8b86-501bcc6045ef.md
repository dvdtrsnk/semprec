# Handover: answer 400 when the caller's code is a substring of the provider's error token while completing a mailbox sign-in

Delivered on chain `e1-246-mail-oauth`, candidate commit `765cf3b6d1f2ccda9b0ba8439fa33d2f72dc66e9`, landed by a `--no-ff` merge on `feature/backend-parallel` as the third chain of a train with `e1-236-mail-sync` and `e1-243-blob-writer`.

**What changed.** `MailAuthorizationCodeRejectedError` (`backend/packages/data/src/mail/providerTypes.ts`) takes a third constructor parameter `grantRefused` (boolean). `exchangeAuthorizationCode` (`mail/oauthTokenExchange.ts`) computes it as `providerCode === "invalid_grant"` before the redaction and passes it; the redaction of `providerError` and the message text are unchanged. The complete route handler (`mail/mailOauthRouteHandlers.ts`) answers 400 `validation_failed` with field `code` when `error instanceof MailAuthorizationCodeRejectedError && error.grantRefused`, and no longer reads `providerError`. So a caller whose submitted code, verifier or client secret happens to be a substring of the provider's error token no longer turns a refused grant into a generic 500.

**Contracts dependents build on.** `MailAuthorizationCodeRejectedError.grantRefused`. A refused `invalid_grant` answers 400 `validation_failed` (field `code`), creates nothing and uses up the one-time state. `invalid_client`, an unknown error code and a non-JSON body still end as the unexpected error (generic 500 over HTTP). The Microsoft administrator-consent branch still runs first and throws `MailAdminConsentRequiredError`. `grantRefused` comes from the provider's code, which belongs to a fixed set, never from a submitted value, so it holds no secret. No route, table, migration, operation or job name changed.

**Files.** `backend/packages/data/src/mail/providerTypes.ts`, `backend/packages/data/src/mail/oauthTokenExchange.ts`, `backend/packages/data/src/mail/mailOauthRouteHandlers.ts`, `backend/packages/data/src/__tests__/oauthTokenExchange.test.ts`, `backend/packages/data/src/__tests__/mailOauthRoutes.test.ts`, `backend/services/alldots-api/src/__tests__/mailOauthHttp.test.ts`.
