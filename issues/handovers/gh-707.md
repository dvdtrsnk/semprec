## Summary

Implemented issue #707: each account the mail live-sync root hosts now beats its own `mailsync:<id>` process heartbeat.

**`mailLiveSyncRoot.ts`**
- `HostedEntry` gains a `heartbeat: ProcessHeartbeatHandle | null` field.
- In `reconcileOnce`, after a lifecycle's `start()` resolves successfully, `startProcessHeartbeat` is started for that account and stored on the entry; a lifecycle whose `start()` throws gets no heartbeat.
- `stopHosted` now calls `entry.heartbeat?.stop()` before `lifecycle.stop()`.
- `onLifecycleError`'s `phase` union gained `"heartbeat"`.
- Docstring updated.

**`processHeartbeats.ts`**
- `getActiveMailSyncProcessNames` now joins `mail_account_sync_state` against `items` and filters on `deleted_at IS NULL`, so a soft-deleted mailbox's stale sync-state row no longer keeps it in the expected set forever.
