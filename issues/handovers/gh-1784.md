  - One exception per night: `pg_advisory_xact_lock(hashtext('sleepNight:'||tenant||':'||night))`, then a lookup of another live item with the same night, on create and when a patch names `night`; 409 `duplicate_item`, field `night`. A trashed exception does not count.
