## Tests

New `patchView adoption` block in `__tests__/views.test.ts`:
- A user patching an agent's view gets back a row with `createdBy: "user"`, `creatorProjectItemId: null`, and the new `name` and `config`. Reading the view again gives the same row.

- When an agent's patch that sets `isDefault` is rejected (`ForbiddenError`), the view reads back unchanged.
- When a user's patch is rejected after adoption has run (`ConflictError` on a second default view), the adoption is rolled back and the view reads back unchanged.
