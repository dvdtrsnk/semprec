Repository-Issue: gh-1088

## Delivered behavior

- **Adapter** (`web/src/api/invitationOperations.ts`): `createInvitationOperations({ baseUrl, fetchImpl? })` and `acceptInvitation({ token, password })`. It posts JSON to `/api/invitations/accept` with `credentials: "same-origin"`, through the plain `fetch`, with no bearer header. A 200 `{ user }` resolves to `{ email }`. A 404 is `unavailable`. Any other non-2xx is `retryable` and carries the status; its message is the body's `error` string, or `Request to /invitations/accept failed with <status>` when the body has none. A transport failure or a malformed success body is `retryable`.
- **Route** (`web/src/main.tsx`): `?page=invite#token=<token>` builds `invite = { token, operations }`. The token is read from the fragment exactly as the password-reset token is, and an empty `#token=` becomes `null`. The composition-root doc comment documents the URL.
- **App** (`web/src/App.tsx`): `InviteRoute` and an `invite?` prop. The page renders outside `SessionGate`, and the session bootstrap is skipped, so `getSession` is never called and no header is shown.
- **Page** (`web/src/views/invite/InvitationAcceptPage.tsx`):
  - On mount it clears the fragment with `history.replaceState`, which adds no history entry. It keeps the `token` prop and never re-reads the URL.
  - A `null` token shows the invalid-link message at once, with no request and no form.
  - A form with one password field and a submit button. Both are disabled while the request is pending.
  - Success shows the new account's email and a link to `?page=login`.
  - `unavailable` (404) replaces the form with the single invalid-link message, with no retry.
  - `retryable` keeps the form enabled and shows the message in a `role="alert"` element.
- **Styles**: `web/src/views/invite/invite.css`, a copy of the setup wizard's layout.
- **i18n**: `invite.title`, `invite.password`, `invite.submit`, `invite.submitting`, `invite.success`, `invite.success.login` and `invite.invalid` in `en` and `cs` (`web/src/i18n/messages.ts`).
