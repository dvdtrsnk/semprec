# Handover: answer the Graph mail webhook's validation handshake as the calendar webhook does

Commit on `fix/followup-mail-edges`: `4f0f7b529`. Nothing was run against a real server.

**Root cause.** `graphWebhookHandler.ts` wrote its own handshake answer: any token length, no `X-Content-Type-Options: nosniff`. The calendar receiver bounded the token and set `nosniff`.

**Changes.**
- `graphNotificationBatch.ts`: `answerGraphValidationHandshake` (400 over 1024 characters; otherwise 200 `text/plain; charset=utf-8`, `no-store`, `nosniff`, the literal token), used by both Graph receivers after the throttle and before the body is read.
- `docs/architecture/tenancy-and-security.md`: public throttles; the handover of sp-8acebdc7-a9eb-4f52-8d7a-7b47f95680fc no longer lists this as left.

**Tests** (`__tests__/graphWebhookHandler.test.ts`): "echoes the validation token back as plain text within three seconds" now asserts the exact Content-Type and `nosniff`; "refuses a validation token over 1024 characters with 400 and echoes one of exactly 1024". Both fail before the fix; the calendar handshake test stays green.

**Left.** Nothing.
