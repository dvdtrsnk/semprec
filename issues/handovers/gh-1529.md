## Delivered behavior

- Seeds Projects.pinnedOrder as a user-owned number with a null stored name. Adds Czech and English projection labels and increments the systemDatabases manifest to 1.3.0.
- Extends the registered Projects pre-write transform after the existing terminal-status rule. A resulting pin without an incoming or stored order receives the maximum numeric order among live pinned projects plus one, starting at one. A transaction-scoped advisory lock keyed by the database id serializes automatic allocation through the write commit.
- Keeps explicitly supplied orders on pinned projects, including null. Keeps existing stored orders when omitted from a patch. Clears the order to null when the resulting pin is false, null or absent, including automatic terminal-status unpinning. Re-pinning then allocates the last position.
- Adds and registers a tenant-scoped cutover through the maintained-tenant runner, including suspended tenants. It inserts only a missing schema property under the exclusive properties lock, then locks and numbers only live pinned rows without an order by Czech title and id. Item values use migrateItemPropertyWithClient. Existing values and other schema entries are preserved; an unchanged second run performs no writes.
