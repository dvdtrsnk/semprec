## Entry points and contracts dependents build on

- Processing proposals: `kind` option `mailThread`; relation property `sourceThread` (Processing proposals to Threads, `many_to_many`, `owner: system`, owner process the Processing proposals module). The tool that creates such cards is gh-2035 and is not part of this source.
- Confirm of a `mailThread` card answers 409 `conflict` (field `sourceThread`) for a Trash source and writes nothing; a card whose source thread was purged (no edge left) answers a validation error on `sourceThread`.
