# gh-1469 — Transcript duration and completion time

Repository-Issue: gh-1469
Implementation commit: `1f66bb6d`.

## Delivered behavior

- Registers `durationSeconds` and `finalizedAt` as Transcripts computed keys and exports their constants.
- Prepare writes duration through `writeComputedAndAnnounce` in the Files checkpoint transaction. Existing prepare checkpoints skip the step unchanged.
- Finalize writes a UTC ISO timestamp through the same helper in its status transaction. The existing done guard preserves it on retry.
- Registers a per-tenant duration backfill after the transcripts catalog cutover. It reads source links with the existing parser, skips missing or malformed checkpoints and missing source files, and preserves existing duration values. Keyset pages of 100 use separate transactions and lock candidate transcript rows.
- Adds backfill integration coverage and extends pipeline integration assertions for values, invalidation and replay stability. Updates the public export expectation.

## Notes for dependants

The transcript cache now exposes duration as seconds and completion time as an ISO UTC string. Endpoint and list reads remain out of scope (#1576, #1636). Old completed transcripts receive only duration; historical completion times are not invented.
