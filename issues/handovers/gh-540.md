Closes #540

Relay pushes a head while a pull request is a draft and marks it ready right after. The `synchronize` (draft payload) and `ready_for_review` runs start in the same second and shared one concurrency group, so when the draft run started second it cancelled the real review and then skipped its own job, leaving the required `review` check `cancelled` (PR #534, twice in an hour, a fix round each time).

The group now ends in `-draft` or `-ready`: a draft run can no longer cancel a ready one, while a newer ready run still cancels an older ready run of the same pull request. `workflow_dispatch` has no pull_request payload and lands in the ready group.
