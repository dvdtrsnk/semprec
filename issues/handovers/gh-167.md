## Summary

Closes #167. Adds an `AsyncLocalStorage`-backed trace context (`packages/shared/src/traceContext.ts`) minted at every entry point:

- HTTP requests and WS upgrades in `semprec-api` (`app.ts`, `serve.ts`)
- Scheduler-fired and lifecycle-fired agent runs, binding `agentRunId` (`scheduler/actions.ts`, `lifecycleAdapter.ts`, `sempConversation.ts`)
- Every graphile-worker job, via a new zod-validated queue envelope (`{ traceId, payload }`): `enqueueJob` stamps the active trace server-side and `registerTask` restores or mints one before the handler runs, so a public job producer can never supply or omit it
- Mail-sync cycles bind `mailboxId` (`worker.ts`)

The trace id is forwarded to `semprec-ai-gateway` as `x-trace-id` (`httpAiGatewayClient.ts` → `completeHandler.ts`) and merged into every pino log record via a `mixin`, alongside `agentRunId`/`jobName`/`jobId`/`mailboxId` bindings where available.
