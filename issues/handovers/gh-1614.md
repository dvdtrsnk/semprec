# Handover for gh-1614

Page Markdown can now carry an item reference as the inline link `[Title](semprec://items/<uuid>)`. The link stays plain content (the `link` attribute of the text run); nothing here writes a relation edge.

**What changed**
- `shared/block-model/src/markdown.ts` (exported from the barrel): `collectItemLinks(blocks)` returns `{ ids, malformed }`: the distinct, lower-cased well-formed UUIDs of `semprec://items/` links in first-appearance order, and whether any such link had a non-UUID destination. Pure, no I/O.
- The existing parser and serializer already round-trip any link destination byte-identically, so no parsing change was needed; `semprec://page/<id>` handling is unchanged.
- `backend/packages/data/src/docs/assertItemLinksExist.ts`: `assertItemLinksExist(client, parsedBlocks, field)` reads `items` through a tenant-scoped client (row-level security hides other tenants) and throws `ValidationError` (400 `validation_failed`, `details.issues[0].path = field`). An unknown id, a soft-deleted item, a foreign-tenant id and a malformed id produce an identical error body that does not reveal which. It writes nothing.
- `shared/block-model/fixtures/markdown.json`: vector `item link round trip`.

**Tests**
- `shared/block-model/src/__tests__/markdown.test.ts`: fixture round trip (runs in both directions) and `collectItemLinks` cases. `pnpm --filter @semprec/block-model run test` in `backend/`.
- `backend/packages/data/src/__tests__/assertItemLinksExist.test.ts` (integration tier): live item accepted; unknown, foreign tenant, trashed and malformed ids give equal bodies; no `item_relations` row written.
- Only targeted checks were run (these tests, tsc of the data package, eslint, prettier); no full verify.

**Notes for dependants**
- No REST/MCP write path calls `parseMarkdown` yet. Whichever route persists parsed Markdown (#1608 consumers) must call `assertItemLinksExist(txClient, parsed, "<markdown field name>")` inside the request's tenant transaction, after `parseMarkdown` and before writing blocks.
- `field` is the caller's name for the Markdown body, so the error path matches the request.
- #2016 derives the Journal `events` relation from these links; use `collectItemLinks` to read them.
- Ids are compared lower-cased; a link with an upper-case UUID is accepted but is serialized back as written.
