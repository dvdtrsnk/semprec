## Changes
New `.github/scripts/review-followups/hints.mjs`, a zero-dependency ES module. Its header comment says what each hint means and when it is `null`.

- **`hintsApi(client)`** binds the four endpoints from #573's `github.mjs` to `client`. `computeHints` reaches GitHub only through this object, so tests pass a fake.
- **`computeHints(api, { pr, mergedAt, base, findings })`** returns a `Map` keyed `"<pr>:<key>"` holding `{ touchedAfterLastSeen, laterPrsTouchingPath }`.
  - **`touchedAfterLastSeen`** is `true` when a commit after `lastSeenSha` has the path among its files, under either name of a rename, and `false` otherwise.
  - It is `null` when:
    - `lastSeenSha` is `""`;
    - `lastSeenSha` is not in the pull request's commit list;
    - the list has 250 or more entries (GitHub's cap).
  - **`laterPrsTouchingPath`** is the number of distinct pull requests, excluding `pr`, found for the commits from `listCommitsTouchingPath({ branch: base, path, since: mergedAt })`.
  - **Caching:** within one call, each list is fetched at most once, however many findings share it.
  - **Errors:** any error from `api` rejects the call; no hint is guessed from a failed read.

The `touchedAfterLastSeen` scan stops at the first matching commit, so a commit after the match is never fetched rather than fetched once. That is why the header says "at most once".

## Tests
New `hints.test.mjs` uses `node:test`, `node:assert/strict` and a fake `api` that counts calls. It covers:

- **Acceptance criteria 1–2:** later commit touches the path, no later commit does, a rename away from the path, `lastSeenSha` is the last commit, and the three `null` cases.
- **Criteria 3–4:** distinct pull requests are counted once, `pr` is excluded, the count is 0 when nothing touched the path, and the arguments passed to `listCommitsTouchingPath`.
- **Criterion 5:** three findings on the same path cause exactly one call per list and one call per distinct commit.
- **Criterion 6:** an error from each of the four `api` functions rejects `computeHints` with that error.
- **`hintsApi`:** it passes calls through to a fake client.
