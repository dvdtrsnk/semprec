**What changed**

- **Page** (`web/src/views/account/AccountPage.tsx`): an export section (request, refresh, list with loading, error and empty states, download link only for `ready` rows) and a delete section (password field, wrong password is 403 and clears the field, `last_admin` has its own message, any other failure shows its message). The session stays on any refusal.
- **Wiring**: `?page=account` route in `main.tsx`, `AccountRoute` and `onAccountDeleted` in `App.tsx`, which sets the session to `ending` and so triggers the existing `window.location.replace("/")`. The header shows an `account.link` for every authenticated user.
- **i18n**: `account.*` keys in `en` and `cs`.
- **Tests**: adapter tests, page tests, and three new App tests (header link, route renders, reload after deletion).
