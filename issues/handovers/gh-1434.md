# gh-1434 implementation handover

Implementation commit: 9a45ffef. Frozen base: 033659a54a429febe74501a35fcce3ff912a99b7.

## Delivered behavior

- `backend/services/semprec-api/src/proposalComputation.ts`: `createProposalComputation({ pool, gateway })` returns a `ComputeSemprecProposalFn`. For a `database` entity kind it first reads the target database's property catalog (key, type, select option keys; relation, rollup and system-owned properties omitted because `assertValidProposalEnvelope` rejects them) in a short read transaction, then calls `gateway.complete` with operation `inbox_proposal`, the heartbeat's project item, temperature 0.2, a system instruction, one user message and a JSON Schema. The gateway call runs with no transaction open. The answer is validated with a zod schema (`target?`, `properties`, `reason?`, `confidence?` in 0..1); a mismatch throws, so the tick writes no card and the job fails and retries. Gateway errors propagate unchanged (failure recording is #1485).
- Item text is user data: sent in the user message between `<<<INBOX_ITEM_TEXT` and `INBOX_ITEM_TEXT>>>`, occurrences of either delimiter inside the text are removed, and the system message says to treat it as data only. The user message also carries type name and emoji, entity kind, `date` and `time`.
- `inboxTickAction.ts`: `ProposalComputationInput.projectItemId` (filled from `context.projectItemId`), `ProposalComputationResult.reason` and `confidence` (ignored by the tick until #1495).
- `actionRegistryComposition.ts`: builds the gateway client once with the new `createAiGatewayClientForApi()` (in `projectAgentGuidanceComposition.ts`; the only place reading `AI_GATEWAY_PORT` / `AI_GATEWAY_INTERNAL_TOKEN`) and registers `semprec.tick`. `createAgentGuidanceDriftActionForApi(pool, gateway, moduleRegistry?)` now takes the gateway as a parameter. The agents-runtime registry is unchanged and still lacks `semprec.tick`.
- `@semprec/data` now exports `listPropertiesByDatabase` (needed by the api service for the catalog read); `publicSurface.test.ts` updated. `semprec-api` gained the `zod` dependency (`backend/pnpm-lock.yaml` updated).
