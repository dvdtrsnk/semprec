## Delivered contract

`@semprec/shared` exports `AiGatewayTextBlock`, `AiGatewayImageBlock` and `AiGatewayContentBlock`. `AiGatewayMessage.content` accepts the existing string or an array of text/image blocks. The HTTP client already JSON-serializes its typed input; a new client test proves mixed blocks larger than 1 MiB reach its fetch request unchanged. Its 60-second deadline and 1 MiB response limit remain in effect.

The `/internal/complete` handler validates nonempty block arrays, text strings, JPEG/PNG MIME types, nonempty canonical standard base64, decoded image size <=1.5 MiB and <=4 images across the entire request. It buffers at most 8 MiB using the capped reader, then enforces the original 1 MiB limit when the validated request contains no image. The total JSON body limit includes base64 and envelope overhead.

Every currently accepted operation can carry images. The operation whitelist and attribution rules are unchanged. Anthropic maps images to `{type: 'image', source: {type: 'base64', media_type, data}}`, preserves block order and sends text blocks and string messages in their existing provider shapes. This is transport validation; the gateway does not open blob storage, decode image formats or perform extraction.

## Accounting and production wiring

The handler estimates input tokens as ceil((system + message text + serialized response schema characters)/4) + 1600 * imageCount. The existing output reservation remains 4096 tokens. Existing `@semprec/ai-gateway.complete` owns reservation/settlement/failure; final token and cost accounting uses the provider's reported usage. Validation and oversized bodies do not reserve or invoke a provider. Budget refusal and failed-provider accounting remain covered.

Production: `serve.ts` -> `createDispatcher` in `app.ts` -> `createCompleteRequestListener` -> existing gateway accounting -> configured structured provider (constructed by `startupConfig.ts`). No test-only production registration was added.

The widened public content union also required narrowing the text-only `FakeSummaryClient` in `semprec-transcribe/src/transcriptionTask.test.ts`; production transcription behavior is unchanged. This supporting test change fixes the TypeScript error caused by this contract addition.
