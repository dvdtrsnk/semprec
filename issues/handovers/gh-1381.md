# Handover for gh-1381

`POST /internal/complete` now accepts image content. Messages keep `content: string` or may carry an array of `{ type: "text", text }` and `{ type: "image", mimeType, data }` blocks. This is transport only; extraction (#1970) and new operations (#1392) are untouched. Targeted checks run: lint, format check, `pnpm -r run build`, `check:boundaries`, the affected unit tests and `completeHandler.test.ts` (44 passed). The full `pnpm run verify` was not run.

**What changed**
- **`packages/shared/src/aiGatewayClient.ts`:** exports `AiGatewayTextBlock`, `AiGatewayImageBlock` and `AiGatewayContentBlock`; `AiGatewayMessage.content` is `string | AiGatewayContentBlock[]`. The HTTP client serialises the input as is, so it needed no code change (timeouts and response caps are unchanged).
- **`completeHandler.ts`:**
  - Blocks are validated: `type`, string `text`, `mimeType` of `image/jpeg` or `image/png`, strict base64 `data` of at most 1.5 MiB decoded, at most 4 images per request across all messages. Failures are 400 `validation_failed` before any reservation.
  - The body is read with the existing capped reader up to 8 MiB; a body above 1 MiB with no image block in `messages` is then answered 413, so text-only requests keep the 1 MiB limit and anything above 8 MiB is 413.
  - `estimatedInputTokens` adds 1600 tokens per image to the text estimate (image data is not counted as text).
- **`structuredProviders/types.ts` and `anthropicProvider.ts`:** `StructuredCompletionMessage.content` follows the shared type. A string message is sent exactly as before; blocks map to Anthropic `text` and `image` (`source.type: "base64"`) blocks.

**Tests**
- `completeHandler.test.ts` (new "image content blocks" group): text plus image dispatch with real usage recorded; string message unchanged; fifth image, `image/gif`, bad base64, empty image, unknown block, image over the limit all 400 with no audit row; exact 1.5 MiB accepted; 9 MiB 413; text-only above 1 MiB 413; 2 MiB body with an image accepted; the reserved row's cost grows by 1600 tokens per image.
- `anthropicProvider.unit.test.ts` covers the provider mapping, `httpAiGatewayClient.unit.test.ts` covers block serialisation.
- `semprec-transcribe`'s `transcriptionTask.test.ts` fake client was narrowed to the string form because the type widened.

**Notes for dependants**
- The budget check (`assertWithinBudget`) compares existing spend with the caps; the new estimate is stored as the reserved row's `cost_usd` and counts against later calls, it does not reject its own call.
- Any operation may send images; the operation list is unchanged.
- The caller must send a reduced JPEG or PNG (base64); the gateway never reads the blob store.
