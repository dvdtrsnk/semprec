## What was delivered

- `GET /api/mail/mailboxes/:id/folders` (mail module custom route `mailFolderList`, justification `single-consumer-read`), implemented in `backend/packages/data/src/mail/mailFolderList.ts`. It answers 200 with a bare array of `{ id, name, specialPurpose, behavior, unreadCount, totalCount }`.
- Which folders: the non-deleted Folders items related to the mailbox through `Folders.mailbox`. A folder whose `specialPurpose` is `all` is not listed.
- Order: the system folders `inbox`, `sent`, `drafts`, `archive`, `junk`, `trash` in that order, then every other folder by name as the caller's locale collates it (`Intl.Collator`), ties by id.
- Names: a system folder is named by the catalog key `mail.folder.<specialPurpose>` in the locale `toManifestLocale(users.locale)` gives, Czech or English; any other locale reads English. Every other folder keeps `Folders.name`.
- Counts: `unreadCount` is the number of unread threads with a copy in the folder, counted over the thread list's own `copies` and `copy_stats` with the list's `unread` predicate and its folder predicate, so it equals the number of threads `GET /api/mail/threads?folderId=<id>&unread=true` returns. `totalCount` is the number of non-deleted Emails items linked to the folder, drafts included.
- The mailbox lookup and one counting statement run in one repeatable-read transaction: three queries per request, whatever the number of folders.
- `:id` is validated as a UUID. A malformed id, an unknown, deleted or foreign mailbox and a tenant without a Mailboxes database answer the same 404 `not_found` ("Mailbox not found").
- Six catalog keys in `mail/i18n/cs.json` and `mail/i18n/en.json`: `mail.folder.inbox` ("Doručená pošta" / "Inbox"), `mail.folder.sent` ("Odeslané" / "Sent"), `mail.folder.drafts` ("Koncepty" / "Drafts"), `mail.folder.archive` ("Archiv" / "Archive"), `mail.folder.junk` ("Nevyžádaná pošta" / "Junk") and `mail.folder.trash` ("Koš" / "Trash").

## Deviations from the specification and spec seams

1. The route entry is in the slice `routeMatrix/mail.ts`, not in `routeMatrix.ts`, which concatenates the slices.
2. File beyond the issue's `Touches`: `mail/mailThreadPredicates.ts`. The list's `inFolder` predicate takes a bind parameter, which cannot name a different folder per row, so counting every folder in one statement needs the same predicate for a folder row.
3. `chokePointWriteBoundary.unit.test.ts` and `publicSurface.test.ts` carry the new entries; the issue's `Touches` does not list them.
4. The Task says to validate `:id` as a UUID and does not name the status of a malformed id. It answers 404 `not_found`, as the mailbox detail and removal-impact routes of the same path family do.
5. "Alphabetically" is implemented as the collation of the caller's locale (`cs` or `en`), not code-unit order.
6. `unreadCount` reads every copy of a thread in the tenant, as the thread list does.
7. No owner probe was added to `ownerProbes()`: the isolation case seeds its own mailboxes and contains its own positive control.
