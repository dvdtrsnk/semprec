# Handover: show why the server refused a draft, a send or a thread action in the mobile mail screens

Commits on `feat/internet-accounts`: `ff4379fab` (shared), `353db712a` (Apple). Android has no mail screens and is unchanged.

**Changes.**
- `:shared:core` `MailRefusal`: one case per refusal code (17). `:shared:domain` `MailOutcome<T>` (`Done` / `Refused`); `MailDraftRepository.create`, `createPrefilled`, `update`, `send` and `MailRepository.setRead`, `setFlagged`, `archive`, `trash`, `restore` answer `RepositoryResult<MailOutcome<T>>`.
- `:shared:data`: `ApiErrorCode.kt` holds the error-code decoder moved out of `HttpMailboxRepository` (nested `error.code` or a flat `code`); `MailRefusalCodes.kt` maps `mail_drafts_folder_missing`, `mail_sent_folder_missing`, `mail_archive_folder_missing`, `mail_trash_folder_missing`, `mail_inbox_folder_missing`, `mail_reauthorization_required`, `mail_disabled`, `mail_recipient_rejected`, `mail_auth_failed`, `mail_server_unreachable`, `mail_attachment_too_large`, `mail_draft_already_sent`, `mail_draft_not_editable`, `mail_thread_no_received_message`, `mail_move_source_unverified`, `mail_thread_already_trashed`, `mail_thread_not_archived_or_trashed`. An unknown code or an unreadable body stays its `FailureKind`.
- `:shared:presentation`: `MailWrite` / `mailWrite` flatten an answer for a ViewModel. `MailComposeState.refusal` (a reply whose draft could not be made) and `sendRefusal`, `MailThreadState.sendRefusal` and `actionRefusal` (flag, move), `MailThreadsState.actionRefusal` (read mark). A refusal sets `REJECTED` as the failure next to it; a new send, a retry, a dismissal or a failure without a reason clears it.
- Apple: CoreKit `MailRefusal` and the three bridges; the Mail feature's `MailRefusal.message` (`mail.refusal.*`, en and cs, listed in the policy) is said instead of the generic text in the compose error, both send failures and the thread and list alerts.

**Deviation from the spec.** The Task named a presentation enum `MailRefusalReason` mirroring a domain `MailRefusal`. The enum lives in `:shared:core` instead, as the shared vocabularies (`FailureKind`, `AccountEnums`, `SearchVocabulary`) do; it is exported through core, and a 17-case mirror mapping would exceed detekt's `CyclomaticComplexMethod`. For the same SwiftLint limit the CoreKit mapping is a computed property `SharedSDK.MailRefusal.refusal` rather than an `init(_:)`; it stays an exhaustive switch.
