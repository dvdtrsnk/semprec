- `__tests__/agentRunsActorUserIdCutoverMigration.test.ts` (new), three integration cases:
  - each root run gets its own tenant's user, even though tenant zero's user is the earliest account;
  - a run whose tenant has no user throws, and neither tenant's rows change;
  - an already-`NOT NULL` column makes the cutover a no-op.
  - The column is made nullable for each case and restored to `NOT NULL` in `finally`, after the case's rows are deleted.
