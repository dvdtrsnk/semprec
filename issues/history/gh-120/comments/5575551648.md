## Summary

Implements issue #120: enforces the daily/monthly AI budget caps and adds the pi-provider routing seam.

- **Settings**: `dailyBudgetUsd` (default 50) and nullable `monthlyBudgetUsd` (default unlimited) added as System settings — seeded for fresh installs (`seedSystem.ts`) and backfilled idempotently for existing installs via a new migration (`0019_settings_ai_budgets.sql`). An explicit `null` is honored as "uncapped" and distinguished from a missing/unseeded property.
- **Budget check**: before every `complete`/`embed`/`transcribe`/`diarize` gateway call, the calendar-day and calendar-month spend is computed from `ai_gateway_calls` in one query and the call is rejected with `BudgetExceededError` once either non-null cap is already reached; a null cap never blocks, and the two caps are enforced independently.
- **Failure propagation**: the rejection is a plain thrown `Error`, so it flows through the existing `agent_run` → `status='error'` handling with no new plumbing; calls made outside a run never touch `agent_runs`.
- **Pi routing**: added `registerPiProviders` in `agent-runtime`, a seam to register the gateway's `baseUrl` for pi's `anthropic`/`openai` providers exactly once at startup. Since the `services/semprec-agents` composition root doesn't exist yet in this codebase (confirmed by inspection — it's a future issue's deliverable, same situation as `startupRepair.ts`'s `repairInterruptedRuns`), this ships as a documented, tested seam awaiting that real caller.
