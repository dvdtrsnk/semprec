Rejecting this follow-up after a spec audit against `origin/develop`:

- The problem it describes does not occur. When the test that uses the pool is filtered out, the pool is never created and `afterAll` has nothing to end, which is the correct behaviour.
- The Task cannot be implemented as written. Declaring `let pool: Pool | undefined` and assigning it in `beforeAll` makes `createChokePoint(pool)` inside `it()` fail with TS2345 (checked with `tsc`). Test files are compiled by `pnpm -r run build` (`include: ["src"]`), so "change nothing else" cannot hold.

Closing retires this finding, as described in `.github/ISSUE_FORMAT.md`.
