- **`registry.ts`** — `ModuleRegistry.loadModule(path)` uses an explicit known-path dynamic `import`, validates the manifest's structural shape, verifies every named `handlerExport`/`payloadSchemaExport` actually exists on the imported module, and rejects duplicate module ids/names or duplicate database keys/agent-tool/task/worker names across modules — all failing synchronously so a bad module blocks startup loudly.
