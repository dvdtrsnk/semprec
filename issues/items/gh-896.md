## Context

Review follow-up from harvest issue #889. PR #466 (finding 5a239bcb70), `backend/packages/data/src/transcription/transcriptEventMatch.ts:170`: the card's history entry is built with the template `${candidates.length} Events matched the recording's time window, so none was linked; proposed a new Event.` It renders "1 Events matched ..." when exactly one candidate was found but was already linked to another transcript, a grammatical error in a user-visible history string.

## Task

In `transcriptEventMatch.ts`, make the history entry say "1 Event matched the recording's time window, so none was linked; proposed a new Event." when `candidates.length === 1`, keeping the existing wording for other counts. In `backend/packages/data/src/transcription/__tests__/transcriptEventMatch.test.ts`, the existing test "proposes a card rather than a second edge when the one candidate is already linked to another transcript" gains an assertion on the stored history text (the singular wording), and the existing test "creates a card and no edge when several Events match" gains an assertion on its stored history text ("2 Events matched the recording's time window, so none was linked; proposed a new Event.").

## Touches

- backend/packages/data/src/transcription/transcriptEventMatch.ts (the history entry text only)
- backend/packages/data/src/transcription/__tests__/transcriptEventMatch.test.ts (the two tests named above, one added assertion each)

## Scope

### In scope

The singular wording and the two added history-text assertions.

### Out of scope

Localizing the string, and any other history entry.

## Acceptance criteria

- With exactly one candidate that is already linked to another transcript, the card's history entry reads "1 Event matched the recording's time window, so none was linked; proposed a new Event."
- With several candidates the entry still reads "<n> Events matched the recording's time window, so none was linked; proposed a new Event." with the real count, asserted in "creates a card and no edge when several Events match" (2 candidates), and the existing tests in the file pass.
