## Context

`backend/packages/data/src/__tests__/queueConcurrency.test.ts` (issue #705) failed on `develop` in CI run 36830666135 (`integration-shard (1)`, 2026-10-01): `expected 1790840083688 to be less than 1790840083686` at the assertion that the two unaffinitized probe jobs overlap.

The test proves concurrency from wall-clock timing: every probe sleeps 300 ms, and the second unaffinitized run must start before the first one ends. That only holds when graphile-worker picks the second job up within 300 ms of the first, which graphile-worker does not promise. A `jobs:insert` notification only nudges a worker that is idle at that moment (`worker.nudge()` returns `false` for a worker mid-`getJob`, or before the LISTEN client has connected right after `runWorker` resolves), and a job no idle worker was nudged for waits for a freed worker or the next 2 s poll.

The failing run's graphile log shows exactly that. Only two of the four workers ran jobs. Task 1 (tick) completed at 07:34:43.358; tasks 2 (tick) and 3 (unaffinitized) both started right after it, about 30 ms later; task 4 (the second unaffinitized job) ran after task 3 on the same worker. The production behaviour #705 asks for (up to 4 unaffinitized jobs at once) was not broken. The test measured pickup latency instead.

The integration tier's split into three shards (#657) is not a factor: the file runs alone in its own vitest worker process against its shard's database, as it did before the split.

## Task

- Rewrite the unaffinitized half of the test so the overlap is proven directly rather than inferred from timestamps. Each unaffinitized probe stays in flight until both unaffinitized probes have started, bounded by a wait well above graphile-worker's 2 s `pollInterval`, and records whether the other one started before it stopped waiting. The test asserts both did.
- The serialized case must still fail: with `concurrency: 1` the first probe gives up waiting before the second starts, and the assertion fails.
- Keep the semprec-tick half (second tick run starts no earlier than the first one ended) unchanged.
