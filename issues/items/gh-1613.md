**Blocked by:** #1537, #1608
**Model tier:** low

## Context

Model tier rationale: Fills existing nullable fields by calling an already-delivered serializer in one place, with an existing response shape and tests.

#1537 returns the period read with `markdown: null` on the period, on the day's `week` and on every entry of a month's `weeks`. A read-only view of a week's note (the expanded week row of a month, the week block of a day) needs the page's text, but the item envelope carries no content and the client should not have to open a collaborative document for a read-only rendering.

#1608 adds the serializer that turns a page into canonical Markdown (whole page, without the title).

Decision: `markdown` is `null` when the period has no entry or no page, and an empty string `""` when the page exists and is empty. Nothing is created by the read.

## Task

Load `testing`.

1. In the period read handler, for the period itself, the day's `week` and each month `weeks[]` entry that has a `docId`, load the page and serialize it with the #1608 serializer, then set `markdown`.
2. Load pages for all weeks of a month in one batch, not one at a time.
3. Do not create any doc; absent doc means `markdown: null`.
4. Tests: an existing week with text returns its Markdown; an existing empty doc returns `""`; an absent entry returns `null`; the response shape is otherwise unchanged; no write happens.

## Touches

- backend/packages/data/src/journal/journalRouteHandlers.ts (fill `markdown`)
- backend/packages/data/src/docs/docsStore.ts (batch read of docs for a list of item ids, only if none exists)
- backend/packages/data/src/journal/__tests__/ (markdown tests)

## Scope

### In scope

- Populating the `markdown` fields of the period read from the page serializer.

### Out of scope

- The serializer itself; #1608.
- Writing a page from Markdown; #1765 and #1679.
- Any change to the period read's other fields; #1537.

## Acceptance criteria

- When a week page has text, then the day's `week.markdown` and the month's matching `weeks[].markdown` contain that page as Markdown without a title.
- When the week entry exists with an empty page, then `markdown` is `""`.
- When the entry or page does not exist, then `markdown` is `null` and no row is created.
