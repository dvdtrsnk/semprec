## Context

Model tier rationale: One aggregation read added to an existing authorized endpoint, over an existing table and with an existing test fixture style, but it must get the failed/reserved/estimated semantics exactly right.

Every model call an agent run makes is recorded in `ai_gateway_calls` (`provider`, `model`, `input_tokens`, `output_tokens`, `audio_seconds`, `cost_usd`, `agent_run_id`, `status` `reserved|settled|failed`; migrations 0018, 0034, 0049; index `ai_gateway_calls_agent_run_idx`; store in `backend/packages/data/src/aiGateway/aiGatewayCallsStore.ts`). A `reserved` row holds the cost estimate with NULL tokens until the call settles; a `failed` row has `cost_usd` 0. Nothing aggregates these rows by run: `GET /api/agent-runs/:id` (`backend/services/semprec-api/src/agentRunHandler.ts`, backed by `getAgentRun`) returns the run without any spend.

This issue adds a `usage` object to that response so a run's cost and tokens per model can be shown. It builds on #1442 for model display names and on #1805, which extends the run detail response; `usage` is added next to those fields. #1744 later adds the message-scoped variant and #1889 and #1909 consume the aggregation.

Only the run's own calls are summed (`agent_run_id` equal to the run). Delegated sub-runs do not occur in production today, so they are not included until delegation is hosted (ADR `docs/adr/2026-09-10-no-speculative-generality-beyond-issue-scope.md`).

## Task

Load `testing`, `io-hardening` and `canonical-keys`.

1. Add `getAgentRunUsage(client, runId, locale)` in a new `backend/packages/data/src/aiGateway/agentRunUsage.ts`, exported from the data package barrel. It reads `ai_gateway_calls` where `agent_run_id = runId` and `status <> 'failed'`, grouped by `(provider, model)`, and returns:
   - `totalCostUsd`: the sum of `cost_usd` over the counted calls (a reserved call counts at its estimate);
   - `estimated`: true when any call of the run is `reserved`, otherwise false;
   - `perModel`: `[{provider, model, displayName, callCount, inputTokens, outputTokens, audioSeconds, costUsd}]`, ordered by `costUsd` descending then `model`. `displayName` comes from `resolveModelDisplayName` of #1442 with the caller's `users.locale`. `callCount` counts non-failed calls only. `inputTokens` and `outputTokens` are numbers (0 when every call is still reserved); `audioSeconds` is null unless the model's calls carry audio seconds.
   - A run without calls returns `{totalCostUsd: 0, estimated: false, perModel: []}`.
   - Decimal sums arrive from `pg` as strings; convert with `Number` as `aiUsageReport.ts` does.
2. In `agentRunHandler.ts`, add the result as `usage` to the `GET /api/agent-runs/:id` body, using `toManifestLocale(identity.user.locale)` for the locale. The change is additive; every existing field and the authorization are unchanged. The route already runs inside `runInTenant`, so a run of another tenant is not visible and still answers 404 exactly like an unknown id.
3. Tests: a data-package test `backend/packages/data/src/__tests__/agentRunUsage.test.ts` (two settled Sonnet calls aggregate to one `perModel` entry with the summed tokens and cost; a failed call changes neither `callCount` nor cost; a reserved call sets `estimated` true; two models give two entries; empty run) and an extension of `backend/services/semprec-api/src/__tests__/agentRunHandler.test.ts` (the response carries `usage`; a run of another tenant returns 404).

## Scope

### In scope

- The per-run aggregation and its additive `usage` field on `GET /api/agent-runs/:id`.

### Out of scope

- Scoping usage to one chat answer (`?messageId=`) and the per-message column: #1744 and #1889.
- Listing runs with their cost: #1909.
- Sub-runs created by delegation.
- The monthly or account-wide usage report: #1472.

## Acceptance criteria

- When a run has two settled Sonnet calls with 6180 input and 240 output tokens in total and cost 0.021, then `usage` is `perModel [{displayName "Claude Sonnet", callCount 2, inputTokens 6180, outputTokens 240, costUsd 0.021}]`, `totalCostUsd` 0.021, `estimated` false.
- When a call of the run is `failed`, then `callCount` and `costUsd` do not change.
- When a call of the run is `reserved`, then `estimated` is true.
- When the model id belongs to a new Sonnet version, then `displayName` is still "Claude Sonnet"; an unknown id is returned raw.
- When the run belongs to another tenant, then the response is 404, identical to an unknown id.
