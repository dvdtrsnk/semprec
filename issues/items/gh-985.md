## Context

Two crontab sweeps maintain block/canvas documents (`backend/packages/data/src/worker.ts:82-83`, handlers at `:143-148`).

`docCompactionSweep` runs every 5 minutes and calls `handleDocCompactionSweepTask` (`backend/packages/data/src/docs/docPersistence.ts:266-269`), which calls `runCompactionSweep` (`:243-264`). That sweep:
- selects `SELECT doc_id FROM doc_updates GROUP BY doc_id HAVING count(*) >= $1` with plain `pool.query` (`:248-251`);
- calls `loadDoc` per doc, each in its own `withTransaction` (`:126-133`);
- compacts each doc: upserts `doc_snapshots`, inserts a `doc_snapshot_history` checkpoint and deletes the compacted `doc_updates`;
- counts per-doc failures. `assertSweepNotFailedEntirely` (`backend/packages/data/src/docs/sweepOutcome.ts:14-21`) throws only when every attempted doc failed.

`docHistoryCleanup` runs daily at 03:15 and calls `handleDocHistoryCleanupTask` (`backend/packages/data/src/docs/docHistory.ts:166-170`). It does three things:
1. `runDocHistoryRetentionSweep` (`:134-152`): `SELECT id FROM docs`, then `rebaselineDocHistory` per doc in its own transaction (`:46`).
2. `cleanupExpiredDocHistory`: `DELETE FROM doc_snapshot_history WHERE expires_at < now()` (`:161-164`).
3. The same all-failed assertion.

Every table involved is tenant-owned: `docs`, `doc_updates`, `doc_snapshots`, `doc_snapshot_history`, `doc_history_updates`.

Tenancy state this issue builds on:
- Each tenant table carries `tenant_id` under a RESTRICTIVE RLS policy `tenant_isolation`: `tenant_id = (SELECT app_tenant_default())`.
- `app_tenant_default()` is `COALESCE(app_current_tenant(), app_sole_tenant())`. `app_current_tenant()` reads the transaction-local GUC `app.tenant_id`.
- `withTransaction`, autocommit `pool.query` and `pool.connect()` clients set that GUC from the ambient scope: `runInTenant(tenantId, fn)` sets the tenant and `runAsSystem(reason, fn)` sets `''` (`@semprec/shared`).
- In system scope, tenant rows are visible only while exactly one tenant exists. With two tenants, or after the strict switch (#1067), these sweeps would see no docs, and a compaction row written there would have no tenant.
- Both tasks are `tenancy: 'system'` crontab tasks, so the task runner calls them inside `runAsSystem`.
- #983 added `forEachActiveTenant` (`backend/packages/data/src/tenancy/forEachActiveTenant.ts`, exported from `@semprec/data`). Called from a system scope, it runs the callback inside `runInTenant(tenantId, …)` for each tenant with `status = 'active'`, starting at a rotating offset. A throwing tenant does not stop the others. After all tenants were attempted, the failures are rethrown as one `AggregateError`, so the job is retried.
- This issue calls it as `forEachActiveTenant(pool, async () => …)`. If the merged signature differs, use the merged one.

#1026 later authorizes doc sync per socket tenant in these same files.

## Acceptance criteria

All of these are integration tests (`*.test.ts`), with two tenants under the runtime role unless stated otherwise.
- **Per-tenant compaction.** Tenant zero and tenant B each hold one doc with at least 200 (the default threshold) `doc_updates` rows. One `docCompactionSweep` run compacts both docs: each doc is left with fewer than 200 updates, and each doc's new `doc_snapshots` and `doc_snapshot_history` rows carry that doc's own `tenant_id`.
- **Failure isolation.** Tenant B's only over-threshold doc has a corrupted update row, so all of B's attempted docs fail. Tenant zero's over-threshold doc is still compacted and committed, and the handler rejects so the job is retried.
- **Per-tenant history cleanup.** Tenant zero and tenant B each hold an expired checkpoint (`expires_at` in the past) and a NULL-expiry baseline. One `docHistoryCleanup` run deletes both expired checkpoints and keeps both baselines. Every re-baseline checkpoint it writes carries its doc's `tenant_id`.
- **Inactive tenant.** An over-threshold doc of a tenant whose `status` is `suspended` is not compacted.
- **Single tenant unchanged.** With only tenant zero, the existing `docs.test.ts` cases pass.
