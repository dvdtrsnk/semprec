## Context

Review follow-up from harvest issue #889. PR #469 (finding ed2125d67c), `backend/packages/data/src/chokePoint/relationOps.ts:77`: `loadCreatableRelationEdgeContext` declares its `input` parameter as `DeleteRelationInput`, but it performs the pre-flight checks of a create and is called by `createRelationWithClient` and `assertRelationCreatableWithClient`, both of which take `CreateRelationInput`. `DeleteRelationInput` is `Omit<CreateRelationInput, "metadata">`, so the code compiles today only because the narrower type happens to be assignable.
