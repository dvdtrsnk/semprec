## Context

Fast mailbox processing requires row actions, bulk operations, flags, and keyboard navigation beyond the view shell.

## Task

Add row-hover archive, delete, and mark-read/unread actions; bulk selection with the same operations; `j`/`k` movement; and `e` archive. Persist `read` and `flagged` as user-owned generic properties mapped to IMAP `\\Seen` and `\\Flagged`. Missing legacy booleans display as false. Use the generic relation/property mutation path and preserve selection/focus predictably after mutations.

## Scope

### In scope

- Hover actions, bulk selection, keyboard controls, focus, read state, and flag state.

### Out of scope

- Structured search operator parsing, compose/reply, and provider live-sync mechanisms.

## Acceptance criteria

- Pointer and keyboard users can perform the same triage actions.
- Bulk operations affect only selected messages and report partial failures.
- Read/flag changes persist generically and synchronize to the canonical IMAP flags.
- Keyboard shortcuts do not fire while typing in an editable control.
