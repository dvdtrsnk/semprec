**Model tier:** low

## Context

Model tier rationale: One read-only tool that calls an existing function and follows the declared agent-tool shape, with no new lifecycle, authorization or persisted-data contract.

The assistant (Semp) should be able to answer "how much have I spent this month" with the same numbers the Finance overview shows. #1585 builds `getFinanceSummary` and the REST route. The module manifest (`backend/packages/data/src/finance/financeModuleManifest.ts`, from #1353) has an empty `agentTools` list; `ModuleRegistry.getAgentTools` (`backend/packages/module-registry/src/registry.ts`) lists a module's tools filtered by granted capabilities, but today nothing puts module tools into a running assistant session. #1523 composes module agent tools into sessions; until it lands the tool is declared and tested but not reachable by Semp, which is intended.

Decision: the tool is a read and needs no capability beyond what the assistant already holds for reading data, so `capability` is `core.item.read`. Reason: an ungranted tool is absent, so tying it to the existing read capability keeps it off for agents that cannot read items.
Decision: the tool takes the same optional `month` input and returns exactly the REST body.


Shared-file ordering: this issue also waits for #1642 because both edit the same files listed in Touches.

## Task

Load `testing`.

1. Declare in `financeModuleManifest.ts` one agent tool `finance.summary` with `handlerExport: "createFinanceSummaryTool"` and `capability: "core.item.read"`.
2. Add `backend/packages/data/src/finance/financeSummaryTool.ts` exporting `createFinanceSummaryTool`, following the handler shape that `ModuleRegistry` resolves for agent tools. It validates an optional `month` (`YYYY-MM`) and returns the result of `getFinanceSummary` unchanged.
3. Export it from the data package barrel.
4. Tests: the tool is listed for a granted `core.item.read` and absent without it; it returns the same numbers as the REST route for the same data and month; a malformed month is rejected with the same validation error.
