## Context

This issue establishes the first implementation slice of the `observability` batch; #167 builds on it.

## Task

Create a shared `pino` logger in `backend/packages/shared` and wire named root loggers into API, agents, transcribe, AI gateway, and per-mailbox mail-sync. Emit JSON to stdout only. Enforce identity-not-content logging: identifiers may be logged; property values, mail bodies, tool arguments, and decrypted credentials may not. Redact password/token paths and authorization headers. Define info/warn/error semantics and default-off debug controlled by `LOG_LEVEL`. Install shared uncaught-exception and unhandled-rejection handlers that emit one fatal record and exit non-zero.

## Scope

### In scope

- Task deliverables, migrations, integration, automated tests, and necessary documentation.

### Out of scope

- Journald unit configuration is later.
- No Sentry, aggregator, private log files, or logrotate.

## Acceptance criteria

- All five process types use the shared named logger.
- Secret paths are redacted and representative content is absent in tests.
- LOG_LEVEL takes effect after restart without rebuild.
- Unexpected uncaught failures log fatally and terminate.
