Observe a loser rejection as well as a resolution, preserving the original scenario failure if cleanup also fails; do not leave an unhandled rejection. Add a deterministic same-file regression for a failure between starting the loser and committing the winner, exercising the same cleanup path, with observations of loser settlement and client release order.
