## Context

Model tier rationale: A single-pass text change in the two system translation catalogs with no key, schema or stored-data change, verified by an existing catalog-resolution pattern.

Display labels of the system collections come from the translation catalogs, not from stored data: a property's or option's label is resolved at read time from `backend/packages/data/src/seed/i18n/cs.json` and `en.json` (ADR `docs/adr/2026-09-10-english-canonical-keys-with-i18n-labels.md`, resolved by `backend/packages/data/src/manifest/catalogResolution.ts`), while the canonical keys (for example the option key `monitoring`) never change. Several Czech and English labels differ from the wording the app uses, so the API shows one name and the app another. Examples today: the project relation to areas is labelled "Centrum" (English "Hub"), the project date "Datum"/"Date", the girlfriend option "Přítelkyně", the health-record status option `monitoring` "Sledování", the type option `condition` "Onemocnění", the subject property "Subjekt", the tag `dentalHygiene` "Zubní hygiena", the attachments property "Soubory", the event type option `event` "Akce", and the journal period property "Typ" with the option `quarter` "Čtvrtletí".

Saved filters and views refer to keys (`in status [monitoring]`), so changing the labels must not change how they evaluate. The catalog file `seed/i18n/cs.json` is also edited by other issues that add keys; those edit different keys and each of them waits for this one, so this issue is the single place that rewrites existing label values in it.

Decision: the project status option `archived` keeps its current label ("Archivováno" in Czech, "Archived" in English). The app shows "Archiv" in the collection and "Archivováno" in the project detail, and which one the catalog should carry is an open product question; changing it later is a one-line catalog edit.

Decision: English labels change only where the source asked for it (project area, project date, Companies and Health records on an area); no other English label is touched.
