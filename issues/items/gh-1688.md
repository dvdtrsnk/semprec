**Model tier:** medium

## Context

Model tier rationale: A small aggregate read route that reuses the shared thread predicates and the mailbox sync state, with defined fixtures.

The Overview, the Profile and the mailbox sidebar show counts: unread inbox, flagged, Semp drafts, number of connected accounts and which accounts need a new sign-in. There is no count or summary route today. The counts are of threads, and must equal what the list shows with the same filters, so they use the predicates of #1633. Account sign-in state is `Mailboxes.syncStatus` (`needsReauthorization` option, `seed/seedEmailModule.ts`).

The Semp draft count depends on a predicate that does not exist yet (#1694 delivers it and adds it to this response); until then the field is 0. The account summary (#1903) and the overview summary (#1837) consume this route.

Shared-file ordering: this issue also waits for #1686 because both edit the same registry, manifest, cutover, route matrix or hook files listed in Touches.

## Task

Load `state-writes` and `testing`.

1. Implement `GET /api/mail/summary` in `backend/packages/data/src/mail/mailSummary.ts`, declared in `mailModuleManifest.ts` (`handlerExport` `createMailSummaryRouteHandler`, justification `single-consumer-read`) with a `routeMatrix.ts` entry (tenancy `tenant`).
2. Response `{ unreadInbox, flagged, sempDrafts, accounts, accountsNeedingReauth }`: `unreadInbox` is the number of threads matching the `inbox` and `unread` predicates; `flagged` the number matching `flagged`; `sempDrafts` is `0`; `accounts` the number of non-deleted Mailboxes; `accountsNeedingReauth` is `[{ id, name }]` for mailboxes whose `syncStatus` is `needsReauthorization`.
3. Add tests: `unreadInbox` equals the number of threads returned by `GET /api/mail/threads?unread=true`; flagged equals the count of `?box=flagged`; a mailbox needing re-authorization is listed; a deleted mailbox is not counted; another tenant's data is not counted.

## Acceptance criteria

- When there are unread inbox threads, then `unreadInbox` equals the length of the full `GET /api/mail/threads?unread=true` result.
- When an account needs a new sign-in, then it appears in `accountsNeedingReauth` with its id and name.
- `sempDrafts` is 0.
- Counts never include another tenant's mail.
