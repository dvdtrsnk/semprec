**Model tier:** medium

## Context

Model tier rationale: One route that wraps an existing streaming speech adapter with a size limit and returns text, without any agent or persistence; the accounting and budget behavior come from the adapter.

In the message field of a Semp chat the user can tap "Dictate": speech becomes text in the draft, with no agent turn and nothing sent. The ADR from #1372 chose the gateway, and #1396 added the streaming speech-to-text route (`/internal/stt/stream`, chunked budget reservations, audio never stored). The live voice channel of #1546 is not used here, because dictation must not create a thread, message or turn.

Decisions:
- Route: `POST /api/semp/dictation` taking one recorded clip (audio body in the encoding the ADR of #1371 defines for client audio, `Content-Type` naming it) and returning `{ text, language }`. The clip is fed to the gateway stream and the final transcript is returned; live partial results are not part of this issue.
- Limits: the clip must be at most 120 seconds and 8 MB; larger requests are rejected with 413 before the body is read in full.
- Language: Czech by default, an optional `language` field from a closed list.
- Nothing is stored: not the audio, not the text. Neither is logged.


Shared-file ordering: this issue also waits for #1626 because both edit the same files listed in Touches.

## Task

Load `ai-gateway`, `io-hardening`, `error-handling` and `testing`. Register the route in `routeMatrix.ts` and the tenant isolation test.

1. Add the route handler in `semprec-api`: authenticate the session, enforce size and content type, stream the body to the gateway speech-to-text client in chunks, wait for the final transcript and return it.
2. Map the gateway's `budget_exceeded` to the standard budget error response, provider errors and capacity refusal to the usual 502 and 503 responses, and a client disconnect to aborting the gateway stream.
3. Tests with a fake gateway client: a clip returns the transcript text; an oversize clip gives 413 with no gateway call; an unsupported content type gives 415; budget exhaustion gives the budget error; no thread, message or run row is created; a disconnect aborts the gateway stream; an unauthenticated request is refused.

## Scope

### In scope

- The dictation route with limits, error mapping and tests.

### Out of scope

- The gateway speech-to-text adapter: #1396.
- Live voice mode: #1546 and #1734.
- Reading messages aloud: #1626.
- Streaming partial results to the client during dictation.

## Acceptance criteria

- When a clip is posted, then the response contains the final transcript and nothing is sent as a message.
- When the clip exceeds the limits, then it is rejected before reaching the gateway.
- When the tenant's budget is exhausted, then the standard budget error is returned.
- After the call, no audio or text is stored or logged, and no thread, message or agent run exists for it.
