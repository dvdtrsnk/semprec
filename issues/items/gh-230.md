**Blocked by:** #119

## Context

Agent, transcription, diarization, and embedding costs require one complete enforcement point. The AI gateway is the single egress point for `complete()`, `embed()`, `transcribe()`, and `diarize()`, so it is the one place that sees every AI cost in the system. This part adds the accounting: the `ai_gateway_calls` table and a record for every call in its native unit. The sibling part #120 builds on these records to enforce the daily and monthly caps and to route pi's provider calls through the gateway; #121 reads the table for the utilization report.

## Task

- Add `ai_gateway_calls` as a numbered structural migration applied by the runner from #224:
  ```sql
  CREATE TABLE ai_gateway_calls (
    id bigserial PRIMARY KEY,
    at timestamptz NOT NULL DEFAULT now(),
    provider text NOT NULL,
    model text NOT NULL,
    input_tokens integer,           -- NULL = this call has no token concept (diarize()/transcribe()); NOT the same as 0
    output_tokens integer,          -- same
    audio_seconds numeric,          -- NULL unless the call has audio input; native unit for diarize()/transcribe()
    cost_usd numeric NOT NULL,
    agent_run_id uuid REFERENCES agent_runs(id)   -- nullable, not every call originates inside a run (transcription, embeddings)
  );
  ```
- Record every `complete`, `embed`, `transcribe`, and `diarize` call in the gateway using its native units: `complete()`/`embed()` always populate `input_tokens`/`output_tokens` and leave `audio_seconds` NULL; `transcribe()`/`diarize()` populate `audio_seconds` and leave both token columns NULL (NULL means "no token concept", which is a different fact from `0`). `cost_usd` is always non-null. `agent_run_id` is set when the call originates inside an agent run and NULL otherwise.

## Scope

### In scope

- The `ai_gateway_calls` DDL and native-unit accounting for all four gateway functions.

### Out of scope

- The budget settings, the spend query and rejection, pi provider `baseUrl` registration, and run failure propagation (#120).
- Per-project budgets and the read endpoint/graph (#121).

## Acceptance criteria

- No supported AI function called through the gateway bypasses accounting: each `complete`, `embed`, `transcribe`, and `diarize` call produces exactly one `ai_gateway_calls` row.
- Audio calls store null token counts, not zero, and token calls store null `audio_seconds`.
- A call made inside an agent run carries that run's id; a call made outside carries NULL.
