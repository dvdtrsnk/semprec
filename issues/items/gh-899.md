## Context

Review follow-ups from harvest issue #889, both in `backend/services/semprec-ai-gateway/src/structuredProviders/anthropicProvider.ts`:
- PR #755 (finding 649366f56a), line 204: `toolUse.input === undefined` does not catch `input: null`. The response schema field is `z.unknown().optional()`, so `{"type": "tool_use", "input": null}` passes the check and `null` is returned as `content` instead of a `ProviderCallError`.
- PR #755 (finding 6c11fb6be0), line 195: when `issue.path` is empty (the root value is not an object), `path` is `""` and the message `Anthropic response did not match the expected shape: ${path} ${issue?.message}` contains a double space.

## Task

1. Make the `tool_use` input check also reject `null`, throwing the same `ProviderCallError("Anthropic tool_use block carried no input")` as for `undefined`.
2. Build the shape-mismatch message so that an empty `path` yields `Anthropic response did not match the expected shape: <message>` with a single space, while a non-empty path keeps the current `<path> <message>` form.
Add one test per change to `backend/services/semprec-ai-gateway/src/structuredProviders/__tests__/anthropicProvider.unit.test.ts`, next to the existing test "throws ProviderCallError when the tool_use block carries no input".

## Touches

- backend/services/semprec-ai-gateway/src/structuredProviders/anthropicProvider.ts (the `tool_use` input check and the shape-mismatch message only)
- backend/services/semprec-ai-gateway/src/structuredProviders/__tests__/anthropicProvider.unit.test.ts (two new test cases)

## Scope

### In scope

The two changes and their tests.

### Out of scope

Other validation of the provider response and any change to the error class.

## Acceptance criteria

- A response whose `tool_use` block has `input: null` makes `complete` reject with a `ProviderCallError` whose message is "Anthropic tool_use block carried no input".
- A response whose root value fails the schema with an empty issue path makes `complete` reject with a `ProviderCallError` whose message contains no double space and ends with the issue message.
- A shape mismatch with a non-empty path keeps its `<path> <message>` form, and the existing tests in the file pass.
