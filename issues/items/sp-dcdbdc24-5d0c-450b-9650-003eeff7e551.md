## Context

Model tier rationale: Replaces a shared screen model and its Apple screens and moves the entry into the settings sheet.

Mobile shows "Mail accounts" from the Overview stack with iCloud/generic connect only. It becomes "Internet accounts" in the settings sheet.

## Task

Load `kmp-shared`, `shared-viewmodel`, `apple-swiftui`, `mobile-navigation`, `canonical-keys`, `testing` and `mobile-verify`.

1. Shared: `InternetAccount` (provider, address, mailEnabled, calendarsEnabled, mail status, calendar status) read from `GET /api/mail/mailboxes`; `InternetAccountsViewModel` and `InternetAccountViewModel` replacing the mail account ones, with actions toggle service (item PATCH with ifVersion), rename, remove (impact first), sync now.
2. `AccountPage.INTERNET_ACCOUNTS` replaces `MAIL_ACCOUNTS`; the profile row "Internet accounts" with the needs-attention count; the screens live in the profile sheet's stack.
3. Apple: list with provider icons and per-service status, add-account provider picker (iCloud, Google, Microsoft, Other), account detail with Mail and Calendars toggles, status rows and remove. Password providers reuse the existing connect form (Other gains the CalDAV URL field).
4. Copy in en/cs; identifiers; tests per `testing`.
