**Blocked by:** #126

## Context

Users need a visible project-level control over every active synchronized tool.

## Task

Add a third Tools block to each project's AGENT page below guidance and heartbeats. List all active registrations across system servers, grouped with server identity, using the established checkbox list pattern. Bind each checkbox directly to the project's user-owned grant, default false. Show approval/risk metadata and provide minimal authenticated controls for reclassification. Include loading, empty, transport-offline, mutation-error, and concurrent-refresh states with i18n labels.

## Scope

### In scope

- Tools block, grants, classification controls, and UI states.

### Out of scope

- Sync action redesign and automated recommendations.

## Acceptance criteria

- Checkbox state round-trips to the exact project/tool pair.
- A newly synchronized tool appears unchecked in every project.
- Grant changes alter the next generated tool set.
