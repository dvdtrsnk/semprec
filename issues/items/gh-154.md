**Blocked by:** #239, #21, #143, #115

## Context

Issue #238 delivered the `semprec-api` REST adapter with the item envelope and error contract, and #239 delivered the ModuleRegistry manifest that mounts named custom routes into flat `/api`. Three adapters will sit over one choke-point (REST and MCP-over-HTTP in `semprec-api`, AgentTool in `semprec-agents`), and an adapter must contain no business logic — only mapping. That rule is enforced by a dependency-cruiser boundary and contract tests, not by convention. This final slice of the adapter contracts delivers that enforcement; #155 onward mount concrete endpoint families under it.

## Task

Add dependency enforcement so that only the choke-point package may import a DB client for writes to the core tables `items`, `databases`, and `properties`:

- Add a dependency-cruiser rule (the dependency-cruiser setup exists from #113/#115) that forbids any route handler, adapter, or module code outside the choke-point package in `packages/data` from importing a database client or write-capable store for `items`/`databases`/`properties`. Only the choke-point package may import a DB writer for core tables.
- Add contract tests proving that every handler mounted through the adapter of #238 and the manifest of #239 maps onto a choke-point service call and cannot directly write core tables: the tests enumerate all registered routes (generic and custom) and assert each handler's writes go through the choke-point.
- Do not reimplement domain rules in handlers; the rule and the tests exist to make that impossible, not merely discouraged.

## Scope

### In scope

- The dependency-cruiser write-boundary rule with a failing fixture demonstrating it triggers.
- Handler contract tests covering every route registered through the adapter and manifest.

### Out of scope

- The adapter foundation, item envelope, and error contract — #238.
- The route manifest, mounting, and collision detection — #239.
- The complete `packages`/`modules`/`services` dependency matrix (including `items-store-private`) and runtime database roles — #173.
- Concrete generic resource and file endpoints (#155–#158); WebSocket, MCP, and AgentTool adapters.

## Acceptance criteria

- Contract tests prove all handlers map to service calls and cannot directly write core tables.
- A fixture file outside the choke-point package that imports a DB writer for `items`, `databases`, or `properties` fails the dependency-cruiser check; the choke-point package itself passes.
- All routes registered by #239 pass the handler contract tests unchanged.
