## Context

`docs/adr/2026-09-24-choke-point-composed-from-domain-modules.md` (added by #500) records a lint cap of 900 lines per production source file, so no module can grow the way `backend/packages/data/src/chokePoint/chokePoint.ts` did. #529 applies it to `backend/`, and this issue applies it to `web/`. The largest production file in `web/src` today, `web/src/views/mailbox/MailboxClient.tsx`, has about 885 lines.

## Task

Add `max-lines: ["error", { max: 900, skipBlankLines: true, skipComments: true }]` to `web/eslint.config.js` for `src/**/*.{ts,tsx}`, excluding `**/*.test.{ts,tsx}` and `**/__tests__/**`. Next to the rule, add a comment pointing to the ADR and saying why tests are exempt.

Do not add any per-file exemption. If a production file exceeds 900 counted lines when you implement this, do not raise the cap and do not exempt the file. Stop with `Relay-Step-Status: blocked` and name the file and its count.
