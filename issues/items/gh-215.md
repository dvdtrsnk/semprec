**Blocked by:** #214, #115, #121

## Context

Issue #214 established the canonical project-agent guidance source, its shared ports, and the `packages/application` boundary. Detecting semantic drift (#85) needs a structured, schema-validated model completion, but no reusable gateway client exists and `semprec-ai-gateway` has no internal structured-completion route. This part adds the neutral client port, its HTTP implementation, and the gateway endpoint with budget attribution and audit, building on #30's gateway process/budget attribution without assuming a reusable client already exists. #85 is the only consumer in this batch and uses `operation = 'agent_guidance_drift'`.

## Task

Create the neutral gateway contract in `packages/shared/src/aiGatewayClient.ts`: `AiGatewayClientPort.complete(input): Promise<{ content: unknown; usage: { inputTokens: number; outputTokens: number } }>` where input is `{ projectItemId, operation, temperature, system, messages, responseSchema }`. `packages/ai-gateway-client` implements it as `POST http://127.0.0.1:${AI_GATEWAY_PORT}/internal/complete` with `Authorization: Bearer ${AI_GATEWAY_INTERNAL_TOKEN}`, JSON body equal to that input, a 60-second timeout, and strict response validation. Add the same bootstrap token to API/gateway environment templates; gateway rejects missing/wrong token with 401. Network timeout, non-2xx, invalid JSON, or schema mismatch becomes `ai_gateway_failed` with safe `{ reason: 'timeout' | 'http' | 'invalid_response' }` and no provider/body secret leakage. `packages/application` imports only `AiGatewayClientPort`; it never imports a service or provider SDK.

Extend `semprec-ai-gateway` itself with `POST /internal/complete`. Startup requires non-empty `AI_GATEWAY_STRUCTURED_PROVIDER` and `AI_GATEWAY_STRUCTURED_MODEL`; the provider id must exist in #30's gateway provider registry and advertise native JSON-Schema structured output, otherwise startup fails. There is deliberately no silent/default model. The handler authenticates the internal token before parsing, strictly validates the client input, accepts a Draft 2020-12 JSON Schema with no remote `$ref` and maximum serialized size 64 KiB, and passes provider/model/temperature/system/messages/schema to the registered provider's native structured-completion adapter. It validates returned content against the same schema before responding with `{ content, usage }`.

Add nullable `project_item_id uuid` and `operation text` to #30's `ai_gateway_calls`; this route always sets both from the validated request (`operation` must equal `agent_guidance_drift`). Before provider invocation it runs #30's unchanged daily/monthly budget query and returns `403 budget_exceeded` without a call/audit row when capped. After any provider response it writes the standard #30 audit row with configured provider/model, token counts, priced `cost_usd`, `agent_run_id = NULL`, plus project/operation; provider transport failure writes the standard failed-call observability event but no fabricated token/cost row and returns 502 `provider_failed`. Invalid request/schema returns 400 `validation_failed`; invalid provider structured content returns 502 `invalid_response`. Integration tests boot a fake registered structured provider, verify token auth/schema enforcement, prove a request shaped like the drift request (`operation = 'agent_guidance_drift'`, a `contradictions` response schema) traverses this handler, assert project/operation/provider/model/usage/cost audit fields, and prove budget rejection prevents provider invocation.

## Scope

### In scope

- `AiGatewayClientPort`, its `packages/ai-gateway-client` implementation, environment token templates, and client-side error mapping.
- The gateway `POST /internal/complete` route, its startup configuration requirements, budget/observability path, validated structured output, and the additive `ai_gateway_calls` columns.

### Out of scope

- The `core.agentGuidanceDrift` action that calls this endpoint, its prompt, output validation, findings, and notifications; #85 delivers these.
- Guidance persistence, service, and system-prompt projection; #214 delivered these.
- Any provider SDK dependency outside `semprec-ai-gateway`.
- Changing #30's budget query or pricing rules.

## Acceptance criteria

- `/internal/complete` is authenticated, schema-constrained, globally budgeted, and fully attributed in `ai_gateway_calls` with project/operation/provider/model/usage/cost.
- Startup fails when `AI_GATEWAY_STRUCTURED_PROVIDER` or `AI_GATEWAY_STRUCTURED_MODEL` is missing, unknown to the registry, or lacks native JSON-Schema structured output.
- A budget-capped request returns `403 budget_exceeded` and never invokes the provider or writes an audit row.
- The client maps timeout, non-2xx, invalid JSON, and schema mismatch to `ai_gateway_failed` with only `{ reason }` and leaks no provider or body secrets.
- No direct model-provider dependency exists outside `semprec-ai-gateway`, and `packages/application` imports only `AiGatewayClientPort`.
