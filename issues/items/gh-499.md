## Context

Later issues in this batch each move one group of declarations out of `backend/packages/data/src/chokePoint/chokePoint.ts` into its own module, and most of them run in parallel. Today the declarations of one future module are scattered across the file. For example, the relation-edge helpers sit at lines ~219, ~322 and ~720–812, interleaved with item and view helpers. Parallel moves out of interleaved code would edit neighbouring lines and conflict on every rebase.

This issue reorders the file once, with no code changes, so each future module's declarations form one contiguous block bounded by a stable marker line. The marker lines never change afterwards, so two issues editing different blocks can never produce a rebase conflict. The public-surface test from #495 proves the reorder changed nothing.
