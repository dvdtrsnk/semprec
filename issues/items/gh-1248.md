## Context

Model tier rationale: This adds an input-size guard and adjusts existing pure encryption tests without changing the cipher, encoding or stored format.

Issue #1069 also edits the credentials package entry point while retiring the master-only scheme. This follow-up waits for that file owner and changes only the surviving envelope-key wrapper.

- PR #1115, finding `3efdd856ec`, `backend/packages/credentials/src/index.ts:120`: wrapDataKey wraps arbitrary-length plaintext even though unwrapDataKey accepts only a 32-byte data key.

## Task

Check `dataKey.length === DATA_KEY_BYTES` in `wrapDataKey` before sealing; reject every other length with a plain Error identifying the required size, following the existing error shape without a `code` property. Extend the existing wrap/unwrap unit suite with invalid plaintext-key lengths and retain the valid round-trip case. Repair the existing malformed-unwrapped-key fixture: construct its authenticated short plaintext directly with `sealSecret` and the associated-data bytes `semprec:tenant-key:v1:${tenantId}`, rather than obtaining it through the newly rejecting `wrapDataKey`. That existing test must continue to reach unwrapDataKey's own length guard.

## Touches

- backend/packages/credentials/src/index.ts (wrapDataKey only)
- backend/packages/data/src/__tests__/credentialEnvelope.unit.test.ts (wrap/unwrap cases only)

## Scope

### In scope

The wrapping plaintext length guard and the tests that distinguish wrapping rejection from unwrapping rejection.

### Out of scope

Master-key validation changes, tenant-ID normalization, cryptographic algorithms, credential scheme retirement and unrelated tests.

## Acceptance criteria

- For finding `3efdd856ec`, wrapping empty, short (including 16 and 31 bytes) and oversized (33 bytes) data keys rejects immediately with a plain Error mentioning 32 bytes; a generated 32-byte key still wraps and unwraps unchanged. The direct-seal malformed fixture still reaches and fails the unwrap length check rather than failing during fixture setup.
