### Requirement gh-1584: [collection-schema 10/14] Store colors on select options

#### Context

Model tier rationale: One known mechanism (an optional validated `color` on stored select options, projected through the resolver, plus an idempotent per-tenant backfill) across defined store, resolver and cutover seams with existing fixtures, but it writes into schema-locked system databases of existing tenants.

The app shows select values as colored chips: file types, health-record status, event types, people relationships, project status, and the Library statuses. The system databases are schema-locked, so existing tenants can only be changed by a per-tenant cutover registered in `backend/packages/data/src/db/tenantCutoverMigrations.ts` (see `docs/adr/2026-10-08-deploy-time-tenant-work-runs-as-the-runtime-role.md`; `transcription/transcriptsCatalogCutoverMigration.ts` is the pattern: lock, idempotency check, backfill). ### Requirement gh-1587: [links 04/12] Add link.unlink and link.relink operations

#### Context

Model tier rationale: One well-defined mechanism across the existing operation catalog, REST and MCP seams, reusing the state and handoff rules from the preceding issue, but it touches several closed-catalog files with compile-time exhaustiveness checks.

A user can stop an inherited value following its source without changing the value ("unlink"), and can start following again ("relink", which takes over the sources' current value). #1516 ends links when a value is written and defines the `valueLinks` handoff. This issue adds the two explicit operations on top. #1758 puts an approval step in front of Semp's use of unlink.

Today the generic operation catalog is closed: `GENERIC_OPERATION_NAMES` in `shared/src/genericOperations/operationNames.ts` currently lists 32 operations, and `schemas.ts`, `port.ts`, `capabilities.ts` and `bindings.ts` are checked against it at compile time. Decisions:

- `link.unlink` keeps the value and sets the state to `broken`; `broken_by` is `user` for a REST actor and `agent` for an agent or MCP actor.
