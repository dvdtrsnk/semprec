## Context

Model tier rationale: One new read route reusing the shared thread predicates, with localization of system folder names and a defined ordering.

The mailbox sidebar lists the folders of one account with counts: "Inbox 3", "Sent", "Drafts 2", "Archive", "Junk 14", "Trash", then labels (for Gmail, user labels shown as folders). The data is in Folders items (`name`, `behavior`, `specialPurpose`, related to a Mailbox) and in Emails-to-Folders edges; Gmail folders are cleaned up by #1496. Counts use the predicates of #1633. Folder names for system folders are localized by `specialPurpose` (the catalog is `backend/packages/data/src/mail/i18n/cs.json` and `en.json`, resolved by the request's user locale as `transcription/transcriptionRouteHandlers.ts` does with `toManifestLocale`).

Decisions: the order is inbox, sent, drafts, archive, junk, trash, then all other folders alphabetically by name (the order from the provider is not stable, notably for Gmail); the `all` folder is not returned; `unreadCount` counts unread threads in the folder, and `totalCount` counts the messages (Emails items) linked to the folder, which is what the Drafts row shows.

Shared-file ordering: this issue also waits for #1688 because both edit the same registry, manifest, cutover, route matrix or hook files listed in Touches.

## Task

Load `canonical-keys`, `state-writes` and `testing`.

1. Add i18n keys `mail.folder.inbox`, `mail.folder.sent`, `mail.folder.drafts`, `mail.folder.archive`, `mail.folder.junk` and `mail.folder.trash` to `mail/i18n/cs.json` and `en.json`.
2. Implement `GET /api/mail/mailboxes/:id/folders` in `backend/packages/data/src/mail/mailFolderList.ts`, declared in `mailModuleManifest.ts` (`handlerExport` `createMailFolderListRouteHandler`, justification `single-consumer-read`) with a `routeMatrix.ts` entry.
3. Response `[{ id, name, specialPurpose, behavior, unreadCount, totalCount }]`. `name` is the localized label for folders with a system `specialPurpose` (other than `none`) and `Folders.name` otherwise. Validate `:id` as a UUID; an unknown, deleted or foreign mailbox answers 404.
4. Compute counts for all folders of the mailbox in a constant number of queries.
5. Add tests: ordering; localized names in both locales; a Gmail account with two drafts returns `totalCount` 2 for the Drafts folder; `unreadCount` equals the thread count from `GET /api/mail/threads?folderId=...&unread=true`; `all` is omitted; a foreign mailbox is 404.

### Out of scope

## Acceptance criteria

- When the folders of a mailbox are requested, then system folders come first in the order inbox, sent, drafts, archive, junk, trash, followed by other folders alphabetically.
- When the user locale is Czech, then the inbox folder is named "Doručená pošta".
- When a Gmail account has two drafts, then the Drafts folder's `totalCount` is 2.
- When the inbox folder's `unreadCount` is compared to the thread list with the same folder and `unread=true`, then they are equal.
- The `all` folder is not returned and another tenant's mailbox answers 404.
