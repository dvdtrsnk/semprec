## Task

Bump the pinned `dvdtrsnk/code-review-bot` revision in `.relay/config.yml`
(`review.bot.ref`) and `.github/workflows/code-review.yml` (the
`Checkout code-review-bot (private)` step's `ref:`) to
`b27080ebfeb687e8ec0cb1c76885e96db7f3b22b`.

That commit fixes a real bug in the cheap-reuse-after-rebase feature shipped
by the prior pin bump (#491): `check_reuse` gated reuse on the PR's base SHA
matching the base SHA recorded at the last verdict, but `merge-pull-request`
only re-triggers a review by rebasing onto a base branch that has moved —
so the base SHA differs on essentially every rebase-triggered re-review,
making the reuse shortcut structurally unreachable in the one scenario it
exists for. The fix drops the base SHA from the equality gate (diff hash and
review-rules hash remain the gate) while still recording it for operator-
visible logging. See `dvdtrsnk/code-review-bot#26` for the fix itself.
