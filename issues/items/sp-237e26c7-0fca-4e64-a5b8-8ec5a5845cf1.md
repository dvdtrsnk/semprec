## Context

Model tier rationale: A one-value configuration change in two mirrored files with their tests.

The project rename (PR #2124) replaced the Apple app's default server `https://semprec.tresnak.cc` with `https://alldots.tresnak.cc`, a host that does not exist, so a fresh install cannot reach any server without typing an address. The dev server is now reachable at `https://api.alldots.app` (and still at `https://semprec.tresnak.cc`).

## Task

1. Set the default server to `https://api.alldots.app` in `mobile/apple/Tuist/ProjectDescriptionHelpers/ProjectConfiguration.swift` and in the mirrored value in `mobile/gradle/project.properties` (or wherever the Android default lives), keeping both files in agreement as their comments require.
2. Update the tests or fixtures that assert the old default host.

## Touches

- `mobile/apple/Tuist/ProjectDescriptionHelpers/ProjectConfiguration.swift`
- `mobile/gradle/project.properties` and the Android default, if mirrored
- tests asserting the default server

## Scope

### In scope

- The default server value.

### Out of scope

- Server-side `APP_BASE_URL`, any other host.

## Acceptance criteria

- A fresh install of the Apple and Android apps offers `https://api.alldots.app` as the server; no file of the repository names `alldots.tresnak.cc` any more.
