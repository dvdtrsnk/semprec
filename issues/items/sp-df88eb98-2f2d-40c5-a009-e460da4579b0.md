## Context

Model tier rationale: one `when` over a shared enum made exhaustive, with a table test; no behaviour change.

Review of PR #2089 (finding 20): `toProblem()` in `mobile/shared/presentation/.../InternetAccountsViewModel.kt` maps `FailureKind` with `else ->`, so a new `FailureKind` case would compile silently into `UNEXPECTED` instead of failing the build where its meaning has to be decided (`kmp-shared` §5: no `else` over shared enums).

## Task

Load `kmp-shared`, `shared-viewmodel`, `testing`.

1. List every `FailureKind` case (and the `null` of an unexpected failure) in `toProblem()`; the mapping stays as it is (`REJECTED` → `REFUSED`, `UNAVAILABLE` → `UNAVAILABLE`, everything else `UNEXPECTED`).
2. A table test over `FailureKind.entries`.
