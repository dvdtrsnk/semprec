## Context

Model tier rationale: The router function SQL, store queries and route validation are given exactly.

AI use is paid from the operator's global provider keys. Each user's daily and monthly caps are set only by an admin, and a tenant without caps is refused (fail closed). The gateway already enforces this (#1035), reading the global table `tenant_ai_budgets(tenant_id uuid PRIMARY KEY REFERENCES tenants(id) ON DELETE CASCADE, daily_cap_usd numeric CHECK (>= 0), monthly_cap_usd numeric CHECK (>= 0), updated_at, updated_by uuid REFERENCES users(id) ON DELETE SET NULL)` (#1004) on every reservation, under the single advisory lock `hashtext('ai_gateway_budget')` (`backend/packages/ai-gateway/src/gateway.ts:55`). A changed cap is therefore picked up by the next reservation. A missing row refuses every call, and a NULL cap column means no tenant cap for that period; the global env cap still applies. `semprec_data` holds `SELECT, INSERT, UPDATE` on the table and `semprec_side` `SELECT` only. Tenant zero's row was seeded from the settings item, whose `monthlyBudgetUsd` defaults to `null`, meaning uncapped (`backend/packages/data/src/db/migrations/0019_settings_ai_budgets.sql:31-33`). A new tenant has no row until an admin sets one. Nothing writes `tenant_ai_budgets` yet, so this issue adds the only writer.

Spend lives in the tenant table `ai_gateway_calls`, where every row counts at its `cost_usd`: `reserved` at the estimate, `settled` at the real cost, `failed` at 0 (`backend/packages/data/src/aiGateway/aiGatewayCallsStore.ts:189-222`). The admin plane runs in system scope, where row-level security hides every tenant row. Per-tenant spend therefore needs a `semprec_router` aggregate function, built to the router convention (#997; used by #1038's `ops_health_counts()`):

- `SECURITY DEFINER`, owned by the NOLOGIN `BYPASSRLS` role `semprec_router`;
- column-level `SELECT` grants only, and a pinned `search_path`;
- `EXECUTE` revoked from `PUBLIC` and granted only to `semprec_data`;
- returns ids and numbers only.

The global safety cap uses UTC windows (`ai_global_spend`, #1035), and the admin overview reports per-tenant spend in the same UTC windows.

Admin routes are `admin: true` entries of `createAdminRoutes` (`backend/services/semprec-api/src/adminHandler.ts`). They return 403 `admin_required` to members and run in `runAsSystem`. Every admin mutation writes `recordAdminAction(client, { actorUserId, action, targetTenantId, details })` in its own transaction, and `tenantAiBudgetSet` is the action reserved for this issue (#1037).

## Task

Load `state-writes` (upsert plus audit in one transaction), `db-migrations` (router function), `io-hardening` (request validation against the column domain) and `error-handling`.

1. **Migration** (take the next free migration ordinal at commit time; additive):
   ```sql
   CREATE FUNCTION ai_tenant_spend()
   RETURNS TABLE (tenant_id uuid, spent_today_usd numeric, spent_month_usd numeric)
   LANGUAGE sql STABLE SECURITY DEFINER SET search_path = pg_catalog, public AS $$
     SELECT c.tenant_id,
            COALESCE(SUM(c.cost_usd) FILTER (WHERE c.at >= date_trunc('day', now() AT TIME ZONE 'UTC') AT TIME ZONE 'UTC'), 0),
            COALESCE(SUM(c.cost_usd), 0)
     FROM public.ai_gateway_calls c
     WHERE c.at >= date_trunc('month', now() AT TIME ZONE 'UTC') AT TIME ZONE 'UTC'
     GROUP BY c.tenant_id
   $$;
   ALTER FUNCTION ai_tenant_spend() OWNER TO semprec_router;
   GRANT SELECT (tenant_id, at, cost_usd) ON ai_gateway_calls TO semprec_router;
   REVOKE EXECUTE ON FUNCTION ai_tenant_spend() FROM PUBLIC;
   GRANT EXECUTE ON FUNCTION ai_tenant_spend() TO semprec_data;
   ```
   Keep any column grant #1035 already gave `semprec_router` and only add the missing ones. Append one row for `ai_tenant_spend()` to the `## Cross-tenant router functions (semprec_router)` table in `docs/operations/database-roles.md`: executing role `semprec_data`, returns tenant ids and two sums, reads `ai_gateway_calls(tenant_id, at, cost_usd)`.
2. **Store** — in `backend/packages/data/src/aiGateway/tenantAiBudgetsStore.ts` add:
   - `listTenantAiBudgetOverview(client: Queryable)`. One query over `users` JOIN `tenants`, LEFT JOIN `tenant_ai_budgets`, LEFT JOIN `ai_tenant_spend()`, ordered by `users.created_at, users.id`. It returns `{ userId, email, hasBudget, dailyCapUsd: number | null, monthlyCapUsd: number | null, spentTodayUsd: number, spentMonthUsd: number }[]`, with typed rows and numeric strings converted by `Number()`.
   - `setTenantAiBudget(client: PoolClient, input: { tenantId; dailyCapUsd: number | null; monthlyCapUsd: number | null; updatedBy: string })`. It upserts with `INSERT … ON CONFLICT (tenant_id) DO UPDATE SET daily_cap_usd, monthly_cap_usd, updated_at = now(), updated_by` and `RETURNING` the row.
3. **Routes** in `createAdminRoutes` (both `admin: true`):
   - `GET /api/admin/ai-budgets` returns `200 { "spendWindow": "utc", "accounts": [...] }`, using the overview shape above.
   - `PUT /api/admin/accounts/:userId/ai-budget` with body `{ "dailyCapUsd": number | null, "monthlyCapUsd": number | null }`:
     - Validate `:userId` with `assertUuid` (`backend/services/semprec-api/src/adapter/requestValidation.ts`). The body must be an object, and each field must be present and either `null` or a finite number ≥ 0.
     - This is the full domain of the columns: #1004 declared both caps as unconstrained `numeric` with `CHECK (… >= 0)`. A value outside it (negative, a string, `NaN`/`Infinity` encodings, a missing field) is a 400 `validation_failed` naming the field before any query runs.
     - `null` means "no tenant cap for this period", the meaning #1004/#1035 give a NULL column. A missing row still refuses every call.
     - In one `withTransaction`: resolve `SELECT tenant_id FROM users WHERE id = $1` (no row: `NotFoundError`, 404, no audit row), call `setTenantAiBudget`, then `recordAdminAction(client, { actorUserId: identity.user.id, action: "tenantAiBudgetSet", targetTenantId, details: { dailyCapUsd, monthlyCapUsd } })`.
     - Answer `200 { "budget": { userId, dailyCapUsd, monthlyCapUsd, updatedAt } }`.
4. Add route-matrix entries `admin ai budgets` (`GET /api/admin/ai-budgets`) and `admin set ai budget` (`PUT /api/admin/accounts/00000000-0000-0000-0000-000000000000/ai-budget`), both `admin: true`, plus their `ROUTE_HANDLER_FILES` mappings. Add the two new runtime exports to `EXPECTED_RUNTIME_EXPORTS`.

## Scope

### In scope
- `ai_tenant_spend()`, the admin overview and cap-setting routes, the only writer of `tenant_ai_budgets`, and its audit row.

### Out of scope
- Gateway enforcement, the global env caps and the refusal body (#1035).
- A user's own usage report against their caps (#1048).
- Removing the settings budget properties (#1059).
- The admin budgets web panel (#1081).
- Initial caps for a newly invited account: its tenant has no budget row (refused by the gateway) until an admin sets one through this route.

## Acceptance criteria

- When an admin `PUT`s `{ "dailyCapUsd": 5, "monthlyCapUsd": 40 }` for tenant B's user, B's `tenant_ai_budgets` row holds those values with `updated_by` = the admin. One `admin_audit_log` row records `tenantAiBudgetSet` with B's tenant id and `details = { dailyCapUsd: 5, monthlyCapUsd: 40 }`, and tenant A's row is unchanged (integration, `adminHandler.test.ts`, two tenants via `createTestTenant()` from #975).
- When the same request is sent for a user whose tenant has no budget row, the row is created. `getCurrentTenantAiBudget` (#1004) inside that tenant's scope returns the new caps (integration, `tenantAiBudgetsAdmin.test.ts`).
- When the body has `dailyCapUsd: -1`, `"5"` or a missing field, the response is 400 `validation_failed` naming that field, and neither a budget row nor an audit row is written (integration, `adminHandler.test.ts`).
- When `:userId` is not a uuid the response is 400. When it is an unknown uuid the response is 404 `not_found`, and no audit row is written (integration, `adminHandler.test.ts`).
- When tenant A has today (UTC) a settled call at 1.50, a reserved call at 0.25 and a failed call, plus a settled call at 2.00 on an earlier day of this month, and tenant B has a call at 3.00, `GET /api/admin/ai-budgets` reports A with `spentTodayUsd: 1.75` and `spentMonthUsd: 3.75`, and B with 3.00 for both. An account without a budget row has `hasBudget: false` and null caps (integration, `adminHandler.test.ts`).
- When a `member` calls either route, the response is 403 `admin_required`. Without a session it is 401 (integration, `adminHandler.test.ts`, `routeMatrix.test.ts`).
- When `ai_tenant_spend()` is called as `semprec_side`, it fails with a privilege error. The catalog shows it owned by `semprec_router`, `SECURITY DEFINER`, with a pinned `search_path` (integration, `tenantAiBudgetsAdmin.test.ts`).
