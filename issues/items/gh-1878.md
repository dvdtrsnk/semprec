## Context

Model tier rationale: A small change to the candidate query and to one log decision of an existing sweep, in one file pair, with the behavior pinned by a test; no new data contract.

The nightly item sweep (`purgeExpiredTrash` in `backend/packages/data/src/trash/purgeExpiredTrash.ts`) selects trashed items older than the retention (`itemsStore.findItemsDeletedBefore`) from every database of the tenant, archived ones included. For an item in an archived database `chokePoint.purgeExpiredTrashSubtree` refuses (`assertDatabaseNotArchived`), so every night each such item is logged as "Failed to purge trashed item". An archived database is now itself in the trash and is deleted with all its items by #1875, so the item sweep must leave its items alone and say nothing.

Decision: items that were trashed before their database was archived are deleted together with the database when the database is purged; while it is archived the item sweep skips them. If the database is restored, those items keep the remainder of their own retention (their `deleted_at` is unchanged and the sweep sees them again).

## Task

Load `state-writes` and `testing`.

1. In `findItemsDeletedBefore` (`backend/packages/data/src/chokePoint/itemsStore.ts`) exclude items whose database is archived (`database_id` restricted to databases with `archived_at IS NULL`), so they are never candidates.
2. In `purgeExpiredTrash`, treat a `database_archived` refusal raised by `purgeExpiredTrashSubtree` (a database archived between the candidate read and the purge) as a skip logged at debug level, not an error; every other failure stays an error as today.
3. Tests in `backend/packages/data/src/trash/__tests__/purgeExpiredTrash.test.ts`: an item deleted 40 days ago in an archived database is not touched and logs no error; after the database is restored, the same item is purged by the next run; an item in a live database is purged as before; a database archived between selection and purge is skipped quietly.

- Expired trashed items of live databases are purged exactly as before.
