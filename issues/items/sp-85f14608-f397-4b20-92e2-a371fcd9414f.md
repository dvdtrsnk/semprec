## Context

Model tier rationale: A new generic operation that edits a property's configuration and every item value holding the option in one transaction, through the choke point, with tenant isolation, realtime invalidation and search reindexing.

Project tags are options of the user-owned `multi_select` property `tags`. `POST /api/properties/:id/options` (`property.option.add`) adds an option and `PATCH /api/properties/:id/options/:key` (`property.option.update`) renames or recolors one. Nothing removes one. `assertSelectValuesKnown` refuses any value whose option is unknown, so an option cannot simply be dropped from the configuration while items still hold it.

## Task

1. Add the generic operation `property.option.remove` with `DELETE /api/properties/:id/options/:key`. It is allowed on user-owned `select` and `multi_select` properties, including on schema-locked databases, the same as add and update.
2. In one transaction, remove the option from `properties.config.options` and the key from every live and trashed item value of that property. A `select` holding it becomes empty. Item writes go through the choke point, with the usual events, realtime invalidation and search reindex after commit.
3. Answer 204. Answer 404 for an unknown property or key, and 400 for a system-owned property or a non-choice type.
4. Register the operation everywhere `property.option.update` is registered: capabilities, bindings, route matrix, agent and MCP surfaces.

## Touches

- backend/packages/shared/src/genericOperations (operation names, capabilities, bindings, schemas)
- backend/packages/data/src/chokePoint (propertyOps, propertiesStore, item writes)
- backend/services/semprec-api/src/propertiesHandler.ts, routeMatrix
- tests next to each, including tenant isolation

## Scope

### In scope

- Removing one option and its values.

### Out of scope

- Merging two options, and undoing a removal.

## Acceptance criteria

- After a delete, the property has no such option, and no item, live or trashed, holds its key. The other keys of a multi_select value stay.
- An item holding the removed key is then written without a 400.
- 404 for an unknown key or another tenant's property. 400 for a system-owned property or a text property.
- A concurrent write to an item holding the key cannot reintroduce it after the removal commits.
- `pnpm run verify` passes in backend, apart from host-only failures named in the pull request.
