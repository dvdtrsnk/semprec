## Context

During the split, `backend/packages/data/src/chokePoint/chokePoint.ts` re-exports every symbol that moved out, so callers kept working. The target design has no barrel: a caller imports a symbol from the module that owns it (`docs/adr/2026-09-24-choke-point-composed-from-domain-modules.md`). This issue redirects the production callers in `inbox/`. Sibling issues redirect the other caller groups in parallel, and #528 removes the re-exports once every group is done.

Owning modules, all under `backend/packages/data/src/`:
- `createItemWithClient`, `updateItemWithClient`, `writeComputedAndAnnounce` and the item input types: `chokePoint/itemWrites.ts`
- `createRelationWithClient`, `updateRelationWithClient`, `deleteRelationWithClient`, `assertRelationCreatableWithClient` and the relation input types: `chokePoint/relationOps.ts`
- `createRelationPropertyWithClient`, `CreateRelationPropertyInput`: `chokePoint/relationPropertyOps.ts`
- `SystemRelationWriteContext`: `chokePoint/relationEdgeContext.ts`
- `enqueueRollupRecomputeForEdge`: `rollup/recompute.ts`
- `computeDestructiveResourceProjection` and the resource-snapshot types: `chokePoint/destructiveProjection.ts`
- `Actor`: `chokePoint/authorization.ts`
- `createChokePoint`, `ChokePoint`: stay in `chokePoint/chokePoint.ts`

## Task

In each file listed under Touches, replace every import from `chokePoint/chokePoint(.js)` with imports from the owning modules above. Imports of `createChokePoint` and `ChokePoint` stay pointed at `chokePoint.ts`. Keep `type` modifiers as they are. Change nothing else in these files.
