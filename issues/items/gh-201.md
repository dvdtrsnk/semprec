## Context

This issue establishes the first implementation slice of the `mail-sync-hardening` batch; #202 builds on it.

## Task

When high-level download fails before completion, retry the part via bounded BODY[section]<start.count> ranges assembled as the same lazy Readable. Start a fresh replacement stream, stop EOF, enforce MAX_ATTACHMENT_BYTES, bounded chunk/retry, abort non-progress, clean resources.

## Scope

### In scope

- Task deliverables, migrations, integration, tests, and necessary documentation.

### Out of scope

- Normal high-level streaming unchanged.

## Acceptance criteria

- Fake midstream failure succeeds with ordered partial ranges.
- EOF/cap deterministic.
- Empty/nonprogress fails without loop.
- Downstream stream/cap unchanged.
