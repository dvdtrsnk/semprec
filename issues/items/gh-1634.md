**Blocked by:** #1473, #1478, #1491
**Model tier:** high

## Context

Model tier rationale: This defines the outgoing transport interface every later sender implements and its first implementation opens authenticated connections to tenant-chosen hosts with decrypted secrets, so error mapping, timeouts and host policy matter.

Today mail is sent through `MailSendAdapterFactory.createSmtpClient` in `backend/packages/data/src/mail/send.ts`, which nobody supplies, and `NodemailerSmtpClient` in `smtpClient.ts` takes a field-based message with no attachments. Sending must choose its transport by the mailbox's sync mode and accept ready-made MIME, so the same path can send replies and meeting invitations.

This issue defines the transport interface and implements the first transport, SMTP for `imap` mailboxes (iCloud and generic). It builds on the stored server settings (#1473), connections through the outbound address policy (#1478) and the MIME builder (#1491). The Gmail and Graph transports are #1637 and #1753; they implement this same interface, which is why those three issues are ordered.

## Task

Load `io-hardening`, `error-handling` and `testing`.

1. Define in `backend/packages/data/src/mail/mailTransport.ts` a `MailTransport` interface with `send({ raw, envelope: { from, recipients }, providerThreadId? })` returning `{ providerMessageId?: string }`, a `MailTransportFactory` with `forMailbox(mailboxItemId, syncMode)` that decrypts the mailbox credential for the `smtp_send` purpose, and typed errors: `MailSendAuthFailedError`, `MailServerUnreachableError`, `MailRecipientRejectedError`. The existing `MailReauthorizationRequiredError` is reused for revoked OAuth credentials.
2. Implement the SMTP transport for `imap` mailboxes: read the stored SMTP settings of the mailbox (#1473), connect through the policy-checked connection of #1478, authenticate with the stored password and submit the raw MIME with the envelope. Add a `sendRaw` method to the SMTP client in `smtpClient.ts` with the same 30 second timeout as `sendMail`.
3. Map SMTP failures: authentication failure (535) to `MailSendAuthFailedError`, connection failure or timeout to `MailServerUnreachableError`, a permanent recipient refusal (5xx on RCPT) to `MailRecipientRejectedError`. No error message contains the password or the message body.
4. Replace `MailSendAdapterFactory.createSmtpClient` with the new factory in `send.ts`; keep `sendDraftEmail` compiling and its current tests passing by routing its SMTP call through the SMTP transport.

## Scope

### In scope

### Out of scope

- Gmail and Graph transports (#1637, #1753).
- Saving a copy in the provider's Sent folder (#1641).
- The HTTP send route and its error codes (#1896).

## Acceptance criteria

- When an `imap` mailbox sends raw MIME, then the SMTP server receives it with the given envelope recipients, including bcc.
- When the server answers 535, then the transport throws `MailSendAuthFailedError`; when it is unreachable or times out, `MailServerUnreachableError`; when it refuses a recipient permanently, `MailRecipientRejectedError`.
- A host that the outbound address policy refuses is never connected to.
- No thrown or logged text contains the password.
- Existing `sendDraftEmail` behavior and tests are unchanged.
