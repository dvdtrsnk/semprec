**Blocked by:** #1678, #1738
**Model tier:** medium

## Context

Model tier rationale: One new port wired into an existing system-prompt composition, with size limiting and untrusted-data framing, verified with unit tests; no new authorization contract because it only reads the project's own page.

A project's system prompt today contains only the project agent guidance (`project_agent_guidance.markdown` under "## Project-specific guidance", loaded through `LoadProjectAgentGuidancePort` and `createProjectAgentGuidanceSystemPromptOverride` in `backend/packages/agent-runtime/src/projectAgentGuidanceSystemPrompt.ts`, composed in `backend/services/semprec-agents/src/agentSessionComposition.ts`; the guidance limit is 32 KiB in `backend/packages/shared/src/projectAgentGuidance.ts`). The project's own notes (its page) are not included, although an empty-notes screen promises that Semp draws on them when working on the project. #1738 gives thread runs a chat system prompt, but only for thread runs; the override above is received by every run of a project (chat, tick, MCP).

This issue adds a project-notes block to that override: the notes are read as Markdown (#1678) through a new `LoadProjectNotesPort` provided by the semprec-agents composition root (modeled on `LoadProjectAgentGuidancePort`), and added next to the guidance.

Decisions:
- The notes appear in a separate, delimited block labeled as user data that the model must not treat as instructions (prompt-injection framing).
- Limit 32 KiB; longer notes are truncated at a block boundary, followed by a list of the page's subpages (titles and ids) so the assistant can load them with `page.get`.
- A project without notes or whose page does not exist adds nothing.

## Task

Load `ai-gateway`, `state-writes`, `io-hardening` and `testing`.

1. Add `LoadProjectNotesPort = (projectItemId) => Promise<{ markdown: string; subpages: { id: string; title: string }[] } | null>` and compose it in `agentSessionComposition.ts`, implemented with the Markdown read of #1678 (reading never creates a page).
2. Extend `createProjectAgentGuidanceSystemPromptOverride` (or a sibling builder called from it) to append the notes block after the guidance, with a header saying the content is user data, a truncation at 32 KiB, and the subpage list when truncated. Export the limit from `shared/projectAgentGuidance.ts` (or reuse it).
3. Tests: notes within the limit appear in the prompt as a marked data block; notes over the limit are truncated at a block boundary and followed by the subpage list; no notes adds no block; text resembling instructions inside the notes stays inside the data block.

### Out of scope

- Expanding refs attached to a message: #1733.

## Acceptance criteria

- When a project's run starts and the notes are up to 32 KiB, then the system prompt contains them as a marked block of user data.
- When the notes are longer, then they are truncated at 32 KiB and followed by the list of subpages with titles and ids.
- When a project has no notes page, then the prompt is unchanged.
