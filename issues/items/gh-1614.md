## Context

Model tier rationale: Extends the Markdown parser and serializer of a blocker with one link scheme and a tenant-scoped existence check, with round-trip fixtures as the verification.

Pages are exchanged as Markdown by agents and the REST/MCP surface (#1608 defines the canonical serializer and parser with shared fixtures, and links to subpages as `semprec://page/<id>`). A journal day often refers to an item, typically a calendar event ("Standup"). Transcript text already links items with `semprec://items/<uuid>`: `backend/packages/data/src/transcription/transcriptionJob.ts` writes such links. Page Markdown has no item link: the link attribute exists in the block model but the parser does not recognize this scheme or check that the target exists.

Decision: an item reference in text is the inline link `[Title](semprec://items/<itemId>)`, stored as the link attribute of the text run. The parser and serializer do not write relation edges: the text link is plain content. The Journal `events` relation is derived from the event links in a day's page by #2016 (the text is the single source of truth).

## Task

1. In the Markdown parser from #1608 recognize the destination `semprec://items/<uuid>` on an inline link and store it as the link attribute; keep `semprec://page/<id>` as before.
2. Deliver `assertItemLinksExist(client, parsedBlocks, field)` as the backend tenant-scoped guard after pure parsing. Check well-formed UUIDs and live, non-deleted items through an explicitly tenant-scoped runtime-role client. Unknown, foreign, deleted and malformed targets raise the same `ValidationError` contract: status 400, code `validation_failed`, identical safe message/details and Markdown field path. No database I/O enters the shared parser. Actual page-write integration and HTTP evidence belong to #1679 and #1765; do not add an endpoint here.
3. In the serializer, write a link attribute with this scheme back as `[text](semprec://items/<id>)`.
4. Add pure shared item-link roundtrip/collection fixtures and real runtime-role backend tests passing actual parsed blocks into the guard: live target accepted; unknown, foreign, deleted and malformed targets have identical safe errors; no relation or document write occurs. HTTP response tests are deferred to #1679/#1765, never claimed from an exception-only test.
