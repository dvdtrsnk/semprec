## Context

Harvest issue #934 collected findings about code and text that no longer say what they should.

- PR #826, `backend/services/semprec-ai-gateway/src/structuredProviders/anthropicProvider.ts:17`: `RETRYABLE_STATUSES` contains 529, which the `status >= 500 && status <= 599` branch of `isRetryableStatus` already covers.
- PR #826, `anthropicProvider.ts:171`: the deadline-exceeded error says `after ${attempt} attempts` unconditionally, so a first attempt reads "after 1 attempts".
- PR #828, `backend/packages/module-boundaries/src/__tests__/module-boundaries.unit.test.ts:53`: the `it.each` title says "rejects a route handler or module importing %s directly" although the importers are fixtures under `services/`.
- PR #862, `web/src/views/agentPage/ToolsBlock.tsx:38`: the comment says the mount guard is checked "at lines 47 and 50"; the checks are now at lines 59 and 62.

## Task

1. In `anthropicProvider.ts`, change `RETRYABLE_STATUSES` to `new Set([429])`.
2. In `anthropicProvider.ts`, make the deadline-exceeded message at line 171 say "1 attempt" when `attempt === 1` and "<n> attempts" otherwise, and add a test for both forms in `anthropicProvider.unit.test.ts`.
3. In `module-boundaries.unit.test.ts`, change the title to "rejects a service importing %s directly (issue #154)".
4. In `ToolsBlock.tsx`, replace "at lines 47 and 50" in the comment with wording that names the two guards (the `mounted.current` checks in `load`) without line numbers.
