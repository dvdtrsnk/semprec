## Context

Model tier rationale: One extra ffmpeg rendition in the existing prepare step with a strict timeline-equality requirement and checkpoint extension, verified by fixtures rather than a new contract.

Authenticated blob playback shares the normalized Opus segment timeline: reuse supported originals or render AAC/M4A in transcribe. Store playbackBlobId; #1576 exposes it, #1421 purges it. Client caching/deep links are client work.

Decision (by the product owner): no short-lived signed URL is added; the client uses the authenticated blob route with its local cache. A signed URL is added only if a real problem with the cache shows up. A token in a query or path would need a new ADR with an exception to `docs/adr/2026-10-17-secret-link-tokens-travel-in-the-url-fragment.md`.

## Task

Load `io-hardening`, `state-writes` and `testing`.

1. In `mediaNormalization.ts` add `renderPlaybackAudio` that encodes AAC m4a, mono, 64 kbit/s from the same decoded input as `normalizeAudio` and discards the container `start_time` exactly as the Opus path does, so both share one timeline. Stream to storage with the same cleanup on failure.
2. In `runPrepareStep` choose: original reused (no new blob) for `audio/mp4`, `audio/mpeg`, `audio/wav`; otherwise (video, Ogg, others) create the rendition and its blob row. Store `playbackBlobId` in the prepare checkpoint (extend the checkpoint schema, tolerate checkpoints without it).
3. Register the new blob for purge with the derived-blob mechanism of #1421. Test prepare-produced distinct original/normalized/playback rows/bytes via queued ITEM_TRASH_PURGE_SWEEP and runtime-role sweep: expired A deleted, live B preserved, bytes present before purge, teardown afterwards. Reuse isolated producer with optional Ogg. Keep rollback/shared controls; disclose TRASH_PURGE registration/existing queue test as sibling inference.
4. Tests with permanent fixtures: an explicitly described AAC-LC/M4A recording profile with known spoken markers, a video whose audio track starts late, and an Ogg file. Owned offline speech generation is permitted; no live/paid TTS. Record codec/rate/channels and fixture provenance, compare actual seeks/content on normalized and reused/rendered playback timelines, and prove checkpoint duration versus playback within0.1s. This is backend media evidence, not physical iPhone capture/player or subjective listening qualification.
