## Context

Model tier rationale: One flag on the thread list and one box filter with a count, extending the filter and summary queries of other issues over the draft metadata table, with existing list fixtures.

The mailbox shows a label on threads where Semp prepared a reply and a box "Semp drafts" with a count. After #1504 a draft has structured metadata (the `mail_drafts` row with `created_by` and the thread). The thread list filters (box, folder, mailbox, unread) come from #1633 and the counts for overview and mailboxes from #1688. Drafts written by the user, and sent or deleted drafts, are not Semp drafts.

## Task

Load `io-hardening`, `canonical-keys` and `testing`.

1. Add `hasSempDraft` to each row of the thread list: true when the thread has a not-deleted, unsent draft with `created_by` agent.
2. Support `box=sempDrafts` in the thread list filter: the threads for which `hasSempDraft` is true.
3. Add `sempDrafts` to the summary counts of #1688: the number of such threads (not drafts), using the same visibility rule as the other boxes.
4. Resolve `hasSempDraft` for a page of threads in one query; pin `database_id` in item lookups.

## Acceptance criteria

- A thread with an unsent agent draft has `hasSempDraft` true; with only a user draft, a sent draft or a deleted draft it is false.
- `box=sempDrafts` returns exactly those threads and `summary.sempDrafts` equals their number.
