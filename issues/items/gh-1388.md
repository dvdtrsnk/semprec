## Context

Model tier rationale: A small prompt change, but it reads the user's locale under the tenant scope of an agent run and sits in the shared session composition used by every agent run, so the scope assumption must be verified at the call site.

Semp is the assistant the person talks to, and every agent run is built by `createAgentSessionFactoryForRun` in `backend/services/semprec-agents/src/agentSessionComposition.ts` from the constant `AGENT_BASE_SYSTEM_PROMPT`. That prompt says nothing about language, so the model answers in whatever language the task text happens to be in. The person's language is `users.locale` (`cs` or `en`), readable per tenant through `getTenantUserLocale` (`backend/packages/data/src/auth/usersStore.ts`; it returns `null` when the tenant has no bound user or outside a tenant scope).

Decision: this instruction applies to every agent run that goes through the shared composition (chat replies, scheduled ticks, delegated agents), and takes effect from the next run after the locale changes; a run already in progress keeps the prompt it started with.

Decision: transcript summaries keep being written in the language of the transcript (`semprec-transcribe/src/transcriptSummary.ts`) and are not touched here.

#1738 builds the chat system prompt and relies on this language instruction being present in the shared base prompt.

## Task

Load `testing`.

1. In `agentSessionComposition.ts`, read the user's locale once per run in `createAgentSessionFactoryForRun` with `getTenantUserLocale` (exported from `@semprec/data`; export it from the package barrel if it is not yet). Confirm the run is composed inside the tenant scope; if it is not, run the read inside the run's tenant the way the file's other tenant-scoped reads do.
2. Append one sentence to the system prompt before the project guidance override is applied: for `cs` "Answer and write all user-visible text in Czech.", for `en` "Answer and write all user-visible text in English.". A `null` or unrecognized locale adds nothing (the prompt stays as today). Keep the sentences in a small typed map keyed by the supported locales, not inline conditionals.
3. Unit test the composed prompt for `cs`, `en`, `null` and an unrecognized value, and that the project guidance override still applies on top.

- A run started before a locale change keeps its original prompt; the next run uses the new one.
