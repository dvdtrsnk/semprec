**Blocked by:** #154

## Context

The adapter contracts exist: #154 (with its earlier parts) delivered the `semprec-api` REST adapter, the item envelope, the `{ error: { code, details } }` contract, manifest-mounted custom routes, and the choke-point-only write boundary. This slice exposes the first half of the metadata layer — databases and their properties — without introducing module-specific CRUD. #155 completes the metadata layer with views and curated view membership; #156 then projects the item lifecycle.

## Task

Implement the database and property endpoint family as thin mappings onto choke-point services:

- `GET/POST /api/databases`, `GET/PATCH/DELETE /api/databases/:id`, where `DELETE` archives instead of hard-deleting. A `system: true` database returns 403 on both archive and delete.
- `POST /api/databases/:id/properties` and `PATCH/DELETE /api/properties/:id`, enforcing `schema_locked` on the database and `locked` on the property (both → 403 with the matching error code), plus validation. Changing a property's `type` responds 202 after enqueueing the existing `migration_status` job (the asynchronous property-type migration from #21) — the endpoint never performs the migration inline.
- All routes call choke-point services, use localized metadata from #35, authenticate through #34, and return authoritative resource representations or the #154 error contract. No successful mutation returns 204.

## Scope

### In scope

- The complete database endpoint family (list/create/detail/patch/archive) and the property endpoint family (create/patch/delete with lock enforcement and 202 type migration).

### Out of scope

- View endpoints and curated view membership (`POST /api/databases/:id/views`, `PATCH/DELETE /api/views/:id`, `PUT/DELETE /api/views/:id/items/:itemId`) — #155.
- Item rows (#156), query execution and relations (#157), files (#158), realtime delivery.

## Acceptance criteria

- CRUD/archive/lock/type-migration tests cover every database and property route, including the forbidden system-database archive and delete (403).
- A `PATCH /api/properties/:id` that changes `type` returns 202 and exactly one `migration_status` job is enqueued; `schema_locked` and `locked` writes return 403 with the matching error code.
- No handler bypasses the choke-point or returns 204 for a successful mutation.
