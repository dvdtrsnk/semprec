**Blocked by:** #245, #176

## Context

Second of three parts of the recording-preparation slice of the `batch-transcription` batch (approved behavior in #179). #245 delivered the `semprec-transcribe` process, the sole task handler, step 0, and the ordered step runner with checkpoint skipping. This part adds step 1 (`prepare`): media normalization with `ffmpeg` and metadata extraction with `ffprobe`. #182 builds on the normalized audio produced here for diarization and chunked ASR.

## Task

- Add step 1 (`prepare`) to the step runner from #245. `semprec-transcribe` is the only process that calls `ffmpeg`/`ffprobe`.
- Normalize the recording with `ffmpeg` to 16 kHz mono Opus (about 7 MB per hour). For video inputs, extract the audio track into the same normalized format. The normalized audio is the input for every later paid stage (#182).
- Run `ffprobe` on the source and persist the recording duration and `creation_time`: the duration goes into the declared computed checkpoint of this step; `creation_time` is written into the `owner: 'system'` property `date` of the Transcriptions row (through the in-process choke-point writer from #245).
- `ffmpeg`/`ffprobe` are a system-level server dependency, not an npm dependency: add them to the provisioning script from #244 so the production host has them installed.
- The step's result (normalized audio reference, duration, creation time) is checkpointed immediately after the step finishes, so a repeated run skips the preparation.

## Scope

### In scope

- Step 1 implementation, ffmpeg/ffprobe invocation confined to `semprec-transcribe`, `date`/duration persistence, provisioning-script dependency, tests, and necessary documentation.

### Out of scope

- Step 0 and the step runner — #245.
- Diarization, chunked ASR, and their checkpoints — #182.
- Merge, summary, matching, retry — #183, #184, #186.

## Acceptance criteria

- An audio file and a video file with an audio track both normalize to 16 kHz mono Opus, and the Transcriptions row ends up with the duration checkpointed and `date` set from `creation_time`.
- Only `semprec-transcribe` invokes `ffmpeg`/`ffprobe`; no other package or process references them.
- A repeated run of a row whose preparation checkpoint exists skips step 1 without invoking `ffmpeg`/`ffprobe` again.
- The provisioning script installs `ffmpeg`/`ffprobe` idempotently.
