## Context

`web/README.md` states "No user-facing string is written inline in a component" and `docs/adr/2026-09-10-english-canonical-keys-with-i18n-labels.md` makes a hardcoded user-facing label a medium finding, yet four places still render literal English:

- `web/src/views/aiUsage/UtilizationPage.tsx`: `aria-label="cost-per-day"` (line 47) and `aria-label="tokens-per-day"` (line 89) on the two `<svg role="img">` charts — the accessible names screen readers announce; the `<title>` tooltips `` `${point.day}: ${formatUsd(point.costUsd)}` `` (line 60), `` `daily budget: ${…}` `` (line 72), `` `${point.day}: ${point.inputTokens} input tokens` `` (line 104) and `` `… output tokens` `` (line 113).
- `web/src/views/agentPage/ToolsBlock.tsx` lines 113-119: the risk-class `<select>` renders the raw values `unclassified`, `low`, `moderate`, `high`, `destructive` as option labels (`{value}`); `mcp_tool_registrations.risk_class` is free text (`0020_mcp_tool_registrations.sql` line 28), so an unknown value must still be selectable.
- `web/src/components/StateViews.tsx` line 33: `ErrorState` prints the raw `error.message`, which for every adapter is the English technical string `Request to /views/… failed with 404` (`httpGenericOperations.ts` line 53) or the browser's transport message.

The catalogs already hold `aiUsage.chart.costPerDay` / `aiUsage.chart.tokensPerDay` (chart headings) that can double as the accessible names. Depends on sibling G3 (adds `login.*` keys to `messages.ts`), sibling G5 (edits `ToolsBlock.tsx`) and sibling G8a (edits `UtilizationPage.tsx`'s `formatUsd` call sites and adds `useLocale`).

  - `aiUsage.chart.costPoint`: "{day}: {amount}" / "{day}: {amount}"; `aiUsage.chart.budgetLine`: "Daily budget: {amount}" / "Denní rozpočet: {amount}"; `aiUsage.chart.inputTokensPoint`: "{day}: {count} input tokens" / "{day}: {count} vstupních tokenů"; `aiUsage.chart.outputTokensPoint`: "{day}: {count} output tokens" / "{day}: {count} výstupních tokenů".
  - `agentPage.tools.riskClass.unclassified` ("Unclassified" / "Nezařazeno"), `.low` ("Low" / "Nízká"), `.moderate` ("Moderate" / "Střední"), `.high` ("High" / "Vysoká"), `.destructive` ("Destructive" / "Destruktivní").
  - `state.error.status`: "The server answered with status {status}" / "Server odpověděl stavem {status}"; `state.error.transport`: "The server could not be reached" / "Server není dosažitelný".
- `UtilizationPage.tsx`: `CostByDayChart` and `TokenUsageByDayChart` call `useTranslate()`; `aria-label={t("aiUsage.chart.costPerDay")}` / `t("aiUsage.chart.tokensPerDay")`; the four `<title>` strings become the new keys with `{ day, amount }` / `{ day, count }` values (`amount` via G8a's `formatUsd(locale, …)`).
