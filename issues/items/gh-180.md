## Context

This issue establishes the first implementation slice of the `batch-transcription` batch; #181 builds on it.

## Task

Extend Transcriptions catalog with declared computed keys, status error, and user-owned N:N speakers-to-People relation with edge metadata {speaker:'SPEAKER_00'} via code-level migration. Add Files onItemEvent:create: agents enqueue TASK_NAMES.transcriptionJob with fileItemId/jobKey transcription-job:<id> only for audio/* without Emails.attachments edge, performing no item write. Add POST /api/transcriptions for explicit audio/video/legacy files using same job/key; existing transcription returns 409 transcription_exists with id.

## Scope

### In scope

- Task deliverables, migrations, integration, tests, and necessary documentation.

### Out of scope

- No special upload endpoint or paid pipeline yet.

## Acceptance criteria

- Standalone audio enqueues once; mail attachment does not.
- Repeated delivery converges on one job.
- Explicit video can be requested.
- Catalog contracts migrate under ownership/archive guards.
