## Context
Review of pull request #439 found that the doc comment on `backend/packages/data/src/agentRuns/agentRunsStore.ts` (currently around lines 82-89) states `userId` is "required for a user-triggered root", but `backend/packages/agent-runtime/src/sempConversation.ts` (lines 159-164) creates a `triggeredBy: "user"` root run without passing `userId`, silently relying on the store's `getEarliestUserId` fallback instead.
