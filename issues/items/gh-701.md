## Context

Two crontab-driven sweeps process every eligible doc one by one and deliberately isolate per-doc failures so one bad row cannot stop the rest:

- `runCompactionSweep` (`backend/packages/data/src/docs/docPersistence.ts` lines 240-259): selects docs with `count(*) >= threshold` in `doc_updates`, calls `loadDoc` for each inside `try`/`catch`, counts `succeeded`, logs failures with `console.error("Failed to compact doc ...")`, returns the count. `handleDocCompactionSweepTask` (lines 261-263) discards it.
- `runDocHistoryRetentionSweep` (`backend/packages/data/src/docs/docHistory.ts` lines 114-129): iterates `SELECT id FROM docs`, calls `rebaselineDocHistory` per doc, same `try`/`catch` + `console.error`, returns the number of docs actually re-baselined. `handleDocHistoryCleanupTask` (lines 144-147) discards it and then runs `cleanupExpiredDocHistory`.

Because the handlers ignore the outcome, a sweep in which *every* doc failed — a permissions regression, a schema mismatch after a bad deploy, a broken `DOC_HISTORY_RETENTION_DAYS` resolution mid-run — completes its graphile-worker job successfully. Nothing retries it, `queue:permanentlyFailedJobs` and the queue backlog check see nothing, and the only trace is a `console.error` per doc outside the structured logger (`docs/adr/2026-09-13-shared-structured-process-logging.md`).

## Task

1. Add `backend/packages/data/src/docs/logger.ts` (new): `export const logger: Logger = createLogger("docs");` (the `mail/logger.ts` pattern).
2. Add `backend/packages/data/src/docs/sweepOutcome.ts` (new):
   ```ts
   export interface SweepOutcome { succeeded: number; failed: number; }
   /** Throws when a sweep failed for every doc it attempted (so graphile-worker retries the job and the queue checks see it); logs a warning when it failed for some; is silent when nothing failed. */
   export function assertSweepNotFailedEntirely(sweepName: string, outcome: SweepOutcome): void
   ```
   — `failed > 0 && succeeded === 0` → `throw new Error(`${sweepName}: all ${failed} attempted doc(s) failed`)`; `failed > 0` → `logger.warn({ sweepName, ...outcome }, "Sweep finished with per-doc failures")`; otherwise nothing. A sweep that attempted zero docs (`{ succeeded: 0, failed: 0 }`) is not a failure.
3. `runCompactionSweep` returns `Promise<SweepOutcome>`: `succeeded` counts docs whose `loadDoc` resolved, `failed` counts docs whose `loadDoc` threw; each failure is logged with `logger.error({ err, docId }, "Failed to compact doc")` instead of `console.error`. `handleDocCompactionSweepTask` calls `assertSweepNotFailedEntirely("docCompactionSweep", outcome)`.
4. `runDocHistoryRetentionSweep` returns `Promise<SweepOutcome & { rebaselined: number }>`: `succeeded` counts docs whose `rebaselineDocHistory` resolved (whether it returned `true` or `false`), `rebaselined` counts the `true`s (the number the existing test at `docs.test.ts` line 779 reads), `failed` counts throws, logged with `logger.error({ err, docId }, "Failed to rebaseline doc history")`. `handleDocHistoryCleanupTask` calls `assertSweepNotFailedEntirely("docHistoryCleanup", outcome)` *after* `cleanupExpiredDocHistory(pool)` has run, so the expired-checkpoint delete still happens on a partially failed sweep and the throw happens last.
5. Tests:
   - `backend/packages/data/src/__tests__/sweepOutcome.unit.test.ts` (new, unit tier): `{0,0}` and `{3,0}` do nothing; `{2,1}` logs one warning (spy on the `docs` logger) and does not throw; `{0,2}` throws with the sweep name and count.
   - `backend/packages/data/src/__tests__/docs.test.ts` (existing, integration): update the two call sites (line 306 `compactedCount` → `outcome.succeeded`; line 779 → `outcome.rebaselined`). Add one case for the compaction sweep: create two docs over the threshold, then corrupt one by inserting a `doc_updates` row whose `update` bytes are not a valid Yjs update (e.g. `'\x00ff'`); `runCompactionSweep` returns `{ succeeded: 1, failed: 1 }` and `handleDocCompactionSweepTask` resolves; with only the corrupted doc over the threshold, `handleDocCompactionSweepTask` rejects with `all 1 attempted doc(s) failed`.

## Acceptance criteria

- When every doc a compaction or history sweep attempts fails, the graphile-worker job fails (and is retried by graphile-worker's backoff); when some fail, the job completes and one structured warning names the sweep and both counts; when none fail, nothing is logged at warn level.
- When a history sweep partially fails, `cleanupExpiredDocHistory` has still run before the job fails.
- Per-doc failures appear as structured `docs`-logger error records with `docId`, and no `console.error` remains in either sweep.
