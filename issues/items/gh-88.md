## Context

The completed library module registers a `library-grid` view type and stores `coverGlyph` plus `{ blobId }` cover values, but no client renderer exists. The required Add action, cover image, and solid-color/glyph fallback are therefore not observable. #217 bootstrapped `web/` with the authenticated API client, `AuthenticatedWebContext`, i18n hook, `tokens.css` fallback colors, the view-type registry and generic view route; #218 made `GET /api/databases/:databaseId/properties` return server-localized `label`/`options` and migrated the Movies `secondaryRatingLabel` to an i18n key. This issue delivers the shared renderer and its container, replacing the placeholder renderer of #217. #89 builds on the same generic routes for agents/MCP.

## Task

Implement exported `web/src/view-types/library-grid/LibraryGridView.tsx` for registered type `library-grid` with this exact public contract:

```ts
type LibraryModuleContract = {
  coverKey: string; subtitleKey: string; ratingKey: string;
  secondaryRatingKey?: string; secondaryRatingLabel?: string;
  sourceUrlKey?: string; statusKey: string; coverGlyph?: string;
};
type LibraryGridItem = {
  id: string; databaseId: string; properties: Record<string, unknown>;
  computed: Record<string, unknown>; updatedAt: string; deletedAt: string | null;
};
type LibraryPropertyDisplay = {
  key: string; type: string; label: string;
  options?: Array<{ key: string; label: string }>;
};
type LibraryGridViewProps = {
  viewId: string; databaseId: string; contract: LibraryModuleContract;
  properties: LibraryPropertyDisplay[];
  state: { status: 'loading' } | { status: 'error'; error: { code: string } } |
    { status: 'ready'; items: LibraryGridItem[] };
  onCreated(item: LibraryGridItem): void;
};
```

The fetching wrapper passes `loading` before the query settles, `error` with the stable domain code on query failure, and `ready` with #37's exact generic item envelopes on success; only `ready` with zero items renders the empty state. The API adapter builds `properties` from the database property catalog returned by the route of #218, i.e. after #35's resolver has applied explicit override, requested user locale, English fallback, then raw key. For the card title choose the sole property metadata entry with `type = 'title'`; missing or multiple title properties is a component-level `library.createError` state. Subtitle, primary rating, status, optional secondary rating, and optional source link read values only at their respective contract keys. Render each field label from its matching `LibraryPropertyDisplay.label`; `secondaryRatingLabel`, when present, overrides only the secondary rating label. Render a select value by exact option-key lookup and fall back to the raw stored key when metadata lacks that option. Missing optional keys/values omit that field; malformed cover values use fallback. Use this component for Books and Movies/TV. A valid `{ blobId: string }` cover renders from `GET /api/blobs/:id?disposition=inline`; unsafe MIME types or any non-image/failed response use fallback and never embed an attachment response.

Fallback color: select from the `--library-fallback-1..6` variables of `web/src/styles/tokens.css` (#217) with 32-bit FNV-1a over UTF-8 bytes of stable `item.id`: start `2166136261`, for each byte XOR then multiply by `16777619` with unsigned 32-bit overflow, and take the final unsigned value modulo 6. Overlay `coverGlyph` and expose item title as accessible image text. Add uses i18n key `library.add`; states use `library.empty`, `common.loading`, and `library.createError` from `web/src/i18n/{en,cs}.json`, locale selected from authenticated user context per #35 (add the `library.*` keys to both files). After a nonblank name, call exact #37 route `POST /api/databases/:databaseId/items` with `{ properties: { name } }`; send no defaults or system-owned keys. While pending disable the form/button, set `aria-busy=true`, and ignore duplicate submit. On failure re-enable, retain the name, and announce `library.createError` in `aria-live=polite`. On success clear/close the form and call `onCreated` exactly once with the authoritative returned item; the wrapper inserts/reconciles it into the ready list without a second GET. Status/rating labels come from property/i18n metadata.

`secondaryRatingLabel` is an i18n key, never literal display text; this supersedes the earlier "overrides label" shorthand. The Movies contract value is `property.movies.secondaryRating.name` (#218); ship that key in `web/src/i18n/en.json` and `cs.json`, and resolve requested locale → English → matching `LibraryPropertyDisplay.label` → raw key. Books omits it. English/Czech tests prove the renderer never displays the stored key or an untranslated English literal when the locale entry exists.

Add `web/src/view-types/library-grid/LibraryGridViewContainer.tsx` and register it as the sole renderer for `library-grid` in `web/src/view-types/registry.ts` (#217), removing the placeholder. The generic view route resolves `{ viewId, databaseId }` and dispatches through that registry; both seeded Books and Movies/TV default views therefore mount this container. The container consumes `AuthenticatedWebContext = { user: { locale: string }; api: AuthenticatedApiClient }` and the typed `getView`, `listProperties`, `queryView`, and `createItem` methods from #217.

On mount or id change the container concurrently calls `GET /api/views/:viewId`, `GET /api/databases/:databaseId/properties`, and `POST /api/views/:viewId/query` with `{ cursor: null, limit: 50 }`. It validates the view's `library-grid` contract, projects the locale-resolved property catalog to `LibraryPropertyDisplay[]`, follows `nextCursor` only when the user requests more, and drives the exact loading/error/ready state. `createItem` calls the specified database-items route; `onCreated` reconciles the returned row by id into container state. Locale changes re-project property labels and re-render without rewriting items. Integration tests mount the generic route under authenticated Czech/English contexts, prove both system views dispatch to this container, assert the three calls and state transitions, and verify Add becomes visible from the authoritative response.

Because labels are server-resolved, a change of `AuthenticatedWebContext.user.locale` aborts any older property request, increments a request generation, sets the container to loading while preserving no stale localized labels, and refetches `GET /api/databases/:databaseId/properties`. Only the latest generation may commit. Failure enters the same error state with `library.createError`; retry repeats the current locale request. Items/view need not refetch. A cs→en race test delays the Czech response and proves it cannot overwrite the later English catalog.

## Scope

### In scope

- Web library-grid renderer, container, registry registration, generic create action, blob cover display, fallback, library i18n keys, and tests.

### Out of scope

- Workspace bootstrap, API client, context, i18n hook, tokens, registry and route scaffolding, delivered by #217.

## Acceptance criteria

- Books and Movies/TV render through one shared component driven by their registered contracts.
- Missing, loading, or failed covers show a stable color and `coverGlyph`; a valid blob replaces the fallback.
- Add calls `POST /api/databases/:databaseId/items` with only `{ properties: { name } }` and creates no system-owned values.
- Empty and error states are keyboard- and screen-reader-usable.
- Contract, item, and resolved-property metadata are runtime validated; title/field/option lookup and all fallback behavior match the exact rules above.
- Loading, error, ready-empty, and ready-populated states are driven only by the discriminated `state` prop; covers request the authenticated safe-inline blob URL.
- Add disables duplicate submits, announces failure without losing input, and hands the authoritative success row to `onCreated` exactly once.
- The generic view registry/container makes Books and Movies reachable and verifies authenticated view/property/query/create integration in both locales.
- Runtime locale changes refetch the server-localized catalog with abort/generation protection and deterministic loading/error behavior.
- English/Czech tests prove `secondaryRatingLabel` is rendered from the i18n entry, never as the stored key or an untranslated English literal when the locale entry exists.
