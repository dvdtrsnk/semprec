**Blocked by:** #131

## Context

Approvals are a system responsibility and cannot be hidden inside the originating project.

## Task

Add one Semprec navigation destination listing all pending requests across projects. Each row shows tool, risk class, safe payload summary, requested time, source project, and source agent-run link, with explicit Approve and Reject actions. Show decided state after races instead of treating a zero-row transition as an error. Provide loading, empty, malformed-payload, and action-error states using shared i18n/client conventions. A notification may link to this list but cannot itself decide.

## Scope

### In scope

- Global list, source links, safe summaries, decisions, and UI states.

### Out of scope

- Per-project approval lists, chat/push decisions, and notification transport delivery.

## Acceptance criteria

- Requests from different projects appear together.
- A race refreshes to the authoritative decided state.
- Sensitive credential values are never rendered.
