## Context

Model tier rationale: A one-condition filter in a single function with an existing unit test file and no new lifecycle, authorization or persisted-data contract.

An agent run offers the model the MCP tools a project has granted. `createMcpTools` in `backend/services/semprec-agents/src/agentSessionComposition.ts` reads `listMcpToolGrantsForProject` (`backend/packages/data/src/mcp/mcpAgentPageGrants.ts`) and keeps rows with `granted`. That listing deliberately includes tools of servers whose `mcpServers` item is not active (`active` false), because the project settings screen must show them as offline. As a result the model is also offered a tool of a switched-off server, and calling it ends with "This MCP tool is unavailable..." from `mcpInvokeTool.ts`. The catalog of one run must contain only tools that can actually run.

`getGrantedMcpAgentTools` in `backend/packages/data/src/mcp/mcpAgentTools.ts` already applies the full rule (grant, active registration, active and live server) for the permission manifest. This issue makes the run catalog follow the same rule. The grant itself stays stored, so switching the server back on makes its tools appear in the next run without any user action.

#1533 follows in the same file and changes how the remaining tools are named for the model.

## Scope

### In scope

- Excluding the tools of inactive MCP servers from the tool catalog of an agent run.

### Out of scope

- The names the model sees for MCP tools: #1533.
- Any change to what the settings listing returns, including server state and counts: #1455.
- Treating a server whose last connection failed as unavailable; only the `active` flag decides here.

## Acceptance criteria

- When a project has a granted tool of a server with `active` false, then the run's tool list does not contain it and the stored grant row is unchanged.
- When the server is activated again, then the next run's tool list contains the tool.
- When a granted tool belongs to an active server, then it is still in the list.
- A tool of an active server that is not granted is not in the list.
