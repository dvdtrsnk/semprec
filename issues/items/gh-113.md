**Blocked by:** #112

## Context

Manifest boundaries are ineffective if source code imports across modules/services directly.

## Task

Configure `dependency-cruiser` or an equivalent static rule so `modules/X/**` may not import `modules/Y/**` except through Y's registered public entry point. Apply the same no-internal-cross-import rule to `services/*`. Provide a repository script with actionable diagnostics and fixtures proving allowed shared-package/public-entry imports and rejected private imports.

## Scope

### In scope

- Configuration, runnable script, exceptions limited to declared entry points, and tests.

### Out of scope

- GitHub Actions workflow wiring and broad architecture refactors.

## Acceptance criteria

- Deliberate forbidden module and service imports fail the script.
- Public entry-point and neutral shared-package imports pass.
- Diagnostics name importer, imported path, and violated rule.
