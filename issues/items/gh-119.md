**Blocked by:** #118

## Context

Process memory is disposable, while long conversations can exceed the model context before their next turn.

## Task

Reconstruct dormant delegated and Semp conversations from the complete ordered `agent_run_events` history into `initialState.messages`. Before the first resumed turn, call public `estimateContextTokens(messages)` and `shouldCompact(tokens,contextWindow,settings)`. When required, convert stored events to the exact `Entry[]` tree (`id`, `parentId`, `seq`, `timestamp`, `message`) and use public low-level `prepareCompaction` plus `compact`; do not call the unfinished `AgentLane.compact()` wrapper or pi internals. Persist the resulting valid continuation/audit events so repeated restart remains deterministic.

## Scope

### In scope

- Reconstruction, protocol validation, pre-turn sizing, low-level compaction, and restart tests.

### Out of scope

- Custom compaction algorithms and unexported pi modules.

## Acceptance criteria

- A restarted conversation resumes with prior context.
- Oversized history compacts before provider invocation.
- Tool-use/result invariants remain valid after reconstruction.
