## Context

This single implementation issue delivers the complete `tasks-time-fix` batch.

## Task

Implement pure deriveTaskTime(timeFrom,timeTo): string|null with zero-padded 24-hour HH:MM; both become HH:MM–HH:MM using en dash, one becomes that value, neither NULL. Whenever a Tasks create/patch touches either source, derive from the effective post-write pair and store time in the same generic choke-point transaction. Keep time system-owned/locked and reject direct writes. Add idempotent stale-row backfill.

- Create/update covers both/from-only/to-only/neither exact values.

- Direct time writes remain rejected.
- Backfill corrects stale rows and rerun is no-op.
