## Context

This issue builds on #177 and completes the `operations` batch.

## Task

Monthly restore newest snapshot into disposable PostgreSQL/MinIO. Assert pg_restore success, items count >0, max(items.updated_at) freshness, doc_snapshots count >0 plus nonempty bytea, and 20 random blob objects match. On failure write backup_restore_failed through canonical notification writer and send external /fail; send HEALTHCHECKS_RESTORE_PING_URL success only after all assertions. Always destroy disposable state.

## Scope

### In scope

- Task deliverables, migrations, integration, tests, and necessary documentation.

### Out of scope

- Never modify production data.

## Acceptance criteria

- Valid fixture passes and pings once.
- Each injected failure emits one notification, /fail, and nonzero status.
- No success ping on failure.
- Disposable state is always removed.
